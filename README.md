# Аварийная смена

Прототип 2D survival horror, строго сверху. Unity **6000.6.5f1**, URP 2D.

Откройте проект через Unity Hub, затем `Assets/EmergencyShift/Scenes/FirstShift.unity` → Play.
WASD — движение, мышь — прицел, F — фонарь, E — дверь, ЛКМ — выстрел после подбора оружия. Лут подбирается автоматически. R — повтор после поражения/выхода.

FirstShift:9 помещений,19 сталкеров, патрули/засады, карты, запертые улучшения, вход/выход. BasementPrototype — свободные тесты с вашими настройками; LevelTemplate — основа новой карты. Сборка начинает с FirstShift.
