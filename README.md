# Аварийная смена — первый каркас

Поведение сталкера v0.7.2 принято пользователем. Базовый игровой набор работает, полный MVP ещё не завершён. [Актуальная готовность механик и следующие задачи](Docs/MVP_STATUS.md). Ниже также сохранена история предыдущих итераций.

Прототип 2D-хоррора для Unity **6000.6.5f1**. Есть капсула, фонарь, дверь и шестиногий сталкер с подкрадыванием, реакцией на свет, атакой и гибелью. Окружение остаётся однотонным. Сталкер озвучен «живой мембраной»: движение, световая боль, атака/ранение/разрыв и посадки частей.49 WAV/13 групп, расстояние/преграды/лимиты; старые пробы удалены. [Подробный гайд по звуку и C#](Docs/STALKER_AUDIO.md).

v0.4.2: все рабочие кадры сталкера — бледная серо-розовая плоть, без размытого фона. Трупы/куски затемнены и ниже живых врагов. Процедурная лужа появляется сразу при Dead; разлёт частей — через 0.12 с. Форма и общий размер луж различаются при смерти. Видео v0.4 ниже показывает предыдущую бордовую палитру; свежий снимок — `Docs/Previews/pale-living-and-remains.png`.

## Запуск

v0.4.4: чёткие тени повторяют полный текущий кадр сталкера, включая все ноги. Параметры `CreatureGroundShadow2D`: Contact Scale/Opacity, Projection Opacity/Stretch, Maximum Length. Выключение компонента позволяет сравнить вид без теней. Первая версия сталкера принята пользователем; следующая предлагаемая итерация — фонарь и лут.

1. Открыть эту папку через Unity Hub → Add project from disk. Проект уже добавлен в Hub на компьютере Mark.
2. Дождаться импорта пакетов и компиляции.
3. Открыть `Assets/EmergencyShift/Scenes/BasementPrototype.unity` и нажать Play.
4. Кликнуть внутри Game, чтобы ввод получала игра. WASD — движение; мышь — направление света/оружия; F — фонарь; E — близкая дверь. Предметы подбираются автоматически при приближении до .65, без требования света, с сообщением/временным звуком. После находки пистолета ЛКМ стреляет. После поражения R начинает комнату заново.
5. Для изменения уровня остановить Play и работать в Scene/Hierarchy. Изменения во время Play обычно не сохраняются после остановки.

Scene View оставлен в 2D с отключённым просмотром освещения, чтобы геометрию было удобно редактировать. В Game View действует настоящий свет игры и почти полная темнота. Переключение освещения Scene View не изменяет настройки фонаря в игре.

Если в Game видна только середина кадра, исчезли подписи управления/здоровья и E, выбрать `Emergency Shift → Preview → Fit Game View`. Увеличенный Scale при fixed resolution обрезает края кадра; Fit подгоняет его под вкладку и не меняет игровую камеру. После изменения размера окна при необходимости повторить Fit.

Репозиторий: [gameDevHorror](https://github.com/jdays2/gameDevHorror). Краткий прогресс и дальнейшая очередь — `Docs/PROGRESS.md`.

При первом импорте `StarterBootstrap` создаёт сцену, только если её ещё нет. Существующий уровень не пересобирается. Меню первоначального создания: `Emergency Shift → Create prototype scene (once)`.

Вся геометрия первой версии — простые однотонные формы. Вспомогательные белые формы в `Shapes` нужны Sprite Renderer и не являются художественными текстурами уровня.

База фонаря 4.2 единицы/80°; есть слабая подсветка у ног. Параметры меняются на Flashlight2D у Player. В v0.5.2 FlashlightRangeUpgrade.prefab повторяемый: каждая копия добавляет +0.6 дальности/+6° угла. В сцене три предмета: исходный пользователя и два в группе Flashlight upgrades — test path. Подойти до .65 — автоподбор с названием в UI, без чисел оптики. После трёх — 6.0/98°. Бонусы/Repeatable доступны на предмете, Maximum Range=7/Maximum Angle=110 на FlashlightUpgrades игрока. Ключи, коды и мигающие лампы пока будущие механики.

В текущем сталкере сохранены пользовательские дистанция страха 2.0 и задержка 0.33 с. В v0.6 два попадания пистолета убивают его обычным TakeDamage. Для отдельной проверки смерти также доступно Emergency Shift → Preview → Kill selected creature. Старое видео сталкера: Docs/Demos/stalker-demo-v04.mp4.

Пистолет лежит в первой комнате (1.8,-1.8); подойти до .65 — автоподбор. Счётчик появится после находки, ЛКМ — одиночный выстрел. Коробки патронов — (-1.8,1.7) и (11.7,-1.5). Три варианта эффекта переключаются через Emergency Shift → Preview → Shooting → 1/2/3 или Visual Profile на игроке. Сравнение: Docs/Demos/shooting-concepts-v06.mp4; настройка/архитектура — Docs/WEAPONS.md. Магазина/перезарядки пока нет.

В стартовой комнате слева от капсулы лежат четыре тестовых сталкера с кровью и кусками. Включить F и направить фонарь влево/влево вниз. Группа `Test corpses — Stalkers` сохранена в Hierarchy: трупы неподвижны, без AI и коллайдеров. Можно отключить группу или удалить командой `Emergency Shift → Preview → Remove test corpses`.

## Патруль/засада

Выбрать корень сталкера → **Stalker Patrol 2D → Patrol Enabled**. Отметить для мирных перемещений, снять для ожидания на текущем месте. **Use Patrol Area** — опциональные границы; без них короткие шаги от текущего места. **Detection Radius** и LOS нужны только для первого обнаружения: после него погоня до смерти одной стороны, без возврата домой. [Актуальная инструкция](Docs/PATROL_GUIDE.md).
