Прототип 2D survival horror, строго сверху. Unity **6000.6.5f1**, URP 2D.

Текущий этап — расширение концепта, механик и оружия в тестовой песочнице. Уровни для прохождения пока не создаём.

Откройте `Assets/EmergencyShift/Scenes/MechanicsSandbox.unity` → Play. Сборка начинает с этой сцены.
Три подписанные комнаты стоят в ряд вдоль общего коридора: Сталкеры; карта и запертая дверь; тир с неподвижными Сталкерами на 2/6/20 HP. В тире здоровье игрока повышается до 100, снаружи возвращается прежнее здоровье с пределом 3.

WASD — движение, мышь — прицел, F — фонарь, E — дверь, ЛКМ — выстрел после подбора оружия, 1/2 — пистолет/дробовик, X — поштучная зарядка дробовика. Лут подбирается автоматически. **R — полный сброс песочницы в любой момент, T — пополнение патронов уже подобранного оружия.**

FirstShift удалён по запросу владельца. BasementPrototype сохранён с ручными настройками; LevelTemplate остаётся основой сцены. Песочница не читает и не записывает checkpoint-слоты, не имеет целей прохождения или выхода.
