## Работающая версия

Unity **6000.6.5f1**, URP 2D. Основная тестовая сцена — `Assets/EmergencyShift/Scenes/MechanicsSandbox.unity`; текущая сборка стартует с неё. Проходимое демо пока не собрано.

В песочнице проверяются Сталкер, Спящий, двери/карты и оружие. WASD — движение, мышь — прицел, F — фонарь, E — взаимодействие, ЛКМ — выстрел, 1/2 — оружие, X — перезарядка, R — чистый сброс, T — патроны. [Подробности песочницы](Docs/SANDBOX.md).

FirstShift удалён; ручные настройки BasementPrototype сохраняются. Составление плана к релизу не отменяет отсрочку строительства уровня.
