Использование в игре подтверждено; художественная оценка runtime-результата остаётся владельцу. [Контракт](../../../../Docs/Features/DeathScreen.md), [проверки](../../../../Docs/Reports/DeathScreenD01.md).

Источник направления — [концепты C–F / выбран D](../../../Unused/UI/DeathScreen02/README.md); архивные браузерные макеты сохраняются там, C/E/F в игру не подключены. Фонарь после смерти не включается ради оформления.

Ресурсы: `Assets/EmergencyShift/Prefabs/UI/DeathScreenUI.prefab`, `Data/UI/DeathScreen/Transition.asset`; исходный uGUI-рецепт `AgentScripts/InstallDeathScreenD.cs`. Существующий Noto Sans Medium — SIL OFL1.1, TTF и лицензия в `Assets/EmergencyShift/Fonts/MainMenu/`. Шрифт не переупакован. Код/композиция оригинальные, стилистические ориентиры — существующие меню проекта. В реальном линейном рендере World Veil уточнён до alpha.97; тайминги1.4/.7/.5/.35 s — проверенные технические значения, отдельная художественная приёмка не заявлена.
