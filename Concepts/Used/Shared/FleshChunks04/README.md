# Общие куски плоти 04

Четыре новых прозрачных 2D-фрагмента для Сталкера и Спящего: тяжёлый мышечный комок, рваный лоскут, плотный сгусток и сложенная полоска ткани. Это отдельные лежащие куски, без лап, глаз и повторяющейся геометрической формы. У каждого разные разрывы, толщина и складки. Созданы встроенным `image_gen.imagegen`; [точный промпт](Source/prompt.txt), [исходный лист](Source/flesh-sheet.png).

Рабочие ресурсы: `Assets/EmergencyShift/Art/Effects/CreatureFlesh04`. PNG вырезаны по четырём квадрантам исходника; bbox определяется по alpha > 8, с запасом 2 пикселя, исходная прозрачность внутри bbox сохраняется. Размеры в мире: MuscleWad .28, TornFlap .26, DenseClot .20, TissueStrip .25 units. Unity: без NPOT-растяжения и mipmaps, bilinear, clamp, sRGB, native Sprite FullRect с центром .5/.5.

В обоих prefab плоть занимает индексы 10–13, используется существующими GoreProfile/GibMotion2D/RemainsRecord2D. Разный масштаб и импульсы дают локальную вариативность; после оседания части темнее живых и сохраняются до сброса уровня. Не добавлены AI, урон, лут или новая система пулов.
