# Очищенные конечности и составы останков 01

Рисунок этого семейства заменён [упрощённой матовой серией 01](../../Visual/SimplifiedArt01/README.md). Этот документ и прежние изображения сохраняют историю и техническую схему; актуальная детализация задаётся новой серией.

2026-10-17. Исправление по замечанию владельца: рядом с оторванной конечностью попадали края чужих частей из death-sheet; некоторые смерти Сталкера оставляли больше шести ног.

## Изображения

[Очищенные вырезки](clean-crops.png). `Tools/Art/clean_anatomical_gibs_01.py` берёт прежние прямоугольники Gib00–05 из действующих death-sheet обоих видов. В каждом оставляется основной связный силуэт с исходным сглаженным краем, отсоединённые соседние фрагменты удаляются. Сохраняются исходные цвета, холст и основная анатомия. Это обработка существующего рисунка, без перерисовки нейросетью.

Двенадцать отдельных RGBA находятся в `Assets/EmergencyShift/Art/Effects/AnatomicalGibs01`. Прежние native Sprite assets Gib00–05 перепривязаны к чистым текстурам, их GUID, pivot, PPU 330 и мировые bounds сохранены. Исходные death-sheet/анимации не менялись и остаются нужны телам. Индексы 0–4 — конечности, индекс 5 — небольшой кусок ткани. [Отчёт вырезки](crop-report.json) фиксирует удалённые компоненты.

## Состав смерти

У старых трёх составов Сталкера было восемь отдельными спрайтами заданных ног, включая повторные индексы, и сохранялось исходное тело с ногами. Эти ID теперь `restorationOnly`: доступны прежним сохранениям, но не выбираются для новой смерти.

Новые смерти обоих видов используют по три существующих анатомических состава. Исходное тело скрывается, остаётся один отдельный корпус; 3/4/4 оторванные конечности без повторения одной ноги, глаз остаётся в корпусе либо лежит отдельно. Маленьких обрывков мышц/плоти теперь 8/9/10 вместо 3/4/4, в прежних тёплой/холодной палитрах. Полное число частей — 13/14/16. Часть плоти мельче, радиусы/импульсы различаются; лапы не добавлялись для увеличения месива.

`GoreProfile.ChooseVariant()` выбирает только доступные новым смертям составы. У метода нет знания о виде врага; устаревание задано в данных. При отсутствии доступных составов выдаётся явная ошибка. Снимок хранит фактические индексы/положения частей; старые ID не переименованы и не удалены.

Кровь одновременно уплотнена отдельно в [BloodPools01](../BloodPools01/README.md). Её форма и RGB-текстура сохранены. Художественную оценку даёт владелец.
