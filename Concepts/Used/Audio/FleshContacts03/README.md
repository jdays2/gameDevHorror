# Короткий контакт по плоти · 03

2026-10-23, BUG-044. Четыре физических удара по хитбоксу врага, отдельно от его реакции на ранение/смерть. Подключены в fleshImpact банка PistolIndoorAudio, gain .4; художественная оценка владельца ожидается.

Источники — принятые проектные Membrane04/stalker_hit_01..04.wav. Их WAV и личные голоса обоих видов не заменяются. Обработка: моно-сумма, ускорение 1.45× для отличимого короткого тембра, удаление DC, широкое выделение контактной середины, спад .075 с и защитные fades. PCM16/48 kHz, .17 с, peak .8. Это производные прежней проектной звуковой семьи, не новая запись реального попадания. Новых сторонних источников/лицензий нет; исходное происхождение и условия — [Membrane04](../StalkerMembrane04/README.md). Хеши источников/выходов и RMS атаки — [manifest.json](manifest.json).

Повторить: `Tools/Audio/prepare_flesh_contacts03.py` (Python/numpy); назначение через Unity `AgentScripts/AuthorWeaponFx.cs`. Воспроизведение ограничено существующими четырьмя источниками и одним полным контактом материала на залп. Общий обработчик не выбирает вид врага. Личный голос может прозвучать дополнительно; отдельного контакта больше не лишают ни OwnsHitAudio, ни смерть, ни фаза пробуждения.

Проверки на настоящих фонах, со штатной камерой и прямым игровым миксом — [WeaponFeedback51](../../../../Docs/Reports/WeaponFeedback51.md). Громкость выстрелов, помпа, гильзы и голоса сохранены. Это техническое подключение; авторское одобрение не подразумевается.
