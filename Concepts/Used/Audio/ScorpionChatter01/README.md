# Писки присутствия · TASK-005

**Historical / отклонено владельцем 2026-10-31:** звук сочтён похожим на обезьяний крик. Три пробы больше не входят в активный банк и не вызываются из просмотрщика. Обычный писк теперь использует одобренный [Detection.wav](../ScorpionDiscovery01/README.md). Оригиналы и прежняя обработка ниже сохраняют происхождение; описание подключения относится к пробе r10.

Три оригинальных SFX Runway продолжают направление существующего насекомого писка обнаружения. Это художественный звук существа, не запись настоящего скорпиона. Промпты/task ID: [provenance.json](provenance.json); MP3 сохранены в Originals. Референсные записи не копировались.

Production: [Squeak1.wav](../../../../Assets/EmergencyShift/Audio/Enemies/Scorpion/Squeak1.wav), [Squeak2.wav](../../../../Assets/EmergencyShift/Audio/Enemies/Scorpion/Squeak2.wav), [Squeak3.wav](../../../../Assets/EmergencyShift/Audio/Enemies/Scorpion/Squeak3.wav). Все .64s, mono PCM16/32kHz. Конвертация `prepare.py --ffmpeg <path>`: mono/resample, только уменьшение peak до .708, fades2/15ms. Без EQ, изменения высоты и слоёв. Третий исходник не усилен; он заметно тише второго. Хэши в [processing.json](processing.json).

Используется существующий канал Quiet presence. У каждой особи собственные интервалы: ожидание3.5–6.5s, погоня1.6–3.2s, стартовая задержка.8–2.8s, исключён немедленный повтор варианта. Писк доигрывает; атака/сигнал обнаружения откладывают следующий. Смерть останавливает живой канал. SqueakVolume=.3; расстояние и стены ослабляют звук. В игре pitch .96–1.04, исходники сохранены.

В [просмотрщике](http://127.0.0.1:8103/Scorpion01/viewer.html?revision=burgundy-rupture-r10) доступны три отдельные пробы и периодические писки первой особи при включённом звуке. Нативный Play подтвердил воспроизведение в ожидании/погоне. Прямое прослушивание агентом недоступно; художественная оценка остаётся владельцу.
