# Сталкер: контактный ожог и лопанье плоти 05

Текущий EyeBurn сохранён. Оба flesh-pop заменены [CreatureRupture06](../CreatureRupture06/README.md) и остаются здесь как история; профили больше их не выбирают.

Сгенерированы по запросу владельца 2026-10-17 через Runway Sound Effects; подключены для оценки, не объявлены художественно утверждёнными. Сохранены два неизменённых MP3-оригинала; генерация не является полевой/lossless-записью. Условия использования — связанный аккаунт Runway, не сторонняя CC0-библиотека.

- `eye_burn_01.wav`: короткий влажный контакт/шипение, .48 с. Начинается до видимого ожога, без замены голоса реакции.
- `flesh_pop_01.wav`, `flesh_pop_02.wav`: две отдельные атаки влажного разрыва, .655 и .625 с. Не воспроизводить весь двухударный оригинал на одну смерть.

Точная нарезка, пиковые/RMS уровни и SHA-256 — processing.json. Повторяемая подготовка: `Tools/Audio/prepare_stalker_tissue.py --ffmpeg <path>`. Только обрезка, удаление DC, выравнивание пика и короткие fade; без тона/изменения pitch/новой реверберации. PCM16 mono 48 kHz, предзагрузка в Unity.

Прежний принятый голос/движение мембраны и исходники death остались; заменён только текущий Death. Звуки Спящего не менялись. Концепт новой визуальной смерти — Docs/Enemies/RUPTURE_CONCEPT.md.
