# PlayerHit01 · B, плоть и ткань

TASK-009 **отложена владельцем; банк отключён через Volume=0 в сохранённом профиле**. B ранее отклонён по звучанию; поздние голосовые пробы тоже отклонены как мужской стон при неопределённых возрасте и гендере героя. Новых звуков на этом этапе не добавлять; перед возвращением требуется глубокое исследование. Клипы и GUID сохранены как история технической интеграции, восстановление .8 без нового решения не выполнять. [Проверка отключения](../../../../Docs/Validation/PlayerHitTask009/Deferred-off/README.md).

Четыре самостоятельно созданных коротких контакта остаются назначены в `Data/Audio/PlayerHitAudio.asset`, но их общий gain равен0. PCM16 mono48k, около.32s, pitch±1.2%; routing — существующий WorldAudio. Технический контракт — [PlayerHitAudio](../../../../Docs/Features/PlayerHitAudio.md).

Исходные MP3, точные prompts/task IDs, обработка и сравнения сохранены в [общем исследовании A/B/C](../../../Unused/Audio/PlayerHitTask009/README.md). Файлы исследования остаются на прежних путях. [Основное происхождение](../../../Unused/Audio/PlayerHitTask009/provenance.json), [самостоятельные дубли B2–4](../../../Unused/Audio/PlayerHitTask009/independent-takes-provenance.json), [экспорты/измерения](../../../Unused/Audio/PlayerHitTask009/processing.json). Новые источники созданы через подключённый Runway для этой задачи; лицензия внешнего sample pack им не приписывается.

Оригиналы и принятые голоса существ/оружия не заменялись. Эта семья хранит подключённый выбор B, а A/C остаются альтернативами для сравнения. Наличие в Used не означает утверждения окончательного сведения.

Основной игровой пример после отзыва владельца: [B — четыре попадания без выстрелов](../../../../Docs/Validation/PlayerHitTask009/B-hits-only-native/native-gameplay.mp4). Прежний пример с выстрелом на каждом попадании отклонён как демонстрация.
