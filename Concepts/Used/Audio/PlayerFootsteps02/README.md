# Шаги игрока · короткий контакт 02

Рабочая замена по просьбе владельца убрать шарканье. Подключены шесть контактов одной обуви из общего сгенерированного исходника: компактная атака пятки/подошвы, обрезанный хвост, длительность 146–180 мс. Это AI-foley, не реальная полевая запись. Художественная оценка владельцем ещё не зафиксирована.

`PlayerWorldAudio.asset → concreteSteps` использует новый банк. Это основное покрытие и fallback, который сейчас звучит на неразмеченных полах тестовых сцен. Отдельные `woodSteps` и `tileSteps` сохранены. Старые WAV не удалены. История источников/точный prompt — [provenance.json](provenance.json), нарезка, уровни и контрольные суммы — [processing.json](processing.json).

Громкость профиля .24, шаг по пути 1.05 единицы, минимальный интервал .22 с и pitch ±2.5% сохранены. При скорости 3.5 единицы/с номинальный интервал .30 с: клип заканчивается до следующего шага даже при минимальном pitch. Существующий селектор исключает немедленный повтор; шесть вариантов устраняют обязательное ABAB прежней пары. Нового runtime-кода, AudioSource или эффектов нет.

Импорт PCM16 mono 48 kHz, Decompress On Load, preload, normalize выключен. Суммарно 46 368 сэмплов: около 181 KiB float PCM для шести клипов без учёта объектов/буферов Unity. Это оценка содержимого клипов, не замер общей памяти игры. Обработка выполняется заранее, не при каждом шаге.

- [Игровой уровень, .24](Previews/walking-game-level.wav): реконструкция 12 шагов с текущим интервалом и pitch, не запись из Play.
- [Копия +9 дБ для прослушивания](Previews/walking-audition-plus-9dB.wav): только превью, в игре не используется.

Воспроизводимая обработка из корня проекта:

```powershell
python Tools/Audio/prepare_player_footsteps_02.py --ffmpeg <path-to-ffmpeg>
```
