# Общий короткий разрыв 06

2026-10-17. Владелец одобрил исходную односекундную пробу, попросил две вариации в той же стилистике и подключение при смерти врагов.

Три PCM16 mono / 48 kHz клипа находятся в `Assets/EmergencyShift/Audio/CreatureRupture06`; один `Data/Audio/CreatureRupture06.asset` назначен Сталкеру и Спящему. В текущих профилях старые Death/rupture не выбираются. По последующему отзыву владельца общий `volume` набора снижен до 0.8 (примерно −1.94 дБ) только в игровом воспроизведении. WAV и сравнительное прослушивание ниже сохраняют исходный уровень; другие голоса, ожог и контакты не заменены. Визуальная кровь/разлёт частей не менялись.

- 01 — одобренная проба, точная копия WAV, 1 с.
- 02 — монтаж соседних всплесков середины с короткими crossfade и немного более быстрым темпом, около 0.97 с.
- 03 — чуть более низкая/плотная середина и тихий дополнительный всплеск из того же источника, 1 с.

02/03 — **монтажные производные одобренного звука**, не новые независимые AI-записи. Попытки сгенерировать два новых источника сервис отклонил; повторных запросов с обходом фильтра не было. У них общие исходная фактура, атака и близкие RMS/peak; правки меняют ритм, а не только общий pitch. Вариации подключены по поручению владельца, их художественная оценка остаётся за ним.

[Прослушивание 01 → 02 → 03](audition-01-02-03.wav): между звуками 0.4 с тишины. Это монтаж для сравнения, не игровая запись.

`EnemyDeathAudioVariants` хранит последний выбранный клип отдельно от общего asset, на время Play-сессии. Следующий выбор исключает его, включая смерть другой особи/другого вида с тем же набором. Для единственного валидного клипа разрешён повтор; пустой набор молчит. Смерть и тихая загрузка по-прежнему принадлежат существующим компонентам. Новых AudioSource/менеджеров не добавлено.

Оригиналы сохранены в Originals. Одобренная историческая проба также остаётся по прежнему адресу `Concepts/Unused/Audio/StalkerRupture06`, чтобы сохранить ранее выданный плеер. Точная подготовка/хэши — processing.json; повторяемый инструмент — `Tools/Audio/prepare_creature_rupture_06.py --ffmpeg <path>`. Исходная генерация — Runway Sound Effects, не полевая/CC0-запись. Аудио референса пользователя в результат не смешано.
