# Контакт по плоти B · шесть вариантов

2026-10-23. Владелец выбрал B из двух FleshImpactStudies04, затем поручил сделать несколько близких вариантов для серии попаданий. В PistolIndoorAudio.fleshImpact подключены исходный `flesh-contact-B.wav` и пять производных B-02..06, gain .28; прежний выбор запрещает одинаковый клип подряд, pitch .97–1.03 сохранён. После проверки владелец подтвердил: «я проверил, все норм». Художественная приёмка текущего аудиобанка отмечена в [acceptance.json](acceptance.json).

Источник — [B-heavy-wet-rupture.wav](../../../Unused/Audio/FleshImpactStudies04/B-heavy-wet-rupture.wav); [промпт, исходный MP3 и task ID](../../../Unused/Audio/FleshImpactStudies04/generation.json). Это собственная генерация по направлению владельца, референсы Pixabay не сэмплировались. Историческая пара A/B сохранена на прежнем месте для воспроизводимости выбора; текущая производная и её назначение описаны здесь.

Исходный B сохранён побитово. Его почти неслышный хвост ранее укорочен с 1 с до .34 с с .04 с fade, сохранив 99.80% энергии исходного PCM. Пять дополнительных вариантов сделаны из того же исходника: разделение на плотный низкий удар, среднюю влажную ткань и высокую атаку, сдержанный баланс слоёв, небольшие независимые изменения времени хруста/разрыва, короткий хвост. Это производные B, не новые записи или генерации. Первые .004 с контакта сохраняются; к изменённой фактуре плавный переход до .016 с. В результате есть плотный, острый, влажный, компактный и волокнистый варианты одной семьи.

Длительности .29–.35 с (.361 с при минимальном pitch): прежние четыре канала успевают освобождаться при быстрых пистолетных попаданиях с интервалом .1 с. PCM24/48 kHz/stereo, импорт PCM/DecompressOnLoad/preload. Пики .78–.80, RMS первых .2 с отличается от B на 0…−.83 dB; clipped samples=0. Gain .28 сохранён. Бетон/дерево, FirearmMix02, механика, гильзы, голоса и дым не менялись.
