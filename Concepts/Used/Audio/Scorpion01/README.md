# Скорпион · оригинальные звуки · TASK-005

Четыре контакта лап, попадание по хитину/плоти, смыкание клешней, тревога стаи и тихое присутствие. Production — Assets/EmergencyShift/Audio/Enemies/Scorpion. Источники MP3 — Sources; WAV mono PCM16/32kHz, DC убран, клиппинга нет. Длительности/хеши — processing.json, промпты/генерации — provenance.json.

Вдохновение владельца: [SCORPION SOUNDS](https://www.youtube.com/watch?v=2C0146IKxi0), [Opistophthalmus pallipes stridulating (Hissing)](https://www.youtube.com/watch?v=SMBj8VAFoPw). Страницы/названия доступны; прямое акустическое сравнение их дорожек агентом не выполнено. Видео не скачивались, их сэмплы не копировались. Новые эффекты разработаны как сухое хитиновое трение/стридуляция и короткие тяжёлые контакты.

**Клешни r2:** прежнее сухое клацанье отклонено владельцем как не соответствующее концепту. Sources/attack.mp3 сохранён как Historical. Текущий Attack.wav собран из двух новых оригинальных источников attack-r2-1/2: замедленный хруст оболочки, плотный органический хват, приглушённый верх. Длина 340ms, акцент 5ms RMS на 44.8125ms после запуска: cue .32 и strike .40 в атаке .56s дают целевой отступ 44.8ms. Разброс pitch .96..1.03 даёт отклонение до 1.9ms без учёта кадрового/DSP-буфера. Хвост при pitch .96 заканчивается до конца атаки; принудительного Stop при нормальном завершении нет.

ScorpionAudio2D имеет четыре ограниченных источника: голос/попадания, отдельные клешни, контакты, присутствие. Попадание больше не обрывает смыкание. Pitch/выбор контакта косметические. Дальность/стены ослабляют звук; тревога звучит у одного члена. Idle прекращается при тревоге; контакты требуют реального перемещения. Disable/смерть останавливают все каналы и сбрасывают latch. На паузе AudioListener сохраняет позицию воспроизведения.

Полный rebuild: `python process_audio.py`; он вызывает process_attack_r2.py, поэтому не возвращает отвергнутый Attack r1. Только клешни: `python process_attack_r2.py`. Слои, фильтры, fade 4/60ms, компрессия и хеш — [attack-r2-processing.json](attack-r2-processing.json). Остальные семь WAV при полном rebuild остались побайтно прежними.

Технические проверки WAV и события проигрывания выполнены. Нативные счётчики исходной версии — Docs/Validation/ScorpionRoom01/door-play.json; новая проверка одновременного попадания, паузы, disable/reactivate и смерти — [ScorpionAudio02](../../../../Docs/Validation/ScorpionAudio02/README.md). Независимый агент проверил сигнал/код, root — реальные AudioSource. Аудиовход у агента недоступен: прослушивание и художественная приёмка не заявляются. Это не измерение 20 врагов.
