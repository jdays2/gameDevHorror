# Полы · базовые текстуры 01

2026-10-16. Два примера для выбора стилистики владельцем. По следующему поручению владельца подключены в MechanicsSandbox как превью: плитка в комнате 02, бетон в тире 03. Финальное художественное одобрение ещё предстоит. Готовый Kenney pack владелец исключил как несоответствующий стилю и требованиям.

- [Плитка лаборатории](lab-tile-base-01.png): матовая серо-бежевая керамика, регулярная сетка 6×6, узкие швы, сдержанная фактура.
- [Бетон склада](warehouse-concrete-base-01.png): ровный серый бетон с мелким зерном и слабой вариацией тона.

Это чистые основы. Кровь, повреждения, разбитые элементы, ржавчина и потёртости в этом запросе не создавались. Коврики и остальные покрытия не входят в эти первые два образца. Вариации предполагаются после одобрения основы.

Изображения созданы встроенным imagegen; точные промпты и параметры происхождения — [provenance.json](provenance.json). Скопированы исходные результаты без перерисовки/обработки. Сторонние изображения и ассетпаки не использовались; новую стороннюю лицензию этим материалам не назначаем.

Проверены декодирование PNG, размеры, непрозрачность, SHA-256 и вид в Play при существующем свете. Копии в Assets побайтово совпадают с источниками. Импорт: 209 PPU, FullRect, NPOT None, Repeat; одна текстура покрывает 6×6 units, плитка около 1×1 unit. Полы используют Tiled Size 20×16 при Scale 1 и FlatLit. При переключении Draw Mode сначала задавайте режим, затем Scale 1: Unity может автоматически компенсировать размеры спрайта масштабом.

Это проба масштаба и стилистики в тестовой сцене. Вариации повреждений не добавлены; строгая бесшовность для финального производства не утверждена. [Проверка интеграции](../../../../Docs/Validation/SandboxFloorPreview.json).
