## Сцена и переиспользование

Сцена: `Assets/EmergencyShift/Scenes/ArtReview/EnvironmentPropsReview.unity`. Ресурсы — `Art/Environment/IndustrialProps02`, шесть обычных префабов — `Prefabs/Environment/IndustrialProps02`. В комнате семь экземпляров (бочка повторяется дважды), бетон и плитка, подписи, слабый местный свет, игрок/фонарь/камера из существующего LevelRig. Это отдельный арт-тест; MechanicsSandbox остаётся основной сценой. Новый арт-тест не добавлен в Build Settings.

Размеры задаёт PPU каждого спрайта, рассчитанный из видимой ширины. Scale у префабов равен 1. Материал FlatLit общий; коллайдеры следуют основному силуэту: круг для бочки, прямоугольник для остальных. Слой 8 блокирует тело/лучи; PropGroundShadow2D использует общий профиль LowPropShadows: слабая контактная тень и короткая проекция силуэта от фонаря/комнатной лампы. Максимальное удлинение .24 units. URP ShadowCaster на мебели удалён, у стен сохранён. Сложные отверстия/зазоры под стеллажом пока не моделируются. Это ограниченная плоская проекция от одного преобладающего источника, не физический расчёт высоты/полутени. Металлический звук попаданий не создавался; ImpactSurface не назначен. Содержимое и основа каждого PNG пока слиты.

Расположение и свет редактируются в Unity Scene. Команда **Emergency Shift → Art → Create environment review room (once)** предназначена только для первоначального создания, отказывается перезаписывать существующие сцену/ресурсы. При Play ничего не генерируется. Нет чекпоинтов, врагов и сценария прохождения.

## Источники и ограничения

Встроенный imagegen редактировал по одному исходному PNG IndustrialProps01. Стол и шкаф оборудования получили ещё одну коррекцию поверхности: удалены лишние сколы/потёртости при сохранении новой компоновки. Итоговые PNG скопированы без обработки, с исходной альфой. [Точные промпты, исходные хеши и коррекции](provenance.json). Промежуточные невыбранные изображения в библиотеку не включены. Сторонние источники не использованы; сторонняя лицензия не назначается.

Чистая основа сохраняет небольшую фактуру материала и локальную светотень. Не утверждаются идеальное albedo, полная независимость слоёв, финальный баланс масштаба или художественное одобрение. Проверки сцены и реальный Play-кадр — в [гайде](../../../../Docs/Guides/ENVIRONMENT_LIBRARY.md).
