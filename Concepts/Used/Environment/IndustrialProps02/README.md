## Сцена и переиспользование

Сцена: `Assets/EmergencyShift/Scenes/ArtReview/EnvironmentPropsReview.unity`. Ресурсы — `Art/Environment/IndustrialProps02`, шесть обычных префабов — `Prefabs/Environment/IndustrialProps02`. В комнате семь экземпляров (бочка повторяется дважды), бетон и плитка, подписи, слабый местный свет, игрок/фонарь/камера из существующего LevelRig. Это отдельный арт-тест; MechanicsSandbox остаётся основной сценой. Арт-тесты не добавлены в Build Settings. Полностью тёмная копия — `EnvironmentPropsDarkReview.unity`: фонарь выключен при старте, F включает его, фоновая подсветка равна нулю.

Размеры задаёт PPU каждого спрайта, рассчитанный из видимой ширины. Scale 1, общий материал FlatLit, слой 8. Для столкновений сохранены круг бочки и прямоугольники мебели. Для теней восстановлен стандартный URP ShadowCaster2D с источником SpriteRenderer: сетка Tight следует альфе PNG при пороге .2, включая отверстия поддона, без почти прозрачной бахромы. Длина тени зависит от света и не ограничена короткой проекцией. Временные PropGroundShadow2D/LowPropShadows удалены после уточнения владельца: проблема была в прямоугольной форме, а не в размере тени. Удаление двух Inspection light в сцене сохранено. Это 2D-силуэт, без высоты 3D-объекта. Металлический звук попаданий не создавался; ImpactSurface не назначен. Содержимое и основа каждого PNG пока слиты. Подробности — в [руководстве](../../../../Docs/Guides/ENVIRONMENT_LIBRARY.md).

Расположение и свет редактируются в Unity Scene. Команда **Emergency Shift → Art → Create environment review room (once)** предназначена только для первоначального создания, отказывается перезаписывать существующие сцену/ресурсы. При Play ничего не генерируется. Нет чекпоинтов, врагов и сценария прохождения.

## Источники и ограничения

Встроенный imagegen редактировал по одному исходному PNG IndustrialProps01. Стол и шкаф оборудования получили ещё одну коррекцию поверхности: удалены лишние сколы/потёртости при сохранении новой компоновки. Итоговые PNG скопированы без обработки, с исходной альфой. [Точные промпты, исходные хеши и коррекции](provenance.json). Промежуточные невыбранные изображения в библиотеку не включены. Сторонние источники не использованы; сторонняя лицензия не назначается.

Чистая основа сохраняет небольшую фактуру материала и локальную светотень. Не утверждаются идеальное albedo, полная независимость слоёв, финальный баланс масштаба или художественное одобрение. Проверки сцены и реальный Play-кадр — в [гайде](../../../../Docs/Guides/ENVIRONMENT_LIBRARY.md).
