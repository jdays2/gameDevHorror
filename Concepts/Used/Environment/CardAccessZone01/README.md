# CardAccessZone01 · выбранный B

Владелец выбрал полосатый B. Его сокращённая версия — общий prefab `Assets/EmergencyShift/Prefabs/Environment/FloorMarkings/CardAccessZone.prefab`, подключённый ко всем шести карточным дверям MorgueRouteTest. A/C и ранний B остаются историческими вариантами в AccessDoorTrial01; в текущей сцене их экземпляров нет.

Размер — 3×0.900390625 unit (461 px / 512 PPU), прежняя глубина 1.5 уменьшена на 40%. Две маски белого RGB: white-foundation и access-stripes; цвет полос задаёт Color дочернего Access color. Синий по умолчанию, зелёный — override экземпляра, без цветных копий PNG. Материал FlatLit, сортировка -7/-6. Белая основа .78/.79/.76; локальные потёртости частично раскрывают настоящий пол. Два разных следа в середине, более мягкая протёртость, четыре коротких царапины и четыре неравных протёртых края. По дополнительной просьбе владельца резкость снижена: сила повреждений 32%, растушёвка 7 px; до фактуры даже самые стёртые участки сохраняют 68% краски. Сквозных резких вырывов больше нет. Маска износа общая для обоих слоёв, поэтому синяя краска не висит над дыркой в белой. Шум исходной разметки используется только как слабая фактура краски.

Pivot префаба — середина верхнего края; разметка уходит в local -Y, local +Y направлен в дверь. Верхний видимый край всегда примыкает к ближней грани закрытой створки; полотно занимает всю ширину проёма. Скрытой прозрачной рамки у PNG нет. Для створки толщиной .3 центр pivot находится на .15 unit от центра двери; это контакт с гранью, не дополнительный отступ. В текущей сцене все двери и маркировки шириной 3 unit и без scale overrides. Чтобы поставить на другую дверь, ориентируйте +Y в проём, совместите верхний край с гранью створки и ширину с проёмом. Меняйте Color только у Access color; изменения формы/износа общего prefab распространяются на все экземпляры.

Разметка статична: два SpriteRenderer, без света, коллизий, ShadowCaster, runtime-скриптов и генерации при запуске. Звуки принадлежат двери, в этот префаб не входят. Точные исходники/экспорт — prepare.py и provenance.json; скрипт запускается из этой папки, находит Unity-проект и обновляет только две маски. Это развитие процедурной технической геометрии B, без внешних заимствований и изображения света/теней в текстуре.
