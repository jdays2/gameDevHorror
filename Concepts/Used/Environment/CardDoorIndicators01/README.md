# CardDoorIndicators01

По поручению владельца на всех шести карточных дверях MorgueRouteTest размещено по два крошечных индикатора у нижних углов закрытой створки, со стороны напольной разметки. Синий/зелёный цвет соответствует карте и сохраняется после открытия. Пара закреплена на неподвижной раме, не уезжает со створкой. Вид сверху позволяет видеть линзы также при подходе с обратной стороны.

Общий prefab: Assets/EmergencyShift/Prefabs/Environment/CardDoorIndicators.prefab. Local X — вдоль проёма, +Y направлен в дверь. Лампы стоят в x=±1.43, y=-.17 unit относительно центра двери шириной 3 и толщиной .3. Линза диаметром .045 unit (4.5 см при 1 unit=1 м), корпус .075. Цветные линзы FlatUnlit дают постоянную читаемую точку; маленькие Point Light2D с радиусом .18 и интенсивностью .12 слегка освещают ближайший пол (blend style 2). Тени и мерцание отключены. Полноценного освещения комнаты эти точки не дают; защитного источника для врагов или LocalLamp2D на них нет. Настройки размера/яркости принадлежат общему prefab, цвета зелёной пары — override экземпляра; runtime-генерации и новых пользовательских C# компонентов нет.

Круглая линза — исходная техническая форма, растрированная в native Texture2D 32×32 с белым RGB и сглаженной альфой; Sprite также native asset. Внешних источников нет. create.cs — исходный одноразовый авторинг (выполнялся через открытый Editor), сохраняет существующие объекты и отказывается перезаписывать готовый prefab. Дальнейшая правка — в prefab через Unity. Формирование текстуры происходит только при авторинге.

Звуки всех карточных дверей используют прежний общий ReaderFeedback.asset. Отказ и первое успешное считывание проверены с обеих сторон каждой двери. Первое считывание даёт задержку .24 с; отказ ограничен .8 с, после общей разблокировки повторный сигнал не нужен. Сами звуки созданы в AccessDoorTrial01, здесь не заменялись.
