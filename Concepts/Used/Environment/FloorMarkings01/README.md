# FloorMarkings01

2026-10-16. Общая фактура краски переиспользуется в созданных по запросу владельца PNG и Unity-префабах разметки. Художественное одобрение ещё ожидается; Used обозначает использованный источник, а не финальную оценку.

- `Sources/paint-coverage.png` — исходная непрозрачная монохромная маска покрытия из встроенного imagegen.
- [provenance.json](provenance.json) — точный промпт, рецепт перевода покрытия в альфу, параметры и SHA-256.
- [Обзор](Previews/Overview.png), [фактура крупно](Previews/Detail.png) — рендер настоящих ассетов Unity, не генерация сцены по текстовому запросу.
- [Гайд: элементы, стыковка, цвет и длина](../../../../Docs/Guides/FLOOR_MARKINGS.md).

16 PNG имеют исключительно белые RGB-каналы и переменную альфу. Цвета примеров создаются SpriteRenderer.Color, отдельных жёлтых/красных/синих игровых изображений нет. Геометрия нарисована детерминированным Editor-растрированием; это устраняет неточные точки стыковки и брызги вокруг знаков из ранних атласов. Фактура — единая сгенерированная маска, не набор независимых случайных стилей.

История отклонённых технических проб: [Unused](../../../Unused/Environment/FloorMarkings01/README.md). Сторонние изображения/ассетпаки не использованы. Модель встроенным инструментом не раскрывается; сторонняя лицензия этим источникам не приписывается.
