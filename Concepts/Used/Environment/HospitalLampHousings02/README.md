# Настенные лампы 02 · открытая конструкция по схеме владельца

Два RGBA-спрайта созданы встроенным imagegen по [схеме владельца](Sources/user-wall-lamp-sketch.png). Трубка вынесена в комнату на двух торцевых креплениях и целиком видна сверху; у стены остаётся узкая монтажная планка. Между планкой и трубкой прозрачный просвет. Широкой крышки над трубкой нет. Прежняя версия [01](../HospitalLampHousings01/README.md) сохранена как история неверного ракурса.

- [Длинная лампа](Sprites/ward-tube-housing.png): видимая длина 1.10, разные патроны и локальный след использования.
- [Компактная лампа](Sprites/corridor-diffuser-housing.png): длина .86, разные винты и небольшой след подкрашивания на планке.

Исходник вертикальный: трубка слева, планка у стены справа. В prefab дочерний `Mount` повёрнут на +90°, чтобы сохранить прежнее соглашение о направлении крепления. В тире MechanicsSandbox левая лампа имеет поворот 90° и центр (40.2783; 3), правая — 270° и (59.7139; 3). Задние кромки совпадают с внутренними гранями стен x=40.2/59.8. Трубки обращены в комнату; проверено отсутствие стены между источником и комнатой.

## Свечение

`Mount` использует прежний FlatLit. `Bulb` — отдельный прямоугольный sprite с материалом `Materials/HospitalTubeGlow.mat` и шейдером `TubeGlow.shader` (пути относительно Assets/EmergencyShift). Шейдер рисует белое ядро, цветную оболочку и плавно затухающий ореол, без жёстких краёв прямоугольника. Общее поле эффекта .13 единицы поперёк трубки; яркое ядро значительно уже. Параметры материала: Core Strength=.9, Tube Strength=.36, Halo Strength=.22. Цвет берётся из существующего SpriteRenderer лампы; один материал работает для холодной и тёплой палитры.

Это местная имитация свечения трубки; пол по-прежнему освещает существующий Light2D радиусом 1.45 и intensity .28. Глобальный bloom не добавлялся. Эффект использует тот же `Bulb`, который включает/выключает LocalLamp2D, поэтому мерцает вместе с лампой. Дополнительных голосов, таймеров, MonoBehaviour или защитных свойств света нет. Тихий аудиопрофиль сохранён.

Нативные PNG остаются по стабильным путям `Art/Environment/HospitalLampHousings01`: изображения заменены, GUID и Sprite ID сохранены. Полноразмерные оригиналы здесь неизменны, включая alpha; импорт Single с центральным pivot, Bilinear, max size 1024. Ни фон, ни пиксели программно не редактировались.
