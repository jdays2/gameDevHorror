# Настенные лампы 02 · открытая конструкция по схеме владельца

Рисунок этого семейства заменён [упрощённой матовой серией 01](../../Visual/SimplifiedArt01/README.md). Этот документ и прежние изображения сохраняют историю и техническую схему; актуальная детализация задаётся новой серией.

Два RGBA-спрайта созданы встроенным imagegen по [схеме владельца](Sources/user-wall-lamp-sketch.png). Трубка вынесена в комнату на двух торцевых креплениях и целиком видна сверху; у стены остаётся узкая монтажная планка. Между планкой и трубкой прозрачный просвет. Широкой крышки над трубкой нет. Прежняя версия [01](../HospitalLampHousings01/README.md) сохранена как история неверного ракурса.

- [Длинная лампа](Sprites/ward-tube-housing.png): калибровочная длина исходника 1.10; текущая игровая 1.25, разные патроны и локальный след использования.
- [Компактная лампа](Sprites/corridor-diffuser-housing.png): калибровочная длина исходника .86; текущая игровая 1.0, разные винты и небольшой след подкрашивания на планке.

Исходник вертикальный: трубка слева, планка у стены справа. В prefab дочерний `Mount` повёрнут на +90°, чтобы сохранить прежнее соглашение о направлении крепления. В тире MechanicsSandbox левая лампа имеет поворот 90° и центр (40.225; 3), правая — 270° и (59.775; 3). Задние кромки совпадают с внутренними гранями стен x=40.2/59.8. Трубки обращены в комнату; проверено отсутствие стены между источником и комнатой.

## Свечение

`Mount` использует HospitalLampHousing на стандартном URP Sprite-Lit-Default. Однопиксельная чёрная lighting mask исключает только канал трубок (существующий Blend Style 2, Multiply with Mask), а фонарь/обычный свет Style 0 освещают корпус. Сам корпус не излучает свет. Order корпуса 3, трубки 4, стен в двух сценах 2; равного порядка со стенами больше нет. `Bulb` — отдельный прямоугольный sprite с материалом `Materials/Environment/Lighting/HospitalTubeGlow.mat` и шейдером `TubeGlow.shader` (пути относительно Assets/EmergencyShift). Шейдер рисует белое ядро, цветную оболочку и плавно затухающий ореол, без жёстких краёв прямоугольника. Исходное поле эффекта .13 единицы поперёк трубки масштабируется вместе с Fixture; яркое ядро значительно уже. Параметры материала: Core Strength=.9, Tube Strength=.36, Halo Strength=.22. Цвет берётся из существующего SpriteRenderer лампы; один материал работает для холодной и тёплой палитры.

Это местная имитация свечения трубки; пол по-прежнему освещает существующий Light2D радиусом 1.45 и intensity .28. Глобальный bloom не добавлялся. Эффект использует тот же `Bulb`, который включает/выключает LocalLamp2D, поэтому мерцает вместе с лампой. Дополнительных голосов/таймеров или защитных свойств света нет. Настройки экземпляра применяет LocalLampConfiguration2D без собственного Update. Тихий аудиопрофиль сохранён.

Нативные PNG остаются по стабильным путям `Art/Environment/HospitalLampHousings01`: изображения заменены, GUID и Sprite ID сохранены. Полноразмерные оригиналы здесь неизменны, включая alpha; импорт Single с центральным pivot, Bilinear, max size 1024. Ни фон, ни пиксели программно не редактировались.
