# RoomFinish01 — проба отделки тестовой сцены

2026-10-19. Реализовано по запросу владельца; художественная оценка остаётся открытой.

В MorgueRouteTest восемь помещений получили матовый серо-зелёный плиточный бордюр шириной 0.24 unit: 48 отрезков вдоль реальных стен, с разрывами у дверей. Общий prefab `Assets/EmergencyShift/Prefabs/Environment/RoomFinish01/RoomSkirtingStrip.prefab`: длина через SpriteRenderer Size X, ширина через Size Y, вертикальные отрезки повёрнуты на 90°. Повтор плитки 0.6 unit. Библиотечные материалы FlatLit/FlatUnlit и прежние полы сохранены.

Четыре прежних блока сохранили GUID, размеры коллизий и компонентов тени. Их чёрная середина обозначает закрытый объём; внутрь заходить нельзя. Внутренний кант 0.09 unit, снаружи тот же плиточный бордюр. В зале блоки симметричны относительно (26.85,-0.3), в арене выровнены в один ряд с учётом существующих точек появления. Окантовка — дочерняя группа блока и перемещается вместе с ним. Точные позиции — в layout.json.

`MorgueFloorDrain.prefab` — плоская квадратная решётка с рамкой 0.58 unit, семь прутьев, поперечная опора и два крепления. Один прут светлее, как небольшая замена детали. Слив размещён в (-1.25,1.25), в стороне от нового подбора фонаря.

`MorgueMoistureResidue.prefab` — мягкая тёмная плёнка влаги (alpha 0.28) и едва заметный светлый контур высыхания (0.16). Две разные по масштабу/повороту раскладки, северная старее и слабее (65% исходной альфы). Это статичные освещаемые накладки; блеска, анимации воды и скольжения нет. Контур намеренно состоит из неодинаковых смещённых мягких участков, а не правильной окружности.

Все новые детали без Collider2D, ShadowCaster2D, Light2D и пользовательских MonoBehaviour. Новых источников света и теневиков нет; добавлены обычные статичные SpriteRenderer. Общая производительность не измерялась.

create.cs — одноразовый авторинг через открытый Unity Editor, без генерации при Play. Создаёт native Texture2D/Sprite assets и prefab, не перезаписывает готовую семью. Файл приведён к итоговым параметрам; применять к уже оформленной сцене нельзя. Дальнейшая правка — в Inspector и Prefab Mode. Маски влаги и технический рисунок плитки оригинальные, внешних изображений нет.

Previews: Hall-flashlight и Morgue — обычный фонарь; Hall-overview использует временно повышенный общий свет только для проверки композиции. Это не сохранённое освещение игры.
