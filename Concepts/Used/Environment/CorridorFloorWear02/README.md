# Коридорный износ винила · 02

По запросу владельца 2026-10-19 расширена библиотека FloorWear01: тонкий сварной шов, прямые и поворотные контакты колёс, две формы ремонтных вставок. Это геометрически построенные плоские маски, развивающие существующий процедурный подход SurfaceDamage02. Imagegen и внешние изображения не использованы; генерация при игре отсутствует.

`Tools/Art/bake_corridor_floor_wear_02.py` экспортирует пять RGBA PNG в `Sprites` и `Assets/EmergencyShift/Art/Environment/FloorWear01`. Исходник полностью задаёт контуры, seed траекторий, ширины и альфу. Производственные PNG побайтово совпадают с копиями в этой семье. Имеются прямой шов с непрерывными краями, следы с разной длиной контактов и давлением, два ремонта с одним срезанным углом и неброскими местными потёртостями. Тени, блики и объём в рисунок не запечены.

Шестой prefab использует прежний `FloorWear01/castor-scuff.png`; его PNG, GUID и настройки импорта сохранены. Плиточные трещины и сколы не перерисовывались. [Связь с прежней серией](../MorgueFloorWear01/README.md).

`Previews/library.png` показывает библиотеку на ровной подложке; это увеличенный обзор форм. Итоговые игровые кадры `Previews/corridor-west.png` и `Previews/corridor-east.png` сняты в Unity после уменьшения непрозрачности заплат, без коррекции яркости. Геометрическая проверка не означает художественного одобрения владельцем.
