# Карточки доступа 02 — плоские и компактные

Подключены вместо версии 01 по замечанию владельца: убраны объёмная окантовка, глубокие блики и царапины. Матовые спокойные заливки, плоский чип и силуэт портрета. Видимая пропорция около 1.57:1 вместо 2.02:1; при прежней высоте в мире ширина меньше примерно на 22–23%. Финальную художественную оценку выполняет владелец.

- `blue-source.png`, `green-source.png`, `red-source.png` — точные RGBA-выходы встроенного imagegen, без дорисовки/перекраски скриптом.
- `blue-initial-prompt.txt` и `blue-shape-prompt.txt` — два шага синего варианта; промежуточный `Process/blue-flat-wide.png` ещё был слишком широким.
- `green-prompt.txt`, `red-prompt.txt` — отдельные recolor-запросы от финального синего. Геометрия семейств близкая, но генератор не гарантирует побитовое совпадение.
- [provenance.json](provenance.json) — происхождение, SHA-256, размеры и подключение. [Прежний набор](../AccessCards01/README.md) сохранён как история.
- `native-game.png` — фактический Play-кадр MechanicsSandbox 3840×2160. Три верхних образца временные, все карточки HUD раскрыты только на время проверки; Stop удаляет их и тестовое состояние.

Рабочие PNG остаются по прежним адресам `Assets/EmergencyShift/Art/Items/AccessCards01/{blue,green,red}.png`, с прежними GUID. Существующие мировые SpriteRenderer и HUD Image используют те же ссылки. Через TextureImporter изменён только PPU для сохранения видимой высоты в мире; настройки коллизий, подбора, замков, UI-разметка и Runtime C# этой правкой не изменялись.

В общем `Prefabs/Loot/AccessCardPickup.prefab` отключён старый дочерний `Magnetic strip`: прямоугольник от заглушки накладывался поверх готового изображения и выступал за его края. Тело префаба по умолчанию использует существующую зелёную карточку без дополнительного tint, масштаб 1; сценовые варианты сохраняют свои изображения и размеры. PNG не перерисовывались, коллайдер и логика подбора не менялись.

В MorgueRouteTest рядом с двумя карточками размещены небольшие фрагменты из [FleshChunks04](../../Shared/FleshChunks04/README.md), под каждым — два перекрывающихся слоя [BloodPools01](../../Shared/BloodPools01/README.md), с густой серединой. Группа `14 Card owner traces` независима от карточек: плоть и кровь остаются после подбора, отдельно настраиваются через Transform и SpriteRenderer. Это шесть статичных освещаемых спрайтов без коллайдеров и скриптов. [Проверка](../../../../Docs/Validation/AccessCardStripFix.json).
