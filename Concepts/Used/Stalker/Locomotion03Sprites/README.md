# Сталкер: цельные кадры без IK в игре

2026-10-26. По прямому выбору владельца runtime-риг заменён готовыми спрайтами. Область — Сталкер; остальные виды и авторские карты не переводились на новый способ.

## Просмотр

[Локальный просмотрщик](http://127.0.0.1:8797/viewer.html): по умолчанию ходьба 1× на зелёном фоне; есть испуг → отход, ожидание → раскрытие, игровой масштаб и соседние кадры. [Кадры испуга рядом](fear-green.jpg), [зелёная запись 60 кадров/с](green.mp4), [игровой масштаб 15 кадров/с](game.mp4). Для запуска: `python -m http.server 8797 --bind 127.0.0.1 --directory .`. `Frames/` — локальный кэш WebP; `encode_preview.py` создаёт его из исключённых исходных рендеров, а `pack_frame_cache.py` восстанавливает из сохранённых видео.

Это управляемый URP-рендер действующего prefab: 0–2 с ходьба 1.2 units/s, затем реакция/отход 3.8, ожидание, раскрытие, поворот и остановка. `preview-timeline.json` содержит каждый из 480 отсчётов. Проверки реального AI, света, восстановления и сцен находятся в `playmode-results.json`; запись не объявляется свободным прохождением.

## Источник и сборка

Единственный источник кожи/шести лап — Walk00 PaleFlesh, разложенный в Locomotion02. [Скелет](../Locomotion02/skeleton-review.png), [мышечные группы/крепления](../Locomotion02/muscle-review.png), [анатомия и SHA исходника](../Locomotion02/anatomy.json) сохраняются. Новых независимых рисунков состояний нет. `BakeStalkerSprites.cs` собирает 48 равномерных фаз устойчивого цикла, затем 9 степеней поджатия. Корпус и крепления неизменны; костяные длины сохраняются, концы постепенно приближаются к корпусу на 24%. Перенос веса корпуса отключён при подготовке, чтобы отдельный реагирующий глаз имел постоянную анатомическую опору.

`pack_sprites.py` переводит premultiplied alpha GPU-рендера в straight alpha **в линейном цвете**, обрезает тонкие выступы/отделившиеся островки, заполняет малые внутренние отверстия и локальные швы у шести креплений. RGB за прозрачным краем расширяется для фильтрации. Низкая альфа вдали от связного силуэта удаляется: иначе на зелёном фоне остаются почти прозрачные волоски. `alpha-repairs.json` фиксирует изменения каждого кадра; все 432 позы имеют одну видимую alpha-компоненту. Это технический контроль, художественная приёмка остаётся владельцу. Все позы доступны на девяти зелёных листах `Review/closure-*.jpg`; крупные кадры перехода отдельно проверяются в рендере Unity.

Готовые PNG находятся в `Art/Enemies/Stalker/Locomotion03Sprites`: четыре атласа 4096², PPU 224, bilinear, без mipmaps, BC7 на Windows. GPU-данные четырёх BC7-текстур занимают 64 MiB и разделяются между экземплярами; измерение памяти Editor записано отдельно в `preservation.json`. Цена новых кадров — объём изображений, а не личные меши/расчёт суставов. Атласные rect/pivot/хеши — `sprites.json`; имена и spriteID сохраняются повторным импортом.

## Runtime

`StalkerSpriteSet` хранит только неизменяемую матрицу. Личные фаза/отображаемое закрытие принадлежат animator. Фаза продвигается фактическим перемещением: цикл 1 local unit, масштаб экземпляра учтён. Ходьба 1.2/1.5 даёт столько же циклов/с, отход 3.8 — 3.8. При остановке фаза стоит. Поворот сглажен прежним пределом 160°/с; нет дополнительного покачивания всего силуэта.

Испуг больше не выбирает последние два сжатых рисунка по независимому `compactClock`. Один и тот же столбец матрицы сохраняет фазу лап при переходе между рядами; тело поджимается/раскрывается за .24 с. Это только отображение: защита глаза, урон, burn/recoil/retreat и скорости AI не задерживаются. Общий `CreatureSpriteAnimator2D` предоставляет видовую точку выбора кадра, без выбора вида в общих потребителях. Спящий использует прежний путь и прежний общий профиль; Сталкер получил собственный `StalkerSpriteLocomotion.asset`.

Атака/смерть остаются существующими **цельными** рисунками PaleFlesh, без обрезки корпуса и без дорисованных runtime-лап. Отдельные слои большого глаза сохраняют взгляд, веки, предупреждение, ожог и контракт останков. Тени получают тот же целый body sprite. Риг-компонентов в prefab/38 наследующих экземплярах нет. Пять исходников прежнего рига перенесены через AssetDatabase с сохранением GUID в `Editor/Authoring/StalkerSprites`; они нужны только для повторной сборки и отсутствуют в Player assembly. `editor-source-relocation.json` фиксирует отсутствие зависимостей сохранённых сцен/prefab до переноса.

Готовые кадры ограничены записанными позами: свободного мирового контакта IK на произвольном повороте больше нет. Новую плавность/позу добавляют в матрицу и повторно проверяют; не вводят второй runtime-путь для испуга. Переход всей игры на кадровую анимацию этой работой не предусмотрен.

## Воспроизведение и проверка

При остановленном Editor: `BakeStalkerSprites.Bake` → `pack_sprites.py` → `InstallStalkerSprites.Install` → `PreviewStalkerSprites.Capture` → `encode_preview.py`. Unity-команды выполняются через unity-pipeline с явным project path. Инструмент сборки создаёт только изолированную preview scene, установщик сохраняет только профиль/атласы/prefab.

`preservation.json` сверяет 38 авторских актёров с прежним baseline: позиции, масштаб и все gameplay-поля. MainMenu не включается; `playModeStartScene=null`. Итоговый контроль авторинга неприменим: объекты сцен не добавлялись, не перемещались, сцены не сохранялись. Нет внешних загрузок/публикации материалов.

Проверки: 107/107 EditMode и 9/9 PlayMode; тест двух карт отдельно проверяет отсутствие runtime-мешей и постепенный переход к закрытому телу. Windows Release: Succeeded, 0 errors; единственное предупреждение — отсутствие RuntimePipelineConfig, поэтому служебный Pipeline отключён в Player. Console ground truth: 0 errors. Повторная сборка кадров после переноса исходников в Editor воспроизвела контрольный SHA.

Проверка интерфейса просмотрщика встроенным браузером заблокирована его URL policy на странице ошибки доступа. Альтернативный браузерный обход не применялся. Визуальный контроль выполнялся по локальным рендерам/листам; видео и полоса кадров доступны напрямую. Это ограничение не выдаётся за успешную проверку кнопок HTML.
