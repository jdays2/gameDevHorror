# Контур пасти · фильтрация

Исследование отделено от лап и поз. Исходная зарегистрированная пасть Attack03 связна: только 5 пикселей с alpha не выше 6/255 выходят дальше одного пикселя от плотного контура, за двумя пикселями таких точек нет.

Прежняя цепочка Lanczos resize → bicubic placement создавала слабые повторные полосы. В strike09 найдено 183 пикселя alpha 2–5/255 за однопиксельной окрестностью плотной кожи; 66 — дальше двух пикселей. Во всех 24 слоях суммарно 501 такой пиксель за двумя пикселями. Независимая проверка также нашла 20 компонент strike09 при пороге alpha >4, хотя исходный patch был одним.

Положительные BOX area resize → bilinear placement устранили эти выбросы: во всех 24 слоях число пикселей alpha >1/255 за двухпиксельной окрестностью равно нулю. Это смена фильтра переноса исходных пикселей; исходная кожа не обрезалась и не заливалась. Губы, зубы, полость, регистрация и геометрическая траектория открывания сохранены. Альфа и RGB вычисляются в premultiplied linear пространстве.

all24-mouth-kernels-native-green.png содержит каждую пару старый/новый в одном масштабе. strike-XX-old.png и strike-XX-positive.png — замороженные результаты той пробы. После подключения положительных фильтров повторный запуск mouth_resampling_study.py уже не воспроизводит старый вариант автоматически: для истории нужны прежние filter constants, указанные выше. Файл alpha-trace.json относится к старой цепочке, kernel-comparison.json — к замороженному сравнению.

Проверка новой пасти на реальном корпусе, трёх фонах и по связности всех 24 слоёв находится в CandidateAudit/ActualHeldOut04/positive-mouth-components.json и positive-mouth-native-green-dark-light.png. Это отдельный материальный контроль, не приёмка всей атаки или её игрового перехода.
