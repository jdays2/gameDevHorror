# Контролируемое исправление исходного обрывка RM

Сохранены 432 исходные позы в состоянии до новой коррекции дорожек (`poses-before.json`) и исходный whole PNG `whole-before-0-00.png`. По ним повторно отрисованы те же 16 поз, что в первоначальном Preview16.

Очистка выполняется **на original full limb до сегментации и deformation**. В проксимальной области source (радиус root+30px) тонкая перемычка отделяется локальным opening 3px; сохраняется главная связная компонента цепи, возвращается 1px антиалиасинга. За пределами исходной проксимальной зоны альфа не меняется. Ни runtime цель, ни пересечённая готовая лапа не обрезаются.

Из исходных 358×406 слоёв удалено: RF14px (11 непрозрачных), RM60px (47 непрозрачных), LM2 полупрозрачных пикселя и LR2 непрозрачных пикселя тонкой кромки. LF/RR — 0. Точные числа и границы — [source-cleanup.json](source-cleanup.json). [Красная накладка](source-dirt-removed-red.png) показывает конкретный случайный лоскут на нитке под RM; настоящая мышечная масса и основной ствол сохранены. Изображение просмотрено вручную.

Повторная проверка **того же набора поз**: суммарные отделённые пиксели alpha>4 уменьшились **161→0**. Крупное пересечение RF/RM осталось **1063px**, поэтому очистка не спрятала дефект позы. Все данные повторной проверки — [RepaintQA/qa.json](RepaintQA/qa.json). Новый geometry export должен проходить отдельный аудит.
