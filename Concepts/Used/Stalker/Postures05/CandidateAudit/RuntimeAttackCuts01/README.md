# Прерванная атака: независимая проверка до исправления

**FAIL временного перехода**, отдельный от завершённой проверки статических рисунков. Лично открыты исходные PNG 1339–1342 и 1406–1409 размером 640×640 без изменения масштаба. Исходный профиль: `MechanicsSandbox-stalker-20hp-default-stationary-990b0376`, сохранённый root в `../../Scenarios/stalker-interruption-before/`.

- Case 27: 1340 `strike-10` → 1341 `body-0-15`, Attacking → Sneaking/staggered. За 1/60 секунды пасть полностью исчезает, передние лапы перескакивают в обычную фазу. Attack .4375 →0 при неизменной phase .327422857. Relative endpoint jump LF 61.68 px / RF 72.71 px; world knockback не включён в эти числа.
- Case 28: 1407 `strike-10` → 1408 `body-1-05`, Attacking → Recoiling. Attack .4375 →0, fold 0 →.06944 при неизменной phase .108184576. Правая передняя лапа сразу становится горизонтальной у глаза, а пасть закрывается. Relative endpoint jump LF 23.71 px / RF 131.89 px. World position тоже неизменна.

PPU224, scale1, локальные position/scale/rotation тела одинаковы; причина — выбранный whole sprite при отмене атаки. Это не неправильный pivot, масштаб или разрез кожи. Координатные числа — проекция поз относительно корпуса при camera PPU193.939; они не являются измерением контура из PNG. Сам скачок подтверждён исходными пикселями.

В [attack-state-cuts.json](attack-state-cuts.json) сохранены метаданные до/после, точные source SHA и endpoint deltas всех шести лап. Два листа `*-native640-neighbours.png` сохраняют четыре соседних полных кадра без подгонки масштаба. Сравнение текущего attack sample с return-00 важно: return-00 уже имеет закрытую пасть, поэтому простая подмена на него не устранит mouth pop.

Требуется визуальный выход от реально показанного attack sample целыми кадрами, при немедленном gameplay-прерывании. Unity и runtime-код здесь не менялись. Исправление и новый capture выполняет основной агент; до фактического повторного просмотра этот временной gate остаётся открытым.
