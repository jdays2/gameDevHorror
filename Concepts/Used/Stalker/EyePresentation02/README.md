# Глаз: один зрачок и ожог

[Превью](preview.png): взгляд влево, по центру, вправо и повреждённый глаз. Рендер изолированной Unity URP preview scene.

Текущая обработка ожога — [EyeBurn03](../EyeBurn03/README.md); описанный ниже сплошной красный множитель заменён по замечанию владельца. Размер/единственный зрачок и правила состояния сохраняются.

2026-10-17. По замечанию владельца исправлена композиция: кадры тела содержат прежний неподвижный зрачок, а отдельный слой рисует подвижный. В обоих prefab под новым iris добавлена непрозрачная круглая подложка из существующего native EyeDisc, чтобы рисунок тела не участвовал в изображении нового зрачка. Это техническая композиция слоёв; исходные PNG/анатомия не перерисовывались.

Порядок внутри Visual: Body 0, Eye backing 1, Eye iris 2, Eye pupil 3. Подложка диаметром 0,20 units, цвет (0,84; 0,76; 0,75; 1). Единственный подвижный зрачок увеличен с 0,082 до 0,13 units; ход центра прежний 0,045. Общий EyeDisc не изменён: используется также другими эффектами. Подложка/iris/зрачок скрываются при смерти и silent restore.

Stalker.EyeBurned становится true при достижении существующего порога болезненной реакции на направленный свет. Раздражение до порога, обычная близость и попадание сами по себе глаз не краснят. Generic renderer получает только HasEyeDamage из видового адаптера и умножает исходный цвет iris/подложки на (0,72; 0,24; 0,20; 1). После выключения света и открытия века красный повреждённый вид сохраняется. Флаг индивидуален и входит в snapshot; у старого снимка без поля значение false. AI/агрессия/дистанции не изменены. Спящий использует увеличенный зрачок/подложку, но не получает видовой ожог Сталкера.

Источники: прежние EyeDisc.asset и LargeEye01/eye-atlas.png, их GUID сохранены. Изменены компоненты двух prefab и представление; сценическая расстановка сохранена. [Проверки](../../../../Docs/Validation/EyePresentation02.json). Результат внешнего вида оценивает владелец.
