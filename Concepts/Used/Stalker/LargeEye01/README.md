# Сталкер: увеличенный глаз

2026-10-17. Владелец попросил увеличить глаз существующего светочувствительного Сталкера относительно нового Спящего. В `ShadowStalker.prefab` подключён нарисованный глаз с мембраной: открытый, полузакрытый, щель, закрытый. Это уже используемый визуальный слой; художественная оценка ещё за владельцем.

Глаз отделён от тела, чтобы сохранить принятую ходьбу, ноги и GUID всех кадров. `StalkerSpriteAnimator.eyeFrames` повторяет выбор четырёх recoil-кадров; ходьба и атака используют открытый глаз. Закрытый орган остаётся виден, поэтому не проявляется прежний маленький глаз. Подвижный зрачок рисуется отдельно, исчезает при закрытии; смерть/восстановление останков скрывают оба слоя. Пустой массив сохраняет прежнее включение/выключение iris. Общий `EyeDisc.asset` не менялся: он также используется кровью.

## Файлы и воспроизведение импорта

- [eye-atlas.png](eye-atlas.png) — исходный результат встроенного `image_gen.imagegen`, RGBA 1254×1254, сохранён без перерисовки, ресайза или очистки альфы. [Полный промпт](prompt.txt), [источники и параметры](provenance.json).
- Рабочая копия: `Assets/EmergencyShift/Art/Enemies/Stalker/LargeEye01/eye-atlas.png`. Unity: Sprite/Single, Bilinear, sRGB, alphaIsTransparency, без mipmaps/сжатия, NPOT None, max 2048.
- Четыре внешних native Sprite-ассета: EyeOpen, EyeHalf, EyeSlit, EyeShut. Rect ниже — Unity bottom-left; одинаковые размеры, PPU 1160, pivot (0.5, 271/560), FullRect. Рамка вырезается координатами Sprite, PNG не меняется.

| Sprite | Rect x/y/w/h |
|---|---|
| EyeOpen | 32 / 650 / 560 / 560 |
| EyeHalf | 659 / 650 / 560 / 560 |
| EyeSlit | 32 / 24 / 560 / 560 |
| EyeShut | 659 / 24 / 560 / 560 |

Непрозрачный наружный контур около 511 px / 1160 ≈ 0.44 Unity units; полный Sprite rect шире за счёт прозрачного поля. Iris scale=1 и белый tint. Первоначально зрачок использовал EyeDisc: scale=0.082, ход центра=0.045. Текущая коррекция увеличивает его до 0.13 и добавляет непрозрачное перекрытие старого зрачка тела; поверхность и слежение описаны в [EyeSurface05](../EyeSurface05/README.md). В видимом кольце есть небольшие неровности складок; одинаковая регистрация четырёх состояний нужна для анимации, а не для стерильности формы.

## Проверка

[Превью URP](unity-preview.png): сверху прежний глаз, новый, взгляд влево и вправо; снизу полузакрытие, щель, закрытие, прежняя смерть. [Атака и ходьба](unity-attack-preview.png): attack 0–5, walk 6–7. Рендеры собраны из настоящих Unity Sprite/материала FlatLit в изолированной несохраняемой preview scene при ровном глобальном свете. Это просмотр арта, не кадры обычного освещения уровня.

Исторический просмотр проверял увеличение глаза, перекрытие старого века, ноги и пасть; он не исключил просвечивание прежнего зрачка тела надёжно. Замечание владельца исправлено в EyePresentation02. В реальном Play временный экземпляр прошёл 29 проверок представления: ходьба, атака, четыре стадии, отход/ожидание, слежение, legacy без массива, смерть и RestoreDead. Состояния для этой проверки задавались напрямую; это не повтор полного AI-регресса. Итоговые тесты/сборка и сохранность сцен — в [отчёте](../../../../Docs/Validation/StalkerLargeEye01.json).
