# Сталкер: локальный ожог глаза

Историческая проба: заменена [GradualEyeBurn04](../GradualEyeBurn04/README.md) — постепенный бледно-чёрный ожог. Параметры ниже относятся к прежнему состоянию.

2026-10-17. Замена сплошной красной заливки из EyePresentation02 по замечанию владельца. [Превью](preview.png): здоровый глаз, повреждённый открытый, полузакрытый и закрытый. Это рендер настоящих Unity Sprite под URP 2D светом; художественный результат оценивает владелец.

В повреждённом состоянии сохраняется исходный рисунок глаза: приглушение насыщенности и затемнение дополнены двумя разными мягкими участками покраснения. Более крупный участок находится слева сверху, меньший — снизу справа; границы слегка неровные и не двигаются. Вне участков нет красной заливки. Цвет умножается на исходную текстуру, не заменяет её плоским цветом. Альфа, UV, контур и анатомия не меняются. Pupil остаётся отдельным подвижным слоем; серо-коричневая подложка перекрывает прежний зрачок тела.

`Materials/stalker-eye-burn.mat` / `LocalizedEyeBurn.shader`: Darkening 0,38; Desaturation 0,25; BruiseStrength 0,65; BruiseTint (0,9; 0,55; 0,48; 1); EyeRadius 0,22 units в геометрии Sprite. Маска привязана к локальным координатам органа, поэтому расположение повреждений одинаково для четырёх atlas-кадров закрытия. Shader использует штатные URP Lit2DCommon/Normals2DCommon и обычное освещение; собственного свечения нет.

`CreatureSpriteAnimator2D` выбирает общий материал повреждения по HasEyeDamage, сохраняя исходный цвет входа iris. При здоровом snapshot возвращает исходный материал. Shared material не меняется и не клонируется на каждого врага. На подложке используется нейтральный fallback (.64; .60; .60; 1). Материал назначен только Сталкеру; Спящий не получает ожог Сталкера. Сам флаг EyeBurned, его порог и сохранение не менялись.

Исходные PNG LargeEye01 и их GUID сохранены. Изображения не генерировались и не редактировались. Источник стандартных include: установленный Unity URP `com.unity.render-pipelines.universal@2309ae255609`; общий контракт рендера соответствует локальному Sprite-Lit-Default.shader. Собственные форма маски/цветовая обработка — `LocalizedEyeBurn.shader`. [Технические проверки](../../../../Docs/Validation/EyeBurn03.json).
