# Восстановление существ и единый слив · BUG-006/007

2026-10-22. По прямому поручению владельца восстановлены изображения до упрощения `aa1a9dc`: 38 PNG, включая 10 атласов тела/глаза и 28 корпусов/фрагментов. Пиксели побитово скопированы из `SimplifiedArt01/Historical`; новые варианты не рисовались. Сталкер сохраняет серо-розовую плоть, Спящий — холодную палитру, светлый глаз и локальную кровь. Спящий возвращён к принятой временной основе StalkerPlaceholder01/BloodMarks02; отклонённая «Тренога» из Unused не внедрялась.

[images.json](images.json) содержит адреса/GUID, SHA исходных и заменённых изображений, исторический источник и прежний предел импорта. [native-sprites.json](native-sprites.json) — исходные параметры 76 native Sprite: прямоугольник, pivot, PPU, GUID. Базовые prefab врагов, общие материалы, профили/IDs/форматы снимков, количество и порядок кадров/фрагментов не менялись. Сцены наследуют обновлённую библиотеку, ручные overrides сохранены. Изображения исключены из активного recipe упрощения; окружение, кровь и полы этим восстановлением не перерабатывались.

## Слив

Существующий `Prefabs/Environment/RoomFinish01/MorgueFloorDrain.prefab` сохранён с тем же GUID. Вместо 13 SpriteRenderer под корнем — один SpriteRenderer на корне, без дочерних объектов. PNG 256×256, прозрачный холст 0.64 unit/PPU 400, видимая рамка 0.58 unit. Рисунок запечён из исходной сборки в Unity с FlatUnlit, без света сцены; итоговый prefab использует общий FlatLit и реагирует на локальный свет. Нет коллизии, теневика, нового runtime-компонента, лампы или звука. Слой сортировки Default, порядок −5.

[drain-source.json](drain-source.json) сохраняет геометрию/цвет/порядок исходных деталей. Запекание — консолидация существующего рисунка, не новый художественный вариант. Для других уровней использовать тот же prefab; transform и tint настраиваются в Inspector, влажность и кровь добавляются отдельными накладками. Не создавать новые копии текстуры для каждого экземпляра.

## Проверка и воспроизведение

Одноразовые Editor entry points вне Assets: `AgentScripts/RestoreCreatureArtwork.cs` (`Inspect`, `Restore`, `InspectAfter`), `BakeMorgueDrain.cs` (`Bake`, только до появления готового PNG), `ReviewCreatureArtwork.cs` (`VerifyAndRender`, `CaptureAuthoredDrain`). Вызов — Unity Pipeline `run_script --file … --entry Class.Method`; перед работой остановить Play. Это явные миграционные инструменты, не генераторы при запуске игры. `Restore` перезаписывает только перечисленное семейство по поручению владельца; не запускать поверх будущей художественной правки без сверки источников. Batch-импорт не заявлен атомарной транзакцией.

Восстановление подтверждено SHA; нативно проверены GUID/crops/pivots/PPU всех 76 Sprite и повторное создание prefab. Текущий снимок и ограничения — [CreatureRestoration45](../../../../Docs/Reports/CreatureRestoration45.md). Картинки в отчёте: исходное сравнение, нативные позы и игровой размер, повторное использование люка, свет комнаты и отдельная временная проба луча. Ровное освещение таблицы поз не является освещением уровня; позы там выставлены явно. Художественная оценка обоих врагов остаётся владельцу.
