# Когтистый · текущая визуальная библиотека

Источник — [FastGroupEnemy23AssetPack](../../../Unused/Visual/FastGroupEnemy23AssetPack/README.md), production — `Assets/EmergencyShift/Art/Enemies/ClawVisual`, клипы/контроллер — `Animations/Enemies/ClawVisual`, префаб — `Prefabs/Enemies/ClawVisual.prefab`. Молчаливый набор без назначенной игровой механики. [Контракт](../../../../Docs/Enemies/CLAW_PROTOTYPE.md).

`import-manifest.json` фиксирует SHA256 фактических производственных файлов и исходные кадры. Unity создаёт .meta/GUID, при повторном импорте сохраняются ID спрайтов по имени. Общий FlatLit повторно используется. Исторический [ClawPrototype01](../ClawPrototype01/README.md) относится к старому тестовому AI и графике; пользовательские сцены автоматически не заменялись. Used означает применение в prefab-ассете, не художественную приёмку всех материалов.
