# Глаз и останки · BUG-047

Внедрённая проба от 2026-10-24 по прямому поручению владельца. Художественная приёмка ожидается. [Технический контракт и кадры](../../../../Docs/Reports/MonsterEyes03.md), [основная карточка](https://app.notion.com/p/4038d6dc06b6817d8f50c0e84c80608e).

Три фотографии владельца сохранены без обработки в [архиве обсуждения](../../../Unused/Visual/MonsterEyesReview01/References/); [происхождение](../../../Unused/Visual/MonsterEyesReview01/provenance.json). Файлы не копировались в Assets. Источник/автор/лицензия фотографий владельцем не сообщены. Использованы как ориентир молочной мутности поверх радужки и зрачка и раздражённой периферии.

Изменены существующий LocalizedEyeBurn.shader/материал, масштаб зрачка двух prefab, световые профили Сталкера и два GoreProfile. Новый общий remains-eye-cloud.mat обслуживает неподвижную поверхность отделённого глаза. Новых растровых генераций/перерисовок нет; исходные кадры, GUID и принятые палитры сохранены.

Дополнительные фрагменты без глаза используют прежние TornFlap, MuscleWad, TissueStrip, DenseClot из CreatureFlesh04: кровавые обрывки мягкой ткани. Это не конечности; число суставчатых частей внутри каждой пары прежнее. Исходники и обработка — [плоть 05](../../Stalker/Remains04/README.md) и действующая библиотека `Assets/EmergencyShift/Art/Effects/CreatureFlesh04`.

Превью сделаны через настоящий URP Game View в Play, без сохранения пробных объектов в карту. Глаз осмотрен крупно и в игровом масштабе, останки обоих видов — рядом с живыми при одинаковом свете. Эти кадры подтверждают внедрение, но не заменяют оценку владельца.
