# Упрощённая матовая графика 01

Рабочая замена детализированной графики по поручению владельца от 2026-10-18. Эталон — принятые компактные карточки доступа 02: крупные цветовые области, спокойные тона, читаемый силуэт без микрофактуры, влажных бликов и глубокого нарисованного объёма. [Правила направления](../../../../Docs/ART_DIRECTION.md) применяются и к следующему контенту. Подключение выполнено; художественную оценку результата даёт владелец.

| Группа | Заменено PNG |
|---|---:|
| Окружение, мебель, оборудование, светильники, декоративные останки | 42 |
| Атласы тела и глаза двух врагов | 10 |
| Туши, фрагменты плоти и конечности | 28 |
| Лужи, капли и смазы крови | 25 |
| Всего | 105 |

Проверены все 143 рабочих растровых изображения: 105 заменены, 25 уже плоских ресурсов сохранены (16 масок напольной краски, 6 ресурсов HUD, 3 карточки). 13 текстур пола исключены владельцем и побитово сохранены. Также проверены 8 нативных Texture2D: простые формы и функциональные маски света, без объёмной фактуры.

- `Sources/Art/…` — точные финальные RGBA-выходы встроенного imagegen. Пиксели не перекрашивались и не фильтровались скриптом.
- `Historical/Art/…` — прежние рабочие PNG перед этой заменой. Их детализация не служит актуальным эталоном.
- `Prompts/Art/…` — запросы генерации, включая цепочки корректировок.
- [provenance.json](provenance.json) — полный перечень, SHA-256, GUID, происхождение, сохранённые ресурсы и изменения нативных спрайтов.
- [Processing](Processing/README.md) — воспроизводимые настройки импорта и снимки параметров Sprite до/после миграции.

Адреса и GUID сохранены, как и local fileID нативных Sprite. Через Unity API скорректированы PPU, границы кадра и pivots для изменившихся холстов; небольшие изображения ограничены по размеру импорта. Видимые фрагменты вписаны в прежние габариты, сохранён центр видимой формы. Контур маленького `Sleeper/Gib05` немного изменился; это художественная замена, а не побитовое сохранение силуэта. Для полупрозрачной крови габариты измеряются по alpha ≥16, для твёрдых объектов — по alpha ≥128. Сетка и число кадров анимации сохранены.

Ручная расстановка сцен, коллизии, игровой код, звук, события и форматы сохранений этой работой не менялись. Прежние семейства в Concepts остаются историей происхождения и технического устройства.
