# Подключение изображений и параметры спрайтов

Исходные PNG копируются из `Sources/Art/…` в `Assets/EmergencyShift/Art/…` без изменения пикселей и без замены `.meta`. `import-recipes.json` содержит размеры и alpha-границы прежних/новых изображений, исходные GUID и PPU; `native-sprites-before.json` — исходные прямоугольники, pivots и PPU нативных Sprite. `native-sprites-after.json` фиксирует подключённое состояние.

`ApplySpriteMetadata.cs.txt` — тело разовой команды в контексте Unity Editor. Это архив процесса вне Assets, не игровой компонент и не автоматический генератор сцен. Требуется доступ к UnityEditor API и Newtonsoft.Json. Работает только в EditMode, после копирования изображений. Проверяет GUID, обновляет TextureImporter, создаёт временный Sprite и копирует сериализованные данные в существующий нативный ресурс через `EditorUtility.CopySerialized`; сохраняет только изменённые ресурсы через `SaveAssetIfDirty`. Повторение с тем же реестром не должно менять параметры повторно.

- Single sprites: PPU компенсирует изменение видимого габарита, если оно больше 2%; соединяемые горизонтальные трубы масштабируются по длине.
- Нативные Sprite на отдельных изображениях: границы и PPU учитывают фактический импортированный размер. Максимум отношений ширины/высоты alpha-границы вписывает изображение в прежний видимый габарит. Pivot компенсирует изменение центра видимой области. Кровь измеряется по alpha ≥16, твёрдые предметы и останки — по alpha ≥128.
- Атласы: прямоугольники пересчитываются пропорционально холсту; PPU меняется на средний коэффициент размеров. Разметка кадров и нормализованный pivot сохраняются.
- Для малых нативных текстур maxTextureSize ограничивается следующей степенью двойки от исходного размера (64…2048). Полы и уже простые ресурсы в реестр замены не входят.

Команда не сохраняет сцены, не меняет расстановку/коллизии, профили врагов или игровые состояния. Не запускать её автоматически после ручной правки новых Sprite: это снимок данной миграции, а не постоянно действующий импортёр. Для следующей редакции сначала сохранить актуальные параметры и обновить реестр.
