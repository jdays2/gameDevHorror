# Спящий: временная копия Сталкера

По решению владельца 2026-10-17 разработка отдельного дизайна остановлена. Заглушка использует точные копии существующих спрайтов Сталкера с холодной серо-зелёной палитрой. Формы, детали, альфа, размеры, сетки, pivots и состав кадров не менялись. Красная кровь сохранена.

Unity: `Assets/EmergencyShift/Art/Enemies/Sleeper/StalkerPlaceholder01`. Все кадры ходьбы, сжатия, атаки, смерти, фрагменты и четыре века скопированы с отдельными GUID. `animation-map.json` задаёт соответствие сна/пробуждения/активности и ссылается на четыре новых звука Спящего в `Assets/EmergencyShift/Audio/Sleeper/Voice01`.

Существующий Сталкер не изменён. Следующей задачей подключены отдельный Sleeper2D, новые звуки и тестовые экземпляры; поведение и настройка описаны в [документации](../../../../Docs/Enemies/SLEEPER.md). Это временный комплект представления, не принятие прежнего трёхчастного дизайна. Художественная оценка принадлежит владельцу. Старый эксперимент сохранён в Unused и остановлен.
