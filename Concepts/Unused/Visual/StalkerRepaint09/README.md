# Новый Сталкер и четыре анимации

Готовый самостоятельный набор для просмотра находится в Delivery. Архив Stalker-new-animations.zip содержит88 цельных PNG576²: движение24, засыпание16, пробуждение16 и атака32; четыре листа, GIF/APNG, animations.json и автономный viewer.html. Внутри каждого состояния все фазы различаются; общие нейтральная/спящая позы дают84 уникальных RGBA по всему набору.

Новый master создан встроенным ImageGen по исходному розовому Сталкеру до рига. Последовательные проверки статического рисунка: кости, объёмы,22 функциональных агрегата/крепления, кожа. Перегенерация целых AI-листов R1–R3 не выдерживала позу/масштаб и не вошла в конечную анимацию. Конечные фазы собраны ранее предложенным владельцем способом перекрывающихся жёстких элементов из нового master; фазы века взяты из ImageGen. Пиксели кожи не растягивались/не деформировались UV. Выполнена точечная ретушь стыков и альфа-масок, подробные координаты сохранены в Docs/Validation/Task007Repaint09/Delivery/seam-retouch.json.

Перед объёмами просмотрены костные контактные листы всех88 фаз и native-окрестности суставов сна/атаки. Затем отдельно просмотрены объёмы и состав мышц всех88 фаз;22 постоянных ID, O/I и сухожилия сохраняются, alpha-проверка креплений без flags. Это ограниченная инженерная2D-модель, не медицинская/3D-кинематическая или физическая верификация. Крупные источники и rejected-пробы сохранены.

Финальные PNG проверены по H/J/T, прозрачным полям и единой alpha3-компоненте во всех88 кадрах. Все листы и декодированные APNG совпадают с видимым RGBA кадров точно; APNG содержат24/16/16/32 кадров с длительностями900/900/900/560ms. Синтаксис автономного просмотрщика проверен. Итоговые четыре состояния и точечные стыки осмотрены отдельно. Нативный realtime/gameplay не заявлен; при сильном увеличении возможна читаемая граница исходного контура суставов.

Все20 проверок прежних исходных листов/раскладки/16 ключей двух видов пройдены точно. Unity, игровые Assets и сцены не менялись, новый серо-зелёный набор Спящего не создавался. Авторинг сцены неприменим. Художественную приёмку выполняет владелец; полная TASK-007/BUG-054 остаётся в работе.


## Отклонено владельцем · 2026-11-04

Владелец отклонил весь слойный результат за стыки, неровности и неаккуратность. Delivery не принят и не используется для следующей анимации. Численные проверки выше не доказывают художественную цельность. Последнее поручение исключает нарезку/сборку частей и программную дорисовку: новые подробные цельные кадры создаются и перегенерируются ImageGen по неизменным костным и мышечным схемам. Базовое воспроизведение исходных цельных кадров восстановлено отдельно.
