# TASK-005 · Скорпион · native-r3

Новый быстрый групповой враг в визуальной семье Сталкера: восемь опорных ног, две большие передние клешни, массивный шестизвенный хвост, десять чёрных глаз. Групповой бой — роль по заданию владельца; текущий результат — рисунок, быстрый бег и атака, без боевого AI и звука. [Полный контракт](../../../../Docs/Enemies/SCORPION.md).

Редакция r3 выполняет уточнение владельца: более крупные и грозные клешни атакуют перед головой, в беге попеременно клацают. Два пальца имеют отдельный шарнир: подвижная часть жёсткая и не тянет фактуру ладони при закрытии. Хвост расширен в1.65 раза без изменения числа/длины звеньев. Новая голова — более тупая передняя корона с десятью глазами. Старый вариант сохранён в `history-r2/`.

Каркас объявлен до привязки источников: `native-plan.json` и четыре независимые проекции → `03-native-bones-on-skin.jpg` → `04-native-volumes.jpg` → `05-native-muscle-ids.jpg` и39 функциональных агрегатов в `functional-groups.json` → чистая поверхность → анимация. Статусы фактического просмотра — `inspection.json`; художественная приёмка остаётся false. Геометрия задаёт проектные высоты, не измеряет скрытые кости по PNG.

Полные генерации v1–v4 не прошли отдельное наложение скелета и не были объявлены пригодными мастерами. Итог собран в собственном модульном риге: сохранённый снимок поверхности ног Сталкера в `sources/stalker-atlas.png`, отдельное тело, UV-кожа клешней/хвоста из v3. `source-attachments.json` — координаты текстуры, не подогнанный задним числом каркас. Новое тело r3 изменено встроенным image_gen, точный промпт и исходник — `r3-generation.json`; ранние генерации — `provenance.json`. Пользовательский риг Сталкера и его источники не редактируются этой сборкой.

`build_native.py --plan` сохраняет каркас, без аргументов собирает нейтраль и костное наложение; `--volumes`, `--muscles` — отдельные проверки; `--frames run|attack` рендерит24/16 кадров после проверок. `finish_assets.py` проверяет опоры/длины/замыкание и упаковывает готовые кадры. Нужны Python, NumPy, Pillow; пути разрешаются от самого скрипта. Локальная защита от складывания поверхности фиксирует суставные пины и кости, корректирует только свободные вершины. Это не симуляция физических сил.

Экспорт: Run24×15 ms, минимум четыре опоры; Attack16кадров/.665 s, восемь опор. Production: `Assets/EmergencyShift/Art/Enemies/Scorpion`, `Animations/Enemies/ScorpionVisual`, `Prefabs/Enemies/ScorpionVisual.prefab`. Runtime получает цельные PNG-кадры; переключение — Animator `Motion`:0Idle,1Run,2Attack. Событий урона нет. Историческое имя Unused сохранено ради скриптов, фактический импорт — [Used/Scorpion01](../../../Used/Visual/Scorpion01/README.md).

`python serve_review.py` открывает только два семейства и их производственные PNG на127.0.0.1:8103. [Просмотрщик](http://127.0.0.1:8103/Scorpion01/viewer.html): три/одна особь, бег/атака, пауза, кадр, скорость, два фона, крупный вид. Скорость демонстрации2.4unit/s не является утверждённым игровым балансом. Клипы не реализуют автоматический переход из произвольной фазы бега в атаку. Новых останков Скорпиона и полного поведения вида в этом наборе нет.
