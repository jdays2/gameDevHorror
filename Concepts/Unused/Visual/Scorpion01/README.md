# TASK-005 · Скорпион · native-r5-compact

Восемь опорных ног, две компактные клешни с широкой ладонью и короткими хватательными концами, пять сегментов хвоста плюс луковица/жало, десять красных светящихся глаз. Сдержанная серо-зелёная кожа, крупные кровавые мазки. [Текущий контракт](../../../../Docs/Enemies/SCORPION.md).

Бег сохраняет спокойный почти закрытый хват. Атака32кадра/.56s продолжает два цикла шага и в просмотрщике снижает скорость примерно на21%, без остановки. Сценарий сближения с мишенью — художественная демонстрация. По уточнению владельца AI и урон пока не подключены.

Каркас `native-plan.json` объявлен до привязки новых частей: независимые проекции → `03-native-bones-on-skin.jpg` → `04-native-volumes.jpg` → `05-native-muscle-ids.jpg`/40 функциональных агрегатов → чистая кожа → кадры. Статусы фактического осмотра — `inspection.json`, приёмка владельца не подразумевается. После найденного пересечения передней ноги с клешнёй изменено проектное положение рук и повторены проходы. В каждом кадре проверяется отдельная альфа клешней/опорных ног, затем осматривается композиция.

`scorpion_parts_r5.py` — текущая независимая конструкция компактной клешни, жёсткое сочленение ладони и подвижного пальца, подготовка UV. `r5-native-registration.json` отделяет точки рисунка от неизменяемой в анимации геометрии. Первые полные AI-концепты v1–v4 не прошли скелетный проход и мастерами не стали. Новый рисунок клешни — источник поверхности, собранный по нативному макету, не анатомическое одобрение сырого генерата. Снимок поверхности ног Сталкера хранится локально; исходники и runtime Сталкера этой сборкой не меняются.

Кожа/кровь: `body-source-r5-blood.png`, `chela-r5-blood-paint.png` → `chela-source-r5.png`. Хвост и спокойная поверхность ног сохранены изr4. Встроенный image_gen, точные промпты и роли референсов — `r5-generation.json`. Реальный скорпион пользователя использован только как анатомический референс, пиксели stock-иллюстрации не копировались. Эмиссия использует прежнюю маску глаз до крови, поэтому новые мазки не излучают свет. Ранние состояния сохранены вGit и `history-r2/`, `history-r3/`, `history-r4/`; `scorpion_parts.py` — историяr4.

Воспроизведение из этой папки (Python, NumPy, Pillow):

```text
python scorpion_parts_r5.py
python build_native.py --plan
python build_native.py --prepare-r5
python build_native.py
# Осмотреть костное наложение, затем каждый следующий проход отдельно.
python build_native.py --volumes
python build_native.py --muscles
# После осмотра кожи и актуализации inspection.json:
python build_native.py --frames run
python build_native.py --frames attack
python finish_assets.py
python serve_review.py
```

Run24×15ms; Attack32×18/17ms. Конечные длины и минимум четыре опоры сохраняются. Локальная защита от складывания UV корректирует свободные вершины, суставные пины остаются неподвижны. Производственные кадры — цельные PNG, живой IK в Unity нет. `finish_assets.py` проверяет контакты, длины, границы ячеек, пересечения клешней с ногами и согласование границ Attack/Run. Эти проверки не измеряют FPS.

[Просмотрщик](http://127.0.0.1:8103/Scorpion01/viewer.html?revision=compact-r5) обслуживает только два визуальных семейства и их production PNG на loopback. Клешни движутся вместе с поступательным движением в режиме сближения; пауза/кадр позволяют рассмотреть захват. Production: `Art/Enemies/Scorpion`, `Animations/Enemies/ScorpionVisual`, `Prefabs/Enemies/ScorpionVisual.prefab` под `Assets/EmergencyShift`. Импорт только этого семейства: `BuildCreatureVisuals.BuildScorpion`. Сохранены GUID, два renderer, нет AI/коллизий/звука. [Used/Scorpion01](../../../Used/Visual/Scorpion01/README.md).

`r5-first-placement-rejected.json` хранит отклонённую расстановку рук до исправления пересечения. `history-r4/` содержит нейтраль, схему и снимок метаданных, а не самостоятельный production-набор всех прежних клипов.
