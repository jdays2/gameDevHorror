Текущий исправленный статический источник — **base-v3.png**: убран только лишний пятый коготь нижней задней стопы. Сохраняются маленькая опущенная голова, короткая туша, длинные передние лапы и изогнутые когти выбранного рисунка.

Художественный выбор исходника не означает авторскую приёмку анимаций.

## Что проверено

1. До анимаций объявлен новый пространственный `anatomy-plan-v4.json` для явно выбранных новых пропорций; проверены длины парных сегментов и проектные контакты четырёх подошв. Старый FAIL v2 относительно прежнего каркаса v3 сохранён в `bone-verdict-v2.json`, а не переименован в PASS.
2. На `base-v3.png` отдельно просмотрены кости, затем объёмы, затем 22 функциональные мышечные группы и направления/зоны крепления. Итог: `base-v3-validation.json`. Эллипсы — грубые зоны, местами выходящие за кожу; скрытые мышцы, точные 3D-крепления, центр массы и нагрузка не восстановлены по PNG.
3. До генерации листов подготовлены шесть фаз бега и шесть фаз атаки с неизменными 3D-длинами. `phase-plan-review-v4.json` проверяет только проектные схемы, не получившуюся анимацию.
4. Каждый художественный вариант сначала проверялся только костным наложением. После FAIL мышечный проход останавливался. Допуски зафиксированы до просмотра V2 в `animation-qa-thresholds-v2.json`; под рисунки их не расширяли.
