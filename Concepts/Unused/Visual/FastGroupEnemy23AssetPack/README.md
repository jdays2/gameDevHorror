# TASK-005 · завершённый визуальный набор Когтистого

Текущий дизайн J: восемь глаз и одна закрытая пара жвал. Новый набор импортирован в `Assets/EmergencyShift/Art/Enemies/ClawVisual`, клипы — `Animations/Enemies/ClawVisual`, префаб — `Prefabs/Enemies/ClawVisual.prefab`. Это молчаливая визуальная библиотека без AI/здоровья/урона/звука. [Контракт и значения Motion](../../../../Docs/Enemies/CLAW_PROTOTYPE.md).

Walk: 24 × 65 ms, умеренная работа корпуса, минимум три опоры, один цикл задних ног на передний; тот же фиксированный риг F21. Run — точные 24 исходных PNG выбранного F21 BodyMotion R2; Sweep — 18 исходников F22; при упаковке они только уменьшены вдвое. Hit — шесть кадров за170 ms, четыре неподвижные опоры, короткая отдача корпуса и возврат в нейтраль. Три новые статичные композиции A/B/C сохраняют предыдущий состав останков и обновляют голову до J.

Порядок проверки: независимые `01-*-independent-bones.jpg` → `review/*-bones.jpg` → volumes → muscles с ID/креплениями → чистая кожа на двух фонах → все кадры/геометрия → Unity. Отчёт — `technical-validation.json`. Для оторванной лапы B сохранена прежняя проверка возможности фиксированных длин, без выдуманных измеренных высот; у груды C учитываются видимые части, скрытые целые цепи не утверждаются.

`build_pack.py --plan` строит новую ходьбу; без аргумента рендерит её; `build_hit.py` рендерит реакцию; `build_pack.py --pack` создаёт атласы и `asset-pack.json`; `verify_pack.py bones|volumes|muscles|finish` создаёт раздельные проходы. Для hit используются `hit-bones`, `hit-volumes`, `hit-muscles`. Unity-импорт: `AgentScripts/BuildCreatureVisuals.cs`, метод `BuildCreatureVisuals.Build`.

Живые ячейки512², шесть колонок, PPU200, pivot(301.1,255.9) сверху слева. Останки исходно1254²; в производственные копии добавлены16 прозрачных пикселей со всех сторон, pivot сдвинут на столько же до(776,681), PPU555.5556. Все исходные RGBA внутри поля сохранены точно. Это убирает соприкосновение почти прозрачных краевых пикселей исходного генератора с границей текстуры без изменения рисунка.

Источники останков и точные промпты встроенного image_gen — `image-generation.json`; PNG лежат в `remains/`. Кодовые риг/сетка/UV унаследованы от F21, F22 и проверки F18; чужие ассеты/код Сталкера не менялись. Историческое имя Unused сохранено ради воспроизводимости скриптов; фактическое применение отражено в [Used/ClawVisual01](../../../Used/Visual/ClawVisual01/README.md).

Выбор владельцем относится к дизайну J и F21 R2. Новые Walk, Hit, останки и полный импорт прошли техническую проверку; художественная приёмка отдельно ожидается. E/F прежнего дизайна остаются историческими альтернативами, в новый префаб не входят. Смешивания произвольных фаз, падения и физического разлёта новых частей нет.
