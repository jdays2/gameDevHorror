## Первый проход: кости и опора

- Четыре лапы. Передние предназначены для опоры/ходьбы и удара; задние — для опоры/ходьбы.
- Спереди по **три** длинных пальца/когтя. Крупная цепь плечевой пояс→верхний сегмент→локоть→предплечье→запястье читается. В коррекции нужен **один карпальный блок**, из которого расходятся ровно три пальцевые цепи.
- Помеченная владельцем наружная неровность кисти/карпального перехода неоднозначна: выглядит дополнительным бугром/шарниром, хотя отдельного четвёртого пальца нет. Сгладить этот контур в единую ладонь/запястье; не добавлять кость ради объяснения бугра.
- Все шесть передних когтей чрезмерно серповидны. Сохранить длину, кровавые основания и пальцевые крепления, сделать основную часть стержня заметно прямее с небольшим изгибом только у кончика. Светлая прямая на схеме — целевая ось **рогового материала**, не кость. Линия не требует, чтобы прямая фаланга шла через конец когтя.
- Сзади читается схема **три основных пальца + один боковой/отведённый** на каждой стопе. Крупный боковой коготь не означает лишнюю пятую конечность и не должен исчезать при упрощении. Роль/нагрузка бокового пальца по этому виду не установлена.
- Овал — голова, по подтверждению владельца. Центральная цепь голова→шея→грудная/поясничная область→таз едина. Показываем только макушку/спину: глаза, рот, грудь или лицо не добавлять.
- Больших разрывов четырёх цепей в этой позе не обнаружено. Парные лапы используют одинаковый граф/комплект; небольшая разница позы/проекционных длин сама по себе не ошибка.

[anatomy-plan-v1.json](anatomy-plan-v1.json), [anatomy-bones-v1.png](anatomy-bones-v1.png): оригинал с независимым планом. Чистый слой: anatomy-bones-layer-v1.png. Проекционные точки не подогнаны к наружному бугру; отдельного лишнего сустава там нет. Полигон опоры сохранён только в JSON, чтобы диагонали в воздухе не выглядели дополнительными костями.
