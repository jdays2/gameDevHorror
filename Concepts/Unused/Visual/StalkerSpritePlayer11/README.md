Откройте **player.html** двойным кликом. Просмотрщик содержит PNG внутри HTML и работает без сервера/интернета. Это Canvas-проигрыватель последовательности полных PNG, без video/mp4/webm, нарезки тела, рига, деформации или программной дорисовки.

- Выберите движение/атаку/сон/пробуждение и вариант. Слева проба, справа исходные цельные рисунки из фактически подключённых массивов ShadowStalker.prefab, с родными pivot и PPU.
- **Соседние кадры** накладывает целые предыдущий/следующий PNG для проверки. **Наложить исходник** добавляет целый исходный кадр той же временной фазы. **Схема костей** показывает заранее заданный контроль, не подгоняя его к ошибочному рисунку. Диагностические цвета не запекаются в PNG.
- Space — пауза, стрелки — шаг; полоса времени и миниатюры выбирают кадр. Темп/масштаб/фон настраиваются. **PNG этого кадра** сохраняет именно полный исходный PNG.

Для сна/пробуждения только одиночные новые ключи; недостающая серия не имитируется смешиванием/растягиванием ключей. В папке animations — APNG и два GIF-превью свежих проб. В sheets — листы целых PNG; frames — сами кадры; animations.json — порядок/тайминг/источник каждого кадра. RGB и alpha>=3 новых кадров точны относительно целой ячейки AI-листа; допускается только ранее разрешённая очистка отделённой внешней alpha1/2 и прозрачное поле до общего размера ячейки.
