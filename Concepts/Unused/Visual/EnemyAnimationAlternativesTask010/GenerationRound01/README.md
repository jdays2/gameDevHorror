# TASK-010 · параллельные художественные пробы · 2026-11-05

Новое прямое поручение владельца: запустить несколько генераций разными подходами и самостоятельно отправлять на перерисовку результаты, ушедшие от начального дизайна. Это следующий этап после отчёта со схемами; внедрение не выполнялось.

**Сравнивать:** [общая анимация с оригиналом](Selection/compare-walk.png), [A](Selection/A-walk.png), [B](Selection/B-walk.png), [C](Selection/C-walk.png). В каждой пробе ровно 6 разных цельных ключей, 125 ms на ключ, цикл 0.75 s. Это маленький тест для выбора подхода, не полный набор игровых состояний. [Исходные кадры для осмотра](Selection).

| Ветка | Реально использованный способ | Результат |
|---|---|---|
| A | ImageGen: оригинальный рисунок → цельные новые позы, затем исправление проблемной позы | Близкая рисовка, свободнее меняются блики/поза; 02 перерисован целиком |
| B | ImageGen: оригинал + независимая костная схема → цельные новые позы | Стабильнее корпус исходной серии; 02/04/05 перерисованы отдельно |
| C | Реальный Blender 5.2.2 orthographic volume reference → ImageGen, цельная перерисовка по оригиналу | Вся короткая серия заново получена по одному кадру; наиболее согласованная постановка после доработки |

**У всех трёх итог — генерация целых рисованных изображений.** C использует настоящие Blender-ориентиры, но чистовой персонаж не является готовой skinned 3D-моделью. B не является runtime skeleton/mesh. Не выдавать различия входных ориентиров за три реализованных игровых движка/пайплайна. Все генерации — встроенный `image_gen`, без API/CLI fallback. Точные промпты — соседние `*-prompt.txt`, происхождение/хеши — в `generation-manifest.json`.

## Проверка и перерисовки

Сначала получены нейтральные мастера, проверены на фиксированном костном наложении без подгонки лап; затем отдельно сопоставлены 18 условных функциональных областей, непрерывность кожи и детали. Это не медицинский атлас и не восстановление неизвестных высот из верхнего рисунка. После этого запущены три шестикадровые пробы параллельно.

Независимый осмотр r1 двумя проверяющими нашёл:

- A02 RR резко поджималась вверх-внутрь; B02 LR и B05 RR сокращали верхнее звено; C01–03 RR и C04 LR не достигали заданной нижней дуги.
- C00–05 содержали **реальную** дымчатую полупрозрачную подложку. В отличие от неё haze в RGB-only просмотре A/B находилась при alpha=0 и не была видимым фоном.
- Дизайн оставался узнаваемым, все шесть лап/концы и непрерывная кожа сохранялись. Числовой план не доказывал фактических контактов рисунка.

Общая перерисовка листов r2 не исправила позы достаточно. Эти версии оставлены отклонёнными. Затем изменён способ: **отдельная генерация каждого проблемного целого кадра**. Заменены A02, B02/04/05 и все C00–05. Исходные r1/r2 не перезаписывались. Результат повторно предъявлен тем же двум независимым проверяющим.

Финальная выборка хранится в `Selection`. Никаких вырезанных лап, переноса кожи по UV, морфинга или программной дорисовки RGB нет. При упаковке извлекались целые ячейки листа; для отдельных больших PNG применено одно равномерное преобразование всего холста к 576², затем целочисленный сдвиг всего кадра по зрачку на холст640² с origin320. Отдельные конечности/кожа не подгонялись. Все преобразования записаны в [sources-and-registration.json](../../../../../Docs/Validation/EnemyAnimationAlternativesTask010/GenerationRound01/Selection/sources-and-registration.json).

## Ограничения выбора

Рекомендация по маленькой пробе — **C как отправная точка**, B как запасная. У C устранена дымчатая подложка и прежнее сильное поджатие задних цепей; у A/B сохраняются менее точные относительно плана отдельные старые r1-позы. При смешении r1/r3 у A/B слегка различается резкость/темнота контура. Это различия для просмотра владельцем, а не отметка его художественной приёмки.

Точный костный план всех18рисунков, истинные 3D-длины/контакт/перенос веса и полноценная походка в игре не объявлены прошедшими. Функциональные мышечные области нейтрали не означают полного muscle PASS всех состояний. Складывание, раскрытие, атака и Спящий на этом этапе не произведены: сначала владелец получает конкретный небольшой материал для выбора подхода. Готовых production-серий/новых назначений нет.

Вся работа вне Assets. Unity Editor не запускался; установленный Blender использовался только offline, пакеты не устанавливались. Исходные изображения и файлы TASK-007 не менялись. Итоговый контроль авторинга: неприменим.
