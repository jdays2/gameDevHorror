## Источник и обработка партии

Четыре короткие текстовые генерации Runway, по4кредита, всего16. Аудио меню или другого референса в сервис не загружалось. Генератор возвращает фиксированный короткий клип, поэтому для владельца подготовлены первые ровно20с каждого исходника, без ускорения/замедления.

Итоговые RMS−20.01…−20.10dBFS;4× true peaks ниже−5.8dBTP. WAV: stereoPCM24/48kHz,960000samples/канал. Доставляемые MP3 полностью декодированы; их sample-данные конечны, длительности20с. Это техническая проверка, не художественная оценка. [Точные данные](Directions04/processing.json), [скрипт](Directions04/make_samples.py).

Исходники AI-генерации в подключённом аккаунте, без внешних сэмплов. Не объявляются CC0-записями; права и сервисное происхождение не подменяются техническим форматом. Подписанные URL и credentials не сохранялись. MP3-источник остаётся lossy; PCM24 не возвращает утраченное качество.
