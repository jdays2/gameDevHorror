# Bite02 — новые пробы телесного повреждения

TASK-009. Предыдущий B отклонён владельцем: звонкий фрикционный слой напоминает трение ткани/подошвы и скольжение, а требуется ощущение укуса и травмы тела. Это новые независимо созданные источники, не дополнительная ткань поверх прежнего B. Пробы не установлены в production-профиль и художественно не утверждены. [Игровое сравнение D/E/F](../../../../../Docs/Validation/PlayerHitTask009/Bite02-native/DEF-native-gameplay.mp4) записано с временными memory-only назначениями, по четыре настоящих удара без выстрелов.

[Общее прослушивание D/E/F](Previews/DEF_comparison.wav),12.4s. По два одинаковых повтора каждого материала с паузой2s между onset:

| Порядок | Заданный характер | Отдельный WAV | События общего файла |
|---|---|---|---|
| D | Глухое сдавливание тела зубами, короткий прокол | [D](Previews/D_double.wav) | .3 / 2.3s |
| E | Влажный плотный укус, сжатие и короткий внутренний хруст ткани тела | [E](Previews/E_double.wav) | 4.3 / 6.3s |
| F | Короткий разрыв плоти с приглушённым телесным ударом | [F](Previews/F_double.wav) | 8.3 / 10.3s |

У каждого материала пока один независимый исходник, повторённый для оценки характера. Полный вариативный банк требует выбранного направления. В превью не добавлены выстрелы, шаги, шорохи одежды, голос или прочий игровой микс. Названия описывают творческое задание, не заменяют слуховую оценку владельца.

PCM16 mono48k, длительности D.420/E.388/F.338s. Уровни −25.27/−25.26/−25.30 LUFS при одинаковом измерении с дополнением тишиной; static matching, peak≤.65, preview gain.8. Обработка: highpass70Hz, быстрый компрессор threshold.04/ratio4/attack.01ms/release60ms, два lowpass2000Hz, DC removal, trim/fades. Это смягчает короткие пики и верх; обработка не доказывает правильность физической ассоциации. Энергия выше3kHz D/E/F≈.105/.011/.665%; прежние B≈5.9–29%. Конкретные спектральные показатели не являются художественной приёмкой.
