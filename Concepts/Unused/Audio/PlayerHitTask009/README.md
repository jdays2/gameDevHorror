# TASK-009 · отклик принятого попадания

Три созданных для задачи направления, художественная оценка владельца открыта. **B — рекомендуемый рабочий кандидат**, без закреплённого голоса/пола персонажа.

| Набор | Характер | Одиночный | Серия | Контекст |
|---|---|---|---|---|
| A | Сухой короткий удар через одежду | [WAV](Previews/A_single.wav) | [WAV](Previews/A_series.wav) | [WAV](Previews/A_context-offline.wav) |
| B | Более плотный контакт плоти и ткани | [WAV](Previews/B_single.wav) | [WAV](Previews/B_series.wav) | [WAV](Previews/B_context-offline.wav) |
| C | Контакт с тихим коротким выдохом | [WAV](Previews/C_single.wav) | [WAV](Previews/C_series.wav) | [WAV](Previews/C_context-offline.wav) |

[Общее прослушивание A/B/C](Previews/ABC_single-and-series.wav): каждые 7.2 секунды начинается следующий набор, сначала одиночный, затем серия. Четыре монтажных вариации каждого набора находятся в Exports. Это варианты из одного исходника на направление, а не четыре независимые записи.

Общая громкость базовых файлов около −25.2 LUFS (FFmpeg loudnorm, K-weighted, с одинаковым дополнением тишиной для коротких транзиентов), различие <0.1 LUFS; preview gain .8. Не нормализовано по одному peak. 48 kHz PCM16 mono, длительности 0.29–0.35 s, highpass110/lowpass6500, мягкие границы. Пик ограничен .68, серийные варианты отличаются скоростью до 2.1% и уровнем менее 0.5 dB. Измерения и SHA256 — [processing.json](processing.json).

Контекстные WAV — **offline-монтаж**, не запись игрового прогона: одинаковые принятые выстрелы пистолета, шаги и замах/бросок Сталкера; меняется только player hit. Фактическая игровая запись с текущими UI/визуальными реакциями выполняется после game lease.

Рекомендация B основана на компактном физическом контакте без нового голоса. A наиболее сдержанный, но короткий низкий транзиент может хуже читаться рядом с выстрелом; C добавляет уязвимость, но привносит характер дыхания, который владельцем не утверждён. Техническая громкость и отсутствие clipping не заменяют слуховой оценки.

Генерационное происхождение, task IDs и точные prompts сохранены в [provenance.json](provenance.json); исходные MP3 в Sources не изменены. Не приписывать им CC0 или утверждение владельца. Воспроизведение монтажа: `AgentScripts/Task009/prepare_audio.py --ffmpeg <path>` из любого рабочего каталога. Скрипт не пишет Assets и не вызывает Unity.
