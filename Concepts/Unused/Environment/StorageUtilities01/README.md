Различимость каждого следа при окончательном игровом масштабе требует проверки в Unity; не все мелкие детали обязаны быть видны издали.

## Трубы и стыки

[ports.json](ports.json) содержит измеренные координаты портов исходных PNG: X вправо, Y вниз, нормаль наружу. Равномерный масштаб рассчитан для условного диаметра .14 units, без растягивания отдельных осей. В примере концы немного перекрываются. Проверка относится к этим пяти элементам и данному масштабу; нет гарантии бесшовного тайлинга произвольного изображения. Чистую прямую секцию можно повторять, повторяющиеся следы на длинном маршруте потом стоит разбавить нейтральными участками. Коллайдеры, высота труб и runtime-сборка не реализованы.

## Источники и проверка

Встроенный image_gen: первые изображения по стилевым референсам IndustrialProps02, фитинги — правки общей прямой трубы, затем точечные правки индивидуальности. Полные промпты: [generation-plan.json](generation-plan.json), [pipe-generation-plan.json](pipe-generation-plan.json), [individuality-corrections.json](individuality-corrections.json). Итоговые размеры, SHA-256 и связи — [provenance.json](provenance.json). PNG скопированы без обработки растра; Pillow читает метаданные/альфу, Chromium показывает реальное RGBA-наложение. Цветные RGB-пиксели вне альфы не являются видимым ореолом.

Исправление тележки хранится в InteriorProps01/Sprites/medical-trolley-v2.png; старый medical-trolley.png оставлен для честного сравнения. Поворот одного колеса, кольцевой след и локальные царапины видны в сравнении. Остальная предыдущая библиотека не объявлена перегенерированной.
