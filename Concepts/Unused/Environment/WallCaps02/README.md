# Тонкая кромка стены · 02 · отклонена

Владелец попросил убрать всю внутреннюю отделку и вернуть прежний вид стен. Проба Wall Cap снята с 18 стен MechanicsSandbox; исходные FlatUnlit/цвета восстановлены. Шесть рабочих материалов и шейдер удалены из Assets после проверки зависимостей. Исходники с прежними .meta сохранены только здесь, в UnitySource; их не следует копировать обратно автоматически.

Метод: оригинальный статичный шейдер без генерации изображений; кромка 0.025 внутри спрайта, тихая вариация поверхности и едва заметная подкраска около (3.7; 0). Слабая unlit-видимость сохранялась. Это историческая проба, не текущее оформление и не художественное одобрение.
