# Ранние атласы разметки

Две технические пробы imagegen исключены из производства: лишние брызги вне силуэтов, контуры, похожие на наклейки, и несовпадающие точки стыковки. Это не утверждённые игровые ресурсы. Исходные PNG и промпты сохранены в `Sources` и [provenance.json](provenance.json).

Используемый подход — общая маска покрытия с точной геометрией отдельных модулей: [FloorMarkings01](../../../Used/Environment/FloorMarkings01/README.md).
