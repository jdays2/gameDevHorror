# Референсы внутренней отделки стен

Три игровых скриншота и восемь фотографий переданы владельцем 2026-10-18. [Происхождение, хэши и перенос приёмов](sources.json). Это материалы для изучения; права на использование исходных изображений в игре не заявляются.

В пробу WallFinishes01 перенесены смещённые швы плитки, краска/плинтус и панели с защитной полосой. Изометрическая камера, яркие потолочные блики, вывески и водяные знаки не переносятся. Кирпичная кладка — возможное будущее дополнение. Производственные текстуры созданы математически с нуля.
