# Повреждения поверхности · проба 02

Восемь процедурных накладок для оценки владельцем. [Превью на новых полах](overview.png) увеличивает примеры для чтения формы; это не единый игровой масштаб. В Unity пока не подключены. [Проверки файлов](../../../../Docs/Validation/HospitalSurfaces02.json).

| Форма | Подходящая поверхность | Начальная ширина холста, units |
|---|---|---|
| castor-scuff | Потёртости от колёс на керамике, виниле, покрытии | 1.1 |
| metal-drag | Рваные полосы волочения металла по твёрдому полу | 2.2 |
| bone-tip | Один зацеп костяного конца ноги, без человеческой ладони/стопы | 0.65 |
| hairline-crack | Тонкая нерегулярная трещина в минеральной поверхности | 1.6 |
| tile-corner-chip | Скол керамики; две прямые стороны привязать к углу плитки | 0.45 |
| elongated-spall | Вытянутый скол бетона, без круглого центра | 1.3 |
| coating-flake | Содранное покрытие, привязать к цвету нижнего слоя | 1.2 |
| shallow-crease | Неглубокая вмятина в податливом покрытии/листовом металле | 0.8 |

Вмятина не предназначена для бетонной или керамической плиты: там уместны трещина и скол. Скол угла нельзя произвольно положить в центр целой плитки. Размеры относятся к прозрачному квадратному холсту, а не только видимой части следа.

## Устройство

`Sprites` — RGBA 768 × 768 с цветом материала, локальным рисунком и слабыми запечёнными контактными кромками. `TintMasks` — белый RGB с той же альфой для простого перекрашивания; маска сохраняет силуэт/прозрачность, но не внутренние цветовые грани исходника. Прозрачность можно будет задавать цветом SpriteRenderer при будущем импорте. Динамической глубины, нормалей или физической деформации эта проба не добавляет.

Генератор `Tools/Art/bake_surface_damage_02.py` работает заранее: ломаные траектории, неравномерный контакт, локальные надрывы/сколы, отдельные небольшие грани. Шум переиспользован из `Concepts/Unused/Visual/ProceduralBlood01/render_samples.py`; отклонённые изображения FloorAftermath01/PresenceTraces02 не используются. Семена и SHA-256 — в [provenance.json](provenance.json). Это не imagegen и не генерация во время игры.

При будущем размещении: освещаемый слой над полом, без коллизий и собственной длинной тени. Цвет и материал подбираются к конкретному полу. Не делать одинаковую царапину по всей комнате; след должен соответствовать причине — повороту каталки, волочению оборудования или движению существа. Проверки файлов не заменяют художественную оценку.
