2026-10-18. Четыре процедурных примера на оценку владельцем после отклонения PresenceTraces02. Направление — присланный пример переноса крови при скольжении: плотный участок, рваные протяжённые полосы, просветы, отдельные пятна и капли. Ладоней, подошв и радиальных трещин нет.

## Расширение: 12 новых форм разного размера

В `Variations/Sprites/` добавлены ещё 12 отдельных прозрачных PNG; всего в семействе **16 форм**. Первые четыре пробы сохранены. Расширение использует те же функции смаза/пятна и материал крови, но меняет композицию контакта, направление, ширину, изгиб, потерю пигмента и расположение отдельных капель.

| Группа | Предлагаемая ширина холста в Unity | Формы |
|---|---|---|
| Малые S01–S04 | 0.25 / 0.4 / 0.55 / 0.7 units | Капли, срыв острия, короткий затёртый мазок, два касания |
| Средние M01–M04 | 0.95 / 1.2 / 1.45 / 1.7 units | Косой смаз, поворот, прерывистый контакт, пятно со сдвинутым краем |
| Крупные L01–L04 | 2.1 / 2.45 / 2.8 / 3.2 units | Два неодинаковых следа, рывок при волочении, широкий тонкий след, густой смаз с каплями |

Это предлагаемые размеры **всего PNG**, включая небольшие прозрачные поля; единицы игры не заявляются метрами. Значения ещё не назначены Unity-префабам. Максимальная сторона PNG — 512/768/1024 px по группам, пропорции естественные, вокруг формы есть пустое поле. Это разные формы, не только копии в другом разрешении.

- [Общий масштаб на бетоне](Variations/sizes-concrete.png), [на плитке](Variations/sizes-tile.png): 98 px на игровую единицу, одинаковый масштаб пола во всех ячейках. Сам рисунок пола повторяется раз в 6 units, как в текущей библиотеке.
- [Увеличенные формы](Variations/details.png): каждый пример приближен для оценки текстуры; масштаб между ячейками отличается.
- Повторить расширение: `python Tools/Art/bake_blood_trace_variations_03.py`. Seed, размеры, параметры и хеши — `Variations/provenance.json`. Расчёт заранее, сцены и исходные четыре PNG не перезаписываются. Художественную оценку выполняет владелец.

## Первые четыре пробы

- `short-wipe` — короткое скольжение, плотное скопление у остановки, полупрозрачный хвост.
- `long-drag` — протяжённое волочение с изгибом и участком потери контакта.
- `scattered-stains` — не связанные одной идеальной линией пятна, локальный смаз, неодинаковые капли.
- `bone-slips` — несколько неравномерных скользящих контактов костяных концов ног. Это отдельные улики, не точная запись шага всех шести ног.

`examples-concrete.png` и `examples-tile.png` показывают одинаковые четыре PNG на двух существующих полах. `overview.png` даёт сопоставление рядом; `short-wipe-neutral.png` — смаз на светлой нейтральной подложке. Все подложки есть только в превью; четыре `Sprites/*.png` имеют прозрачность, 1024×1024, вид строго сверху. Масштаб в Unity ещё не назначен.

Вычисление заранее: `python Tools/Art/bake_blood_traces_03.py` (NumPy/Pillow). Повторно использованы шум/SDF/неровные пятна из `ProceduralBlood01` и **та же функция материала**, что у игровой крови `BloodPools01`: плотность задаёт цвет, прозрачность и запечённый локальный блик. Изменены формы переноса: давление по длине, неодинаковое окончание полос, просветы по траектории движения, потеря пигмента и локальное скопление. Конкретные seed — в `provenance.json`.

Референс владельца с видимой подписью Shutterstock 2798661061 использован только для понимания движения и плотности; его пиксели/водяной знак в новые текстуры не переносились. Это математическая генерация без imagegen и без симуляции жидкости.

В Assets и сцены эта проба не импортировалась. Предыдущие экземпляры PresenceTraces02 пока остаются на месте, но художественно отклонены. Игровая кровь при смерти не менялась. Для новой пробы проверены RGBA/размер/пустые края и композитинг на обоих полах; техническая проверка не означает одобрения внешнего вида.
