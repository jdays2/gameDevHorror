# Диалоговый интерфейс 03

2026-10-18. Доработка кинематографичного направления Dialogue02: только активный персонаж, компактный размер, временно белый квадрат. Владелец временно принял подачу и поручил добавить линейную пробу в Unity. Этот HTML сохранён как исходный концепт; рабочие ресурсы находятся в Assets/EmergencyShift, [запуск в песочнице](../../../../Docs/SANDBOX.md#пробный-диалог).

`dialogue-concept.html` — источник. Один слот над репликой слева; его содержимое и имя принадлежат текущему говорящему. Сплошной белый квадрат сохраняет 1:1, имеет сторону 128–200 px в просмотре, не затемняется и не получает силуэт/рисунок. При росте панели ответов слот поднимается, сохраняя зазор. Основной HUD по-прежнему скрыт до конца разговора. Альтернативы в этой итерации не добавлены.

`cinema.png` — начало; `cinema-choices.png` — ответы; `cinema-choices-narrow.png` — узкий просмотр. `validation.json` фиксирует браузерную проверку. [Дизайн-система](../../../../Docs/UI/DIALOGUE_DESIGN_SYSTEM.md) — актуальные правила. Dialogue02 сохранён как предыдущая проба; новые размеры и положение на оценку владельцем.

Источник — предыдущий HTML/CSS-концепт Codex и прямое уточнение пользователя. Внешние изображения/шрифты/звук не используются, белый квадрат выполнен CSS. Условный фон не является новой игровой картой; тексты демонстрационные. Рабочий Unity UI создан отдельно из обычных uGUI-компонентов по этому ориентиру; HTML в игру не импортируется. По указанию пользователя коммиты остаются локально, без push.
