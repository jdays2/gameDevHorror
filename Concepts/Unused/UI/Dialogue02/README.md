# Диалоговый интерфейс 02

2026-10-18. Новые направления после отклонения владельцем Dialogue01. Оба на оценку; в Unity не подключены.

- **Кинематографичный** — два крупных силуэта, исчезающий в затемнении низ портретов, свободная реплика без замкнутой рамки, тёплый акцент имени.
- **Больничное досье** — один активный портрет слева, отдельный светлый лист справа, заголовок с засечками и сдержанная красно-коричневая линия. Не подразумевает существование внутриигрового досье или новой механики.

`dialogue-concept.html` — редактируемый источник, `cinema.png` / `record.png` — реплики, `*-choices.png` — ответы, `*-choices-narrow.png` — ширина 320 px. `validation.json` — результат проверки браузерного просмотра. Канонические правила находятся в [дизайн-системе](../../../../Docs/UI/DIALOGUE_DESIGN_SYSTEM.md).

Все силуэты, условная фоновая геометрия, текст и оформление созданы Codex средствами HTML/CSS. Внешние изображения, звук и сетевые шрифты не использованы. Это нейтральные заглушки без лиц и авторинга персонажей; фон не является новой сценой/картой и не заменяет вид сверху в игре. Реплики — демонстрация, не утверждённый сюжет. Предыдущие изображения сохранены в Dialogue01 как отклонённая история; существующие Unity-ресурсы не менялись.

Проверка: обе ветки ответов, смена говорящего, Space/Enter, стрелки для выбора, цифровые команды, скрытие/возврат HUD и повторный вход; обе композиции на 320/736/1024 px без пересечений текста/ответов или выхода панели за экран. Снимки просмотрены визуально. Проверка не подтверждает работу в Unity или художественное одобрение.
