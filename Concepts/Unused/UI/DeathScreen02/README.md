## Поведение и тишина

Во всех C–F сообщение «ВЫ ПОГИБЛИ», первая команда «Повторить попытку» и вторичная «Выйти из игры». Текущие MechanicsSandbox/MorgueRouteTest не имеют checkpoint-контроллера; пояснение «С начала сцены» это отражает. Состояние «С контрольной точки» в просмотре — пример для будущей явно подключённой совместимой сцены. Проверять доступность/совместимость и ошибки нужно при реализации, не по одному наличию файла.

Показаны состояния fresh/checkpoint/loading/error/подтверждение выхода. Это макеты intent: кнопки не вызывают загрузку/quit. При Loading повторные нажатия недоступны. Ошибка сохраняет файл и даёт «Попробовать снова»; fallback чистого запуска остаётся отдельным будущим сценарием, не скрытым удалением сохранения. Фокус начинается на повторе; у выхода подтверждение с «Остаться» по умолчанию. Esc не возобновляет мёртвого игрока. У D фокус — светлая поверхность кнопки; C/E — светлый текст; F — светлый текст и точка.

Музыки нет: ни отдельного трека, ни петли, ни переноса музыки паузы. Никакие UI-звуки дополнительно не созданы. Предложение перехода: захватить игровой ввод сразу на смерти; мир мягко затихает и затемняется примерно за1.4с, текст появляется с0.7с за0.5с; после отпускания удержанного ввода разрешаются команды. В D/E мир остаётся неподвижной приглушённой подложкой, C/F уходит в чёрный. Время/кривые ещё не приняты владельцем. BUG-053 отвечает за будущую проверку мирового затухания, его исправление этой работой не начато.

Состояние перехода должно закрыть/погасить паузу с её музыкой, не запустить её снова и не снять внешние аренды. Сохранить защиту от сквозного клика, старый defeatPrompt/R-путь заменить одним проверяемым intent при реализации. Скрытие HUD само по себе не блокирует игру. Ни кампании, ни перехода в отложенный MainMenu варианты не обещают.
