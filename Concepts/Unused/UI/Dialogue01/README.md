# Диалоговый интерфейс 01

2026-10-18. **Отклонён владельцем.** Историческая первая проба; не использовать как выбранный стиль. Продолжение поиска — [Dialogue02](../Dialogue02/README.md). Не импортирован в Unity.

- `dialogue-concept.html` — редактируемый интерактивный макет: две композиции, смена говорящего, два ответа, завершение и возврат иллюстративного HUD.
- `preview.png` — основной вид; `choices.png` — выбор; `compact.png` — альтернативная композиция; `narrow.png` — проверка ширины 320 px.
- [Дизайн-система](../../../../Docs/UI/DIALOGUE_DESIGN_SYSTEM.md) — единственный источник требований к токенам, компоновке, состояниям и будущим границам реализации.

Все силуэты, схематический фон и оформление созданы Codex средствами HTML/CSS по запросу владельца. Внешние изображения, шрифты, аудио и генерация персонажей не использованы. Фон — условная схема больничного коридора, не скриншот и не новая карта проекта. Реплики вымышлены для демонстрации, не являются утверждённым сюжетом. Макет не меняет сцену, оружие, AI и существующий HUD.

Для просмотра в чате используется копия того же фрагмента в директории визуализаций текущей беседы. Канонический редактируемый источник хранится здесь. Карусель вариантов предоставляется средой просмотра; для автономной проверки можно открыть нужную секцию, сняв `hidden`. Playwright-проверка выполняется в обёртке Visualize с настоящей каруселью.

Проверки: переключение реплик/говорящего, обе ветки ответа, скрытие HUD во время разговора и возврат после завершения, повторный вход, клавиатура, отсутствие ошибок JavaScript/горизонтального переполнения на 320/736/1024/1920 px. Снимки сохраняются после проверки. Это проверка макета; поведения игры и творческого одобрения она не подтверждает.
