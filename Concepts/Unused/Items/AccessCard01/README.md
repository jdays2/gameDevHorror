# Карта доступа 01 · синяя проба

2026-10-18. Владелец предложил форму пропуска по предоставленному Rust-референсу и оставил цвет корпуса на выбор. Выбран холодный серо-бежевый пластик, приглушённые синие полосы сверху/снизу, графитовый портрет справа и небольшой латунный чип слева. Надписей и цифр нет. Фронтальная лицевая сторона строго сверху, без перспективы.

[Исходный RGBA](blue-card-source.png), [промпт](prompt.txt), [проверка в Unity](unity-preview.png), [происхождение](provenance.json).

Создано встроенным imagegen по описанию; исходный референс — фотография владельца с пропусками COBALT, сохранён только для визуального изучения. В production не переносилась готовая графика Rust. Пара небольших потёртостей видна на левом крае и возле чипа; нет отдельной грязной/кровавой версии. За пределами карточки настоящая прозрачность. Native использовал прямоугольник sprite (116,148,1381,688) в координатах Unity; исходный PNG сохранён без обработки.

В Play MechanicsSandbox временный SpriteRenderer использовал прежний FlatLit и ширину 0.5 units (как у старого предмета); высота по пропорциям 0.249. Временный Image в прежнем HUD — 38×24 с Preserve Aspect. На просмотренном кадре читаются полосы, портрет и чип. Маленький HUD использует тот же рисунок; отдельная упрощённая иконка пока не нужна для этой пробы.

Это сохранённая проба внешнего вида, без постоянной замены подбора/префаба/HUD. Временные объекты и текстура удалены из памяти после кадра, сцена не стала dirty. Остальные цвета пока не отрисованы. Runtime-код, логика доступа, ID карт и сохранённая расстановка не менялись; сборка для этого просмотра не требовалась.
