# Активный долг и будущий объём

Перенесено из ENGINEERING_REVIEW, не новые обещания функциональности. ID сохраняются; создание записи не разрешает внеплановую игровую реализацию. [Текущий этап](Roadmap.md).

## BL-001

**Свой код по SOD. Статус: active, топ-приоритет по прямому поручению 2026-10-19.** Проверить использование всех собственных файлов, Model/Controller/View, команды, DI/scopes, конфиги/ID, lifetimes, C#-стиль и проверки. [План/критерии](Roadmap/00-ArchitectureMigration.md). Не закрывать установкой пакета или одной компиляцией.

## BL-002

**Кампания и динамическая persistent-идентичность. Статус: deferred.** Локальные слоты работают с авторенными объектами одной сцены. Нет полноценного перехода/переноса состояния и каталога runtime-spawn ID. Архитектурная миграция должна оставить границы, но не реализует новую кампанию. [Persistence](Features/Persistence.md).

## BL-003

**Независимое сохранение останков удалённого actor. Статус: deferred.** Визуальный RemainsRecord независим, snapshot ещё снимает адаптер actor; до его удаления/будущего пула нужен каталог записей и regression передачи. Не вводить пул автоматически. [Enemies](Features/Enemies.md).

## BL-004

**Будущие save-миграции и отказоустойчивость. Статус: open.** Есть проверки version/ID/saveRevision и ограниченная совместимость payload; нет общего мигратора любых форматов и автоматического fallback .bak. I/O и большой snapshot требуют отдельного анализа. Текущий рефакторинг обязан сохранить действующий формат либо протестировать нужную миграцию, не обещая универсальную систему. [Политика](Guides/CHECKPOINTS.md).

Массовая гибель/пулы учитываются отдельно как [OPT-01](OPTIMIZATION_BACKLOG.md); контентные идеи — [OBJECT_BACKLOG](Environment/OBJECT_BACKLOG.md). Не дублировать их с новыми номерами BL.
