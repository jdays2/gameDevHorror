# 02. Дальнейшее демо

Статус: продуктовая рамка, реализация новых систем не начата этим документом. Приоритет сейчас у [архитектурного прохода](00-ArchitectureMigration.md).

Цель владельца — выход из больницы после пробуждения в подвальном морге, исследование, необязательные рискованные ответвления/секреты, финальный бой и итоговая статистика. Ориентир длительности остаётся непроверенным. Источник — [GAME_CONCEPT](../GAME_CONCEPT.md), действующие ограничения — [SPEC](../SPEC.md).

- Дальнейшая сборка/доработка игрового маршрута — от существующей [пробы](../Guides/MORGUE_ROUTE_TEST.md), с сохранением ручной расстановки. Не регенерировать зарисовки/планы поверх правок владельца.
- Меню выбора сцен и дальнейшие UI-экраны — [UI_PLAN](../UI/UI_PLAN.md); пробный диалог уже существует.
- Третий вид, конкретный босс/финал, обучение, награды и правила итогового подсчёта требуют отдельного решения/фичи.
- Кампания и перенос состояния между уровнями — [BL-002](../Backlog.md#bl-002), без обещания готовности из наличия локального checkpoint.
- Массовая гибель/пулы — [OPT-01](../OPTIMIZATION_BACKLOG.md), отложено владельцем. Сеть/кооп не входят в принятую рамку.

До зависимой реализации закрывать соответствующие [Questions](../Questions.md), а не принимать игровые решения из чужого roadmap.
