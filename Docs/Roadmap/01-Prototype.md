# 01. Реализованный прототип

Сводка на начало текущего прохода, не новый плейтест. Актуальный контракт живёт в документе фичи; числовой баланс не копируется в план.

| Область | Реально доступно | Осталось |
|---|---|---|
| Игрок/мир | Движение, прицел, фонарь/модули, карточки/двери/подборы; находка фонаря и камера в маршрутной пробе | Полная MVC/DI-сверка; [World](../Features/World.md) |
| Враги | Сталкер и Спящий, индивидуальное состояние, смерть/останки | Баланс/визуальная приёмка; [Enemies](../Features/Enemies.md) |
| Оружие | Пистолет/помповый дробовик, магазины, автоматическая/ручная перезарядка, переключение | Найденные улучшения и собственная графика по будущей задаче; [Weapons](../Features/Weapons.md) |
| HUD | uGUI, HP/карты/фонарь/оружие, контекстные сообщения | Ручная визуальная оценка; [Hud](../Features/Hud.md) |
| Диалог | Ветвления и общий DialogueUI.prefab, остановка ввода/мира при сохранении фона | Последствия, условия, журнал и save-прогресс не реализованы; [Dialogue](../Features/Dialogue.md) |
| Уровни | MechanicsSandbox и отдельный тест MorgueRouteTest с картами, лутом, врагами и маршрутной пробой | Полноценная кампания/переходы не готовы; [маршрут](../Guides/MORGUE_ROUTE_TEST.md) |
| Окружение/свет | Библиотека и ArtReview, полы/накладки, URP-тени; локальные художественные решения | Оценка владельцем, будущий финальный арт; [направление](../ART_DIRECTION.md) |
| Чекпоинты | Локальная система авторенных объектов одной сцены | В песочнице намеренно отключена; [Persistence](../Features/Persistence.md) |

Архив старых выполненных шагов и чисел — [прежний план](../Archive/MVP_PLAN-before-SOD.md). Он не возвращает устаревший статус «диалог только планируется» и не отменяет уже созданную маршрутную пробу.
