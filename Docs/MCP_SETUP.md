# MCP и окружение

## Что подключаем

- **MCP for Unity 10.3.0:** пакет редактора закреплён в `Packages/manifest.json` на теге `v10.3.0`. Python-сервер той же версии установлен в изолированное окружение рабочей папки чата.
- **Context7:** удалённый сервер документации `https://mcp.context7.com/mcp`. Не управляет Unity. Доступ и реальные инструменты проверяются отдельно от наличия записи в конфигурации.

Записи `unityMCP` и `context7` добавлены в пользовательский `config.toml` Codex. Существующие настройки сохранены; копия исходной конфигурации находится в служебной папке чата и не включена в проект.

Фактическая проверка: Unity MCP прочитал BasementPrototype, провёл validate и управлял Play Mode; Context7 вернул инструменты `resolve-library-id`/`query-docs` и успешно выполнил поиск библиотеки Unity. Проверки текущей итерации выполнялись через локальный MCP-клиент агента, поскольку список инструментов уже открытого чата не обновился после записи конфигурации.

## Как соединяются части

```text
Codex / MCP-клиент
    → локальный Python-сервер (stdio)
    → локальный мост пакета MCP for Unity
    → открытый Unity Editor с нашим проектом
```

Открытая Unity необходима для операций со сценой. Запуск сервера и получение списка инструментов не доказывают соединение с редактором. Проверяем фактическим чтением текущей сцены и консоли.

`StarterBootstrap` выбирает stdio и запускает редакторскую сторону моста. Конфигурация использует запуск `python -m main`, поскольку стандартный launcher через uvx дал ошибку Windows при первоначальной проверке. Для текущего каркаса этот способ уже подготовлен; настройки конкретного компьютера не коммитятся в проект.

В текущем редакторе указан путь к uvx и дополнен PATH процесса для обнаружения комплектного Python. Это не глобальная установка Python в Windows. Мост stdio и сервер, запускаемый из Codex, не зависят от кнопки автоматической установки в мастере MCP Setup.

После фактической проверки мостов первоначальный мастер отмечен завершённым через публичный API пакета; он не должен автоматически появляться при следующем открытии проекта.

После изменения списка MCP текущему чату может понадобиться перезагрузка подключений или новый чат в проекте. Для текущей проверки агент может обратиться к серверу напрямую по MCP; это отдельно отмечается в отчёте.

Официальные инструкции: [MCP for Unity](https://coplaydev.github.io/unity-mcp/getting-started/install), [MCP в Codex](https://learn.chatgpt.com/docs/extend/mcp?surface=app).
