# Активные дефекты

Известный архитектурный долг находится в [Backlog](Backlog.md), отложенная производительность — в OPT-01. Записи ниже содержат только подтверждённые наблюдения.

Новая запись `BUG-NNN`: откуда/ревизия, воспроизведение и ожидание, фактическое поведение, область/приоритет, статус open | needs-decision | blocked | fixed, проверка исправления и commit. Нумерация отдельна от Q/BL/ADR. Не записывать гипотезу как подтверждённую причину.

Исправленный дефект закрывается регрессией, а не редактированием описания. Историю закрытых записей переносить в Archive при появлении таких записей с сохранением ID/ссылок. Пустой архив дефектов заранее не создаётся.

## BUG-001

Статус: open. Область: сериализованные устаревшие данные. Источник: AssetDatabase/GUID-аудит 2026-10-19 в рабочем дереве после `abeb23c`.

В BasementPrototype (9), LevelTemplate (2) и MechanicsSandbox (4) остаются записи с GUID `280b7908d23022545b84c141862fc18a`, который AssetDatabase не разрешает. Git подтверждает, что это удалённый `Settings/FloorShadows.asset` из отменённой системы конечных теней (`d5eaf5e` → `90641df`). В LevelTemplate записи находятся среди prefab property modifications для отсутствующих сейчас component fileID.

Нужно проверить все 15 записей официальным prefab API и убрать только доказанно неиспользуемые overrides, сохранив действующие поля/связи и ручную карту. Не восстанавливать отклонённую систему теней. Влияние на активное поведение не доказано; успешная сборка не делает эти записи валидными. Критерий закрытия: нет отсутствующего GUID, действующие значения/позы сохранены, сцены проходят целевые проверки.
