# Утверждённый звук сталкера

Рабочий характер — «живая мембрана». Мясистое тело, костяные концы ног. Главный маркер во тьме — движение; в покое редкие короткие мембранные сокращения с нерегулярной тишиной, без жужжания/выраженного дыхания.

- Контакты нейтральные, сухие/короткие, без звонкой плитки;6 вариантов сбалансированы по энергии, громкий повторяющийся акцент убран. Материал поверхности можно развить позже отдельным слоем.
- Свет раздражает: яркий короткий вскрик после задержки реакции, прерывистая боль при быстром отходе, затем тихая дрожь сжатого тела.
- До броска слышно раскрытие пасти/натяжение ткани; затем реальный бросок и успешный укус.
- Ранение локальное; смерть — мокрый разрыв с небольшим костяным хрустом, отдельные посадки частей. Сохранять читаемость при нескольких особях/ограничивать наложение.
- Два спокойных эталона сохранены точно, остальные рабочие звуки развивают этот тембр. Ранее отклонённые пробы удалены, история остаётся в Git.

Реализация/настройки и C#-объяснение — [STALKER_AUDIO.md](STALKER_AUDIO.md). Система подключена к префабу/семи врагам; звук игрока/оружия/окружения — будущие отдельные задачи. Проверка аудиолимитов 20 экземпляров не доказывает готовность всей толпы.
