# Высота окружения и тени

У мебели есть **Environment Height 2D → Height Class**. Это три условных уровня поверхности для вида строго сверху, а не физические метры. Масштаб рисунка и коллайдер не определяют высоту.

| Класс | Примеры | Куда падает тень |
|---|---|---|
| Low | Урна, стулья, низкая скамья, трубы у пола | Пол, другие Low |
| Furniture | Столы, тележка, койки, диван, бочка, поддоны | Пол, Low, Furniture |
| Tall | Шкафы, стеллажи, стены, створки дверей | Все поверхности |

Поэтому урна перед высоким шкафом продолжает затемнять пол, но её длинный чёрный сектор больше не режет верх шкафа. Шкаф затеняет урну и стол; стена — и шкаф. Соседние предметы одного класса по-прежнему могут затенять друг друга.

Выберите корень prefab/экземпляра с компонентом, измените **Height Class** в остановленном Editor и сохраните. Inspector сразу обновляет слои поверхностей и **Shadow Caster 2D → Target Sorting Layers**. Кнопка **Apply height to surfaces and shadows** повторяет применение. Для нового предмета добавьте EnvironmentHeight2D к корню с рисунком/caster и примените класс. Дочерний объект с собственным компонентом получает отдельную высоту; например, высокий блок оборудования на столе. Отдельный контур такой детали всё равно нужно подготовить при авторинге.

Настройки запекаются в обычные SpriteRenderer/ShadowCaster2D и наследуются prefab-экземплярами. В игре нет поиска всей сцены, смены высот каждый кадр или извлечения контура из альфы. Положение, размер коллизий, навигация, слышимость и реакция врагов не меняются.

## Слои и свет

Порядок Sorting Layers: **ES Floor → ES Low → ES Furniture → ES Tall → Default**. Полы, ковры, разметка, кровь, гильзы и останки находятся на ES Floor; персонажи, предметы подбора и эффекты поверх окружения сохраняют Default. Order in Layer внутри своей группы сохранён. Код появления/восстановления останков явно задаёт ES Floor, чтобы смерть не оставляла тушу над высоким шкафом.

Все слои должны быть выбраны в **Light 2D → Target Sorting Layers** у нового обычного света, включая фонарь и вспышку. При добавлении нового Light2D Unity выбирает существующие слои; при копировании старого объекта проверьте список. Не удаляйте/не переименовывайте ES-слои вручную. Стандартные сохранённые префабы источников и текущие сцены уже настроены.

Default также получает обычные тени всех классов: высота живых персонажей в этой модели отдельно не задаётся. Для окружения, созданного вручную без EnvironmentHeight2D, остаются обычные настройки caster; автоматически угадывать высоту по размеру PNG система не пытается.

Потолочные лампы сохраняют [свою маску высоких стен и дверей](HOSPITAL_LAMPS.md): они светят над низкой мебелью. Новая классификация исправляет взаимные тени обычных источников, прежде всего фонаря.

## Границы

Это дискретная модель высоты поверхностей на стандартном [URP ShadowCaster2D](https://docs.unity.com/en-us/engine/6000.3/manual/unity2d/2d-urp/2d-index/2d-shadows/shadow-caster2d). Длина тени на полу остаётся плоской URP-проекцией; конечная высота источника, наклонные лучи и короткие объёмные тени здесь не моделируются. Неодинаковые маски получателей могут разделять пакеты рендера света; оценка FPS требует отдельного измерения.
