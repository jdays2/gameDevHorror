# Проверка раздавливания дверью

Открой `Assets/EmergencyShift/Scenes/DoorCrushTest.unity` и нажми обычный Play. Сцена запускается напрямую, без MainMenu. Готовый локальный Player находится в `Builds/DoorCrush01/EmergencyShift.exe`.

В коридоре слева две комнаты справа: Сталкер у начала и Спящий севернее. Серые створки у входов имеют DoorCrush2D; поперечная обычная дверь коридора оставлена без него для сравнения. Кровавые следы кормления в комнатах — отдельный статичный декор, свежая кровь появляется при смерти.

1. Подойди к входу. E открывает дверь, повторное нажатие после завершения хода закрывает её.
2. Дай Сталкеру увидеть себя через открытый проём, затем отойди в коридор. Для Спящего сначала направь фонарь на него либо попади оружием, чтобы разбудить.
3. Когда преследователь окажется под створкой, закрой её. Ловушка проверяет реальную форму и движение, поэтому слишком раннее или позднее закрытие может его пропустить.
4. Осмотри кровь/останки и повторно открой/закрой дверь: нового разрыва быть не должно. R начинает свежую пробу; рекомендуется сбрасывать между опытами с разными видами. Здоровье обычного игрока сохраняется; в контролируемом захвате агент временно выдавал 100 HP только на время Play.

Игрока дверь этой механикой не убивает. Погоня остаётся опасной: монстр может успеть укусить до закрытия.

Для новой выбранной двери используй CrushingDoor variant либо добавь DoorCrush2D к существующему Door2D. Сохрани её прежние leaf, openOffset, duration, замки и ручные параметры. Требуется solid BoxCollider2D створки в XY, без skew и Edge Radius. Отключение компонента возвращает обычное поведение. Базовый Door и старые карты не переоснащались.

Пример имеет осмысленные `00_Systems`, коридор и две комнатные группы Geometry/Gameplay/Dressing, общие prefab створки/перегородки/подписей и уникальные scene-instance ID. Он добавлен явно в конец Build Settings для штатного R; сохранённый каталог отложенного MainMenu не синхронизировался. Авто-чекпоинты здесь не включены, тест восстановления использует отдельный временный файл.

Технические свидетельства — [DoorCrush01](../Reports/DoorCrush01.md). Художественное одобрение разрыва и удобства ловушки остаётся за владельцем.
