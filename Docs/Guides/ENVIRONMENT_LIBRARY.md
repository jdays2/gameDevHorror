# Библиотека окружения и тестовая комната

Открыть `Assets/EmergencyShift/Scenes/ArtReview/EnvironmentPropsReview.unity`, затем Play. WASD — движение, мышь — направление, F — фонарь. Камера следует за игроком. Сцена предназначена для осмотра окружения, без врагов и оружейного сценария.

В комнате 16×10 units две зоны: слева бетон склада, справа плитка лаборатории. Шесть новых видов предметов и семь экземпляров, две бочки повёрнуты по-разному. Места предметов подписаны. Между зонами свободный проход; внешние стены и предметы блокируют движение. Существующие материалы пола и PNG стрелок переиспользованы; цвет/альфа разметки задаются Color.

`Concepts/Used/Environment/IndustrialProps02/index.html` — отдельный каталог с версиями 01/02, подложками и общим масштабом. [Общий лист](../../Concepts/Used/Environment/IndustrialProps02/Previews/Overview.png), [Play-комната](../Environment/Room.png). Редакция 01 сохранена; актуальные исходники/промпты и ограничения находятся в [README семейства](../../Concepts/Used/Environment/IndustrialProps02/README.md).

## Редактирование

Остановить Play. В `Environment review · warehouse and laboratory` расположены обычные объекты сцены: предметы, два Floor, подписи, стрелки, Local ambient и Inspection light. Цвет/яркость/радиусы освещения относятся только к этой комнате. У экземпляров можно менять позицию и поворот; изменение prefab затронет другие экземпляры. Уровни не пересоздаются при запуске.

Шесть готовых prefab находятся в `Assets/EmergencyShift/Prefabs/Environment/IndustrialProps02`. Основные настройки: общий FlatLit, Scale 1, Sorting Order 1, слой Walls (8), физический круг для бочки/прямоугольники для остальных, PropGroundShadow2D с LowPropShadows: контактная тень и ограниченная проекция от выбранного источника. Пол — порядок -10, разметка -9. Коллайдеры охватывают видимый основной силуэт; проходы под мебелью не реализованы. Проекция переиспользует прежний материал CreatureSilhouetteShadow и не меняет тени врагов/игрока. У мебели нет бесконечного URP-затенения как у стен; физические коллайдеры остались. Свет на компонент назначается через Flashlight и Lamps; незаданные источники оставляют только контактную тень. Это визуальное приближение, максимальное удлинение .24, opacity .13/.22 в общем профиле.

Металлический impact-аудиоматериал пока отсутствует; не заявляется новая звуковая интеграция.

Сцена не подключена к Build Settings и не заменяет MechanicsSandbox. Для проверки отдельно собиралась именно EnvironmentPropsReview, без изменения списка запуска проекта. Чекпоинтов и целей здесь нет. Builder создаёт сцену один раз, существующие файлы не перезаписывает.
