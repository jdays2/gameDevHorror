# Библиотека окружения и тестовая комната

Открыть `Assets/EmergencyShift/Scenes/ArtReview/EnvironmentPropsReview.unity`, затем Play. WASD — движение, мышь — направление, F — фонарь. Камера следует за игроком. Сцена предназначена для осмотра окружения, без врагов и оружейного сценария.

В комнате 16×10 units две зоны: слева бетон склада, справа плитка лаборатории. Шесть новых видов предметов и семь экземпляров, две бочки повёрнуты по-разному. Места предметов подписаны. Между зонами свободный проход; внешние стены и предметы блокируют движение. Существующие материалы пола и PNG стрелок переиспользованы; цвет/альфа разметки задаются Color.

`Concepts/Used/Environment/IndustrialProps02/index.html` — отдельный каталог с версиями 01/02, подложками и общим масштабом. [Общий лист](../../Concepts/Used/Environment/IndustrialProps02/Previews/Overview.png), [Play-комната](../Environment/Room.png). Редакция 01 сохранена; актуальные исходники/промпты и ограничения находятся в [README семейства](../../Concepts/Used/Environment/IndustrialProps02/README.md).

## Полная темнота

`Assets/EmergencyShift/Scenes/ArtReview/EnvironmentPropsDarkReview.unity` — отдельная копия с той же расстановкой, без светящих ламп и фоновой подсветки. Play начинается с выключенным фонарём, F включает/выключает его, WASD и камера обычные. Подписи на полу скрыты; HUD и маркер игрока остаются видимыми. [С фонарём](../Environment/DarkRoom.png), [без фонаря](../Environment/DarkRoomOff.png).

Объект `Black ambient (zero contribution)` задаёт Global Light2D с чёрным цветом и интенсивностью 0. Он ничего не освещает и предотвращает светлый запасной режим URP при полном отсутствии света. Оставить его нулевым для тестов темноты. Комната и её предметы редактируются обычным образом; в Build Settings сцена не добавлена.

## Редактирование

Остановить Play. В `Environment review · warehouse and laboratory` расположены обычные объекты сцены: предметы, два Floor, подписи, стрелки, Local ambient. Цвет/яркость/радиусы освещения относятся только к этой комнате. У экземпляров можно менять позицию и поворот; изменение prefab затронет другие экземпляры. Уровни не пересоздаются при запуске.

Шесть готовых prefab находятся в `Assets/EmergencyShift/Prefabs/Environment/IndustrialProps02`. Общие FlatLit, Scale 1, Sorting Order 1, слой Walls (8). Коллизии упрощены: круг для бочки, прямоугольники для мебели. Визуальная тень задаётся отдельно стандартным URP ShadowCaster2D с источником SpriteRenderer и Cast Shadow. Пол — порядок -10, разметка -9.

Спрайты импортированы как Tight с сохранённым контуром по альфе PNG: порог .2, детализация .05. Это убирает прямоугольник прозрачного холста и почти прозрачные фрагменты, которые давали тонкие паразитные лучи. У бочки округлый контур, у поддона сохранены выступы и отверстия. Длинные тени рассчитывает обычный URP от каждого источника; ограничение .24 и временные контактные проекции удалены. Форма движения не обязана повторять визуальный контур, проходы под мебелью не реализованы.

В Scene оставлены ручные изменения владельца, включая удаление двух Inspection light. Фонарь отбрасывает тени, Local ambient даёт слабый фон. Можно добавить обычный Light2D с Shadows Enabled — отдельные ссылки в предметах не нужны. Новый предмет использует тот же импорт контура и стандартный caster. Builder запекает контуры через внутренний Editor API текущей Unity; при смене версии API проверяется явно. В игре извлечение альфы не выполняется.

Металлический impact-аудиоматериал пока отсутствует; не заявляется новая звуковая интеграция.

Сцена не подключена к Build Settings и не заменяет MechanicsSandbox. Для проверки отдельно собиралась именно EnvironmentPropsReview, без изменения списка запуска проекта. Чекпоинтов и целей здесь нет. Builder создаёт сцену один раз, существующие файлы не перезаписывает.

## Проверка

См. [текущую проверку теней](../Validation/EnvironmentSilhouetteShadows.json) и [первоначальную проверку комнаты](../Validation/EnvironmentReview.json). Старые проверки коротких проекций в первоначальном отчёте относятся к заменённому варианту. Проверяются Play, контуры/свет, камера, ссылки, EditMode и отдельная Release-сборка. Это технические проверки и превью для художественной оценки владельцем.
