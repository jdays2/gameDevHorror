# Управление сценами и переиспользование

Срез 2026-10-22: все 11 сохранённых сцен организованы и проверены в Unity. В них нет свободных SpriteRenderer вне prefab. Это не требование превращать уникальную карту или её контроллер в один prefab: зона, служебный контекст и персональные ссылки остаются авторингом уровня.

## Где искать объекты

| Корень | Что находится внутри |
|---|---|
| `00_SceneServices` | Прежний LevelRig либо камера/игрок/HUD/ambient/audio/context; внутренние ссылки сохранены |
| `10_World` | Помещения и коридоры; внутри — Geometry, Props, Dressing, Gameplay, LightingAudio, Notes по необходимости |
| `90_ReviewStations` | Отдельные демонстрационные станции песочниц, не смешанные с основным маршрутом |
| `Pause Menu` | Исходный незавершённый draft в рабочей версии; не включён в эту публикацию |

MorgueRouteTest: `R01_Morgue`, `R02_Arena`, `R03_Store`, `R04_Hall`, три боковые комнаты, комната зелёной карты и шесть коридоров. Названия O1/O2 из старой схемы соответствуют `R06_FlashlightRoom` / `R07_ShotgunRoom`. Весь интерьер одного помещения можно выделить/скрыть через его группу. Общая стена/дверь имеет одного владельца по расположению; соседнее помещение не содержит её копию. При переносе помещения учитывать принадлежащие соседу граничные элементы.

MechanicsSandbox: безопасный коридор, тест Сталкера, тест карты/двери и оружейный тир. Демонстрационные станции сохранены отдельно. Цельная сборка BloodOverlapTargets перемещена целиком, её внутренние prefab-дети не отделялись. В BasementPrototype — лаборатория, коридор и склад. FloorMarkingsReview использует ReviewServices / Samples / ReviewNotes; другие review-сцены сохраняют тематические сборки под двумя корнями.

## Добавить содержимое на другой уровень

1. Начать с `Scenes/LevelTemplate`, сохранив свою копию сцены. LevelRig/context — один комплект на уровень.
2. Поставить prefab из подходящего семейства. Существующие мебель, двери, лампы, враги и напольные накладки сохранены; новые недостающие статичные основы находятся в `Prefabs/Environment/LevelSurfaces`.
3. У пола Tiled настраивать `SpriteRenderer Size`; у плоских меток — transform, tint и сортировку экземпляра. Цвет, размер, поворот и локальное старение нынешних накладок сохранены как overrides.
4. Для высокого блока с отделкой использовать один из трёх `FullHeightBlock-*` variants: 4.2×1.8, 4.5×1.8, 4.6×1.8 units. Это цельные наследники Wall с вложенным бордюром; новый экземпляр переносится вместе с коллизией и оформлением. Изменение масштаба растягивает всю сборку; для иной постоянной конструкции делать осмысленный вариант.
5. Для статичной крови/плоти использовать BloodDecal/FleshDecal. Это обычные освещаемые накладки, без запуска смерти/разрыва. Runtime BloodPool врагов предназначен для эффекта смерти.
6. `Prefabs/Levels/AuthoringExamples` содержит тестовый ящик бесконечных патронов и маркер диалога. У маркера на новом уровне назначить местный DialogueSession в Inspector; ссылка session в общем prefab намеренно пуста, в песочнице сохранена как override. Ящик — тестовый инструмент, не обычный конечный запас патронов.

Группирующие объекты имеют нулевые позиции/повороты и единичный масштаб. Hierarchy не управляет SpriteRenderer sorting. Не применять все overrides одного экземпляра к общему prefab: положение, патрули, ID, локальный свет и ссылки на другие сцены принадлежат уровню. Для новых копий сохраняемых объектов использовать существующий persistence-authoring только на поддерживаемой сцене; checkpoint-механику в тестовую песочницу не добавлять.

## Проверка и ограничения

Перед каждой записью миграция проверяла world matrices, active state и сериализованные scalar/reference поля существующих компонентов. Prefab-конверсия не заменяла акторов и их настройки. После сохранения проверены prefab-связи и уникальность имеющихся persistent IDs. [Отчёт](../Reports/LevelOrganization46.md) содержит точный состав, результаты и исключения.

Перегруппировка не измеряет FPS и не подтверждает баланс уровня. Новые группирующие Transform не имеют Update, коллизий или света. Существующие пустые исторические wrappers удалены; игровые объекты и визуальный рисунок не добавлялись.
