# Уровни, враги и настройки

Пути ниже относительно корня Unity-проекта. Редактировать при остановленном Play. FirstShift — демонстрация; BasementPrototype — прежняя тестовая сцена с вашими настройками; LevelTemplate — основа.

## Поставить врага

1. Перетащить `Assets/EmergencyShift/Prefabs/Enemies/ShadowStalker.prefab` в Hierarchy и расположить в Scene.
2. В ShadowStalker2D выбрать **Definition** и **Behaviour Profile** из Data/Enemies; у prefab уже назначены.
3. **Detection Radius** — близость для первого обнаружения. Нужна прямая видимость: стена/коробка закрывают игрока.
4. В EnemyPatrol2D выключить **Patrol Enabled** для засады, включить для случайных шагов до агрессии.
5. **Use Patrol Area**, **Area Offset/Size** задают индивидуальную область, редактируемую жёлтым handle в Scene. Без области — короткие достижимые перемещения рядом. Возврата в область после боя нет.
6. Ссылки игрока/фонаря можно оставить пустыми: LevelContext сцены заполнит недостающие. Blocking Geometry должна содержать стены.

## Баланс и разновидности

В Data/Enemies:

- **Stalker-Default.asset / EnemyDefinition:** HP, Pursuit Speed, реакция на попадание, дистанция/длительность/cooldown укуса, сила/тайминг выпада.
- **Stalker-Light-Default.asset:** Retreat Speed, Light Fear Distance, Reaction Delay, время сжатия/отхода/ожидания. Отход быстрее преследования.
- **Stalker-Light-BasementPrototype.asset:** сохранённая задержка .33; основной профиль .45.
- **Patrol-Default.asset:** скорость .6; **Patrol-FirstShift.asset:** .65. Паузы и длина свободного шага также в профиле.

Для варианта: выделить asset → Ctrl+D → переименовать → изменить → назначить нужным врагам. Не копировать класс AI ради скорости. Ранение в Play меняет особь, не asset.

## Лут и двери

Prefabs/Loot: PistolPickup, AmmoPickup, FlashlightUpgradePickup, AccessCardPickup. Подбор автоматический; препятствие блокирует. Amount/bonus/ID редактируются на предмете. Модули FirstShift повторяемые: +.6 дальности/+6°. Лимиты — FlashlightUpgrades игрока; UI не сообщает числовую прибавку.

Prefabs/World/Door открывается через E. Необязательный DoorAccess2D задаёт ID карты/подпись требования; тот же ID в AccessCardPickup2D даёт доступ. Door2D владеет движением/коллайдером/тенью, DoorAudio2D — звуком.

## Геометрия и свет

Wall, CoverBox, EmergencyLamp — Prefabs/World. У непрозрачного укрытия согласованы Collider, слой, тень; украшение без коллайдера свет не блокирует. Не перекрывайте коробками проходы. LocalLamp2D задаёт яркость/цвет/радиус/мерцание, но не защищает от Сталкера.

Один LevelContext, одна камера/AudioListener, один Canvas HUD на сцену. Новую карту начинайте с копии LevelTemplate/комплекта LevelRig, а не случайной смеси объектов разных сцен. Старые одноразовые setup-скрипты удалены; Play не пересоздаёт карту.

## Проверить

- За внешними стенами чёрный фон; ближайшие границы читаются.
- Закрытая дверь блокирует свет/тело/пулю, лут не собирается через укрытие.
- Засада не реагирует сквозь стену; патруль не врезается в неё; после агрессии нет возврата домой.
- После смерти одна лужа/тёмные части, живые рисуются выше.
- Game Scale/разрешение могут увеличить пиксели и обрезать HUD; используйте Fit. Scene Lighting меняет редакторский просмотр, не игровой свет.
