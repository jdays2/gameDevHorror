# План с кликабельными галочками

**[← Старт](../../README.md)** · [План](../MVP_PLAN.md) · [Карточки](../Tasks/README.md)

## Открыть

Дважды нажмите `Открыть план.cmd` в корне проекта. Он запустит локальный просмотрщик и откроет план в браузере. Повторный запуск использует уже работающий просмотрщик.

Если он уже запущен: **[открыть план →](http://127.0.0.1:8768/?doc=Docs/MVP_PLAN.md)**. Страницу можно держать во встроенном браузере Codex или обычном браузере.

## Отметить выполнение

Нажмите галочку или текст пункта. Клавиатурой: Tab переводит фокус, пробел переключает отметку. Надпись «Сохранено в Markdown» подтверждает запись. Ссылка внутри пункта открывает описание и не меняет галочку.

Отметка сразу меняет `[ ]` на `[x]` или обратно в исходном файле. Отдельной копии прогресса в браузере нет. После обновления страницы отметки сохраняются; агент читает те же Markdown-файлы.

«Скрыть выполненное» оставляет только открытые пункты. Кнопка «Обновить» загружает правки, которые агент внёс после открытия вкладки. Если файл успел измениться, сохранение галочки отклоняется с просьбой обновить страницу.

Общий пункт плана и шаги карточки переключаются отдельно: снятие итоговой галочки не отменяет уже сделанные шаги. Агент сверяет итог и критерии по [правилам учёта](../Tasks/README.md).

## Где можно менять отметки

План `Docs/MVP_PLAN.md` и карточки `Docs/Tasks/*.md`. Остальные документы, шаблон карточки и инструкции skills открываются для чтения. Игровые файлы просмотрщик не редактирует.

На скриншоте встроенный Markdown-просмотрщик оформляет заголовки и ссылки, но показывает `[x]` как текст. Простая замена значков не сделала бы их интерактивными. Для отметок используем этот локальный просмотрщик; Markdown остаётся источником данных.

## Запуск и проверки вручную

Нужен Python 3.12 или новее. Launcher ищет комплектный Python Codex и установленный `python`, пропуская WindowsApps alias. Сторонние Python-пакеты не нужны.

```powershell
python Tools/PlanViewer/server.py --open
python -m unittest discover -s Tools/PlanViewer -p test_server.py -v
```

Сервер слушает только `127.0.0.1:8768`, без публикации в интернете и фонового автозапуска Windows. После перезапуска компьютера снова откройте launcher. Чтобы остановить ручной запуск, нажмите Ctrl+C в его терминале. Для скрытого процесса можно завершить именно запущенный `server.py` через Диспетчер задач.

Проверки используют временные файлы внутри игнорируемой папки `work/plan-viewer-tests`; настоящий план тестами не меняется.
