# Больничные настенные лампы

Выберите корень лампы в Hierarchy, откройте **Local Lamp Configuration 2D → Settings**. Настройки хранятся на экземпляре сцены; соседние лампы и общий набор звуков не меняются. Редактируйте в остановленной сцене и сохраняйте её. Изменения в Play подходят для пробы, но Unity откатывает их после Stop.

| Поле | Что меняет |
|---|---|
| Color | Оттенок света, трубки и её ореола |
| Light Radius | Радиус освещения в единицах мира |
| Intensity | Яркость; 0 гасит свет и видимый ореол |
| Casts Shadows | Обычные плоские тени URP в низком режиме; потолочный режим ограничивает свет отдельной маской стен и дверей |
| Starts On | Начальное питание при запуске сцены |
| Flickers / Phase | Мерцание и сдвиг его фазы в секундах |
| Sound Radius | Дальность слышимости в XY; 0 полностью глушит лампу |
| Hum Volume / Contact Volume | Громкость гула / контактов, от 0 до 1 |
| Fixture Length | Длина корпуса вдоль стены в единицах мира |

При выделении и включённых Gizmos голубая окружность показывает свет, янтарная — звук. Это радиусы, а не диаметры. Полная заданная громкость сохраняется до 17,5% Sound Radius, затем плавно падает к нулю на границе. Стена слоя Walls глушит звук. Гул следует фактической яркости, контакты звучат при перебое. WAV и общий `Data/Audio/HospitalLampQuiet.asset` сохранены.

Размер меняйте через **Fixture Length**, оставляя Scale корня = 1. Дочерняя группа Fixture масштабирует рисунок и ореол; радиусы остаются прежними, задняя планка сохраняет привязку к стене. Длинная проба теперь 1,25, компактная 1,0; для сравнения, имеющийся шкаф — 1,55 по длинной стороне. Это стартовая настройка для оценки владельцем.

Для новой лампы перетащите `Prefabs/Environment/HospitalLamp01.prefab` или `HospitalLampCorridor01.prefab`. Все пути здесь относительно `Assets/EmergencyShift`. При Rotation Z=0 стена находится сверху, трубка выступает вниз в комнату; повороты 90/180/270 подходят для остальных стен. Центр корня разместите на 0,025 единицы внутрь комнаты от грани стены: сам источник света и звука должен быть перед стеной. Настройки скрытой калибровки Fixture и локальные положения Mount/Bulb вручную менять не нужно. Новый экземпляр получает слушателя через LevelContext своей сцены; в текущих сценах игрок также задан явно.

## Стандарт prefab и настройка высоты

Все три библиотечных prefab ламп — **HospitalLamp01**, **HospitalLampCorridor01** и **World/EmergencyLamp** — получают потолочное освещение по умолчанию. Радиус нового экземпляра **3.4**, интенсивность **1.2**. У больничных ламп эти значения меняются в Settings; у прежней EmergencyLamp — в LocalLamp2D. Индивидуальные сохранённые настройки уже расставленных ламп остаются сценовыми overrides.

В **Ceiling Light Occlusion 2D** доступны:

- **Ceiling Lighting** — свет сверху над низкой мебелью. Выключить для низко расположенного источника с обычными плоскими тенями; их включение задаёт Casts Shadows.
- **Automatically Find Blockers** — автоматически брать высокие стены и двери своей сцены.
- **Full Height Blockers** — дополнительные прямоугольные препятствия либо полный ручной список, если автоматический режим выключен.

Наши **World/Wall** и створка **World/Door** уже содержат **Full Height Light Blocker 2D**. Поэтому лампу, стены и дверь можно перетащить в другую сцену без заполнения ссылок у каждой лампы. Для самостоятельно созданной высокой стены добавьте этот компонент на объект с BoxCollider2D. Низкая мебель не получает такой маркер. Добавление/удаление/отключение стены обновляет набор препятствий; движение створки обновляет маску. Другие одновременно открытые сцены в расчёт не попадают.

## Потолочное размещение в виде сверху

В BasementPrototype лампы находятся под потолком **над** столами и тележкой. У семи светильников нет Collider2D: они не занимают место на полу. Корпуса, мебель и источник света остались на прежних XY. Интенсивность увеличена втрое, радиусы — на 30%.

Обычный ShadowCaster2D воспринимал стол как непрозрачную стену и создавал длинный чёрный сектор перед ним. Изменение Z не решает это: [URP 2D не учитывает расстояние по глубине для таких теней](https://docs.unity.com/en-us/engine/6000.6/manual/unity2d/2d-urp/2d-index/2d-light-properties-explained). Поэтому для потолочных ламп подключён CeilingLightOcclusion2D: локальная cookie-маска пропускает свет над низкой мебелью, но обрезает его по высоким стенам и створке двери. Ручной фонарь сохраняет прежние тени мебели.

В BasementPrototype автоматически находятся 12 высоких стен и одна движущаяся створка. Столы, кресла, тележки и низкие ящики не перекрывают потолочный свет. Поддерживаются прямоугольники с поворотом и масштабом; это упрощённая модель высоты для 2D, без расчёта коротких объёмных теней от мебели. Свет по-прежнему не отпугивает врагов.

Компонент владеет временными Texture2D/Sprite (128×128), обновляет маску при изменении геометрии, радиуса или положения лампы и освобождает её при отключении/выходе из сцены. В Edit Mode маска обновляется через Update, в Play — через LateUpdate после движения двери. При переключении в низкий режим восстанавливаются исходная cookie и настройки обычных теней. Яркость, мерцание и питание остаются у LocalLamp2D. [Первичная проверка и кадры](../Validation/CeilingLamps02.json), [prefab и камера](../Validation/LampPrefabAndCamera03.json).

## Границы кода

`LocalLampSceneSettings` — сериализуемые значения конкретного экземпляра. `LocalLampConfiguration2D` применяет их в Inspector/при запуске и сохраняет геометрию крепления; собственного Update у него нет. `LocalLamp2D` владеет питанием и яркостью, `LocalLampAudio2D` — двумя голосами, затуханием и последним контактом. Общие клипы остаются в LocalLampAudioSet. Без нового компонента прежние светильники продолжают использовать LocalLightProfile либо свои старые поля. При наличии компонента его Settings имеют приоритет.

Корпус использует отдельный **HospitalLampHousing** на стандартном освещаемом Sprite-Lit-Default, без собственного свечения. Чёрная однопиксельная маска материала исключает канал света трубок: Light2D этих ламп использует существующий Blend Style 2 — Multiply with Mask (R). Фонарь и остальные обычные источники на Blend Style 0 освещают корпус. Сами трубки и ореол остаются на TubeGlow; при отключении питания они гаснут. Маска — технические данные, исходные рисунки не изменены. Корпус рисуется order 3, трубка order 4, стены этих сцен order 2: крепления не пропадают за стеной из-за равного порядка. Эти технические настройки на prefab менять не нужно.
