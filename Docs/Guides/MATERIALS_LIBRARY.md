# Библиотека материалов

Корень: `Assets/EmergencyShift/Materials`. Материалы и связанные шейдеры/маски сгруппированы по назначению. Имя шейдера внутри Shader.Find и GUID ресурса не зависят от имени папки.

| Папка | Содержимое |
|---|---|
| `Shared` | FlatLit и FlatUnlit — общие базовые материалы |
| `Environment/Floors` | Пять материалов пола и FloorWorldLit.shader |
| `Environment/Lighting` | Корпус/маска больничной лампы, трубка/TubeGlow, PropEmission и три материала практических источников света |
| `Characters` | Тень силуэта существа и поверхность глаза Сталкера со своими шейдерами |
| `Effects` | MuzzlePlume и TransientGlow со своими шейдерами |
| `Physics` | NoFriction.physicsMaterial2D |
| `Development` | Изолированная проба FurnitureLightStudy и её шейдер |

Перед добавлением материала проверьте, подходит ли существующий. Отдельный ресурс нужен для устойчивого визуального отличия, а не для каждой копии prefab. Настройки общего материала принадлежат библиотеке; индивидуальные эффекты используют существующий механизм renderer/MaterialPropertyBlock. Папка Development обозначает назначение, но сама по себе не исключает ресурс из сборки: включение определяется зависимостями выбранных сцен.

Новые материалы сохраняются сразу в тематическую папку. Шейдер и маска с одним владельцем лежат рядом с семьёй; общие ресурсы остаются в Shared. При росте отдельной семьи можно выделить вложенную папку без копирования её ресурсов. Не создавать пустые категории заранее.

Перенос выполняется через Unity AssetDatabase при остановленном Play, с сохранением `.meta`/GUID, значений и несохранённой сцены. Обновляются прямые и составные пути редакторских инструментов и действующих импортёров. Датированные отчёты/исходная provenance сохраняют адрес на момент проверки; актуальное соответствие находится в [реестре переноса](../Reports/MaterialsOrganization01.json) и Concepts/catalog.json.
