# Пустая комната для расстановки и проверки света

Сцена: `Assets/EmergencyShift/Scenes/ArtReview/LightingPlayground.unity`.

Комната 24×16 units: плиточный пол, четыре внешние стены с коллизиями и тенями, обычный LevelRig с игроком, камерой, HUD и фонарём. Мебели и врагов изначально нет. Это сохранённая сцена для ручной работы; генератора при запуске нет. Прочие сцены и список Build Settings не изменены.

1. Остановите Play и перетаскивайте готовые **prefab** из `Assets/EmergencyShift/Prefabs/Environment` в корневой объект `Props - drop environment prefabs here`. У prefab уже есть нужные материалы, игровые коллизии и теневые компоненты. Перетаскивание одного PNG этих компонентов не создаёт.
2. Меняйте положение/поворот объектов и сохраняйте сцену через Ctrl+S. Расстановка, сделанная во время Play, не сохранится после его остановки.
3. Нажмите Play: WASD — движение, мышь — направление, F — фонарь. Фонарь включается при старте; камера обычная и следует за игроком.

В `Lighting - optional test sources` находятся два выключенных объекта. Включайте их галочкой активности GameObject:

- `Side light with shadows - enable object to test`: тёплый боковой Light2D с обычными тенями, радиус 5.
- `Ceiling light - enable object to test`: холодный источник без плоских теней для сравнения освещения сверху, радиус 7.

Позиция, радиус и интенсивность редактируются в Inspector. Слабая постоянная подсветка `Faint ambient - keep enabled` находится внутри LevelRig. Для полностью чёрной комнаты уменьшите её Intensity до 0, сохранив сам Global Light2D включённым.

В Scene View выключено отображение игрового освещения для удобной расстановки; Game View использует настоящий свет сцены. Принятый материал C остаётся реализованным на трёх образцах в FurnitureLightStudy: эта пустая комната использует обычные материалы добавляемых prefab, без скрытой автоматической перенастройки мебели.
