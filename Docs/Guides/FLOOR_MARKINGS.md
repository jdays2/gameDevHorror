# Разметка пола: PNG, композиции и цвет

Первый набор создан по запросу владельца: белая краска с прозрачными просветами, лёгкими потёртостями и одинаковой фактурой. Цвет задаётся экземпляром в Unity. Окончательный художественный вид пока на оценке владельца.

## Что готово

- 16 отдельных PNG RGBA, 512×512, в `Assets/EmergencyShift/Art/Environment/FloorMarkings`.
- 20 готовых префабов в `Assets/EmergencyShift/Prefabs/Environment/FloorMarkings`: 16 основных и четыре варианта длины прямых линий.
- Обзорная сцена `Assets/EmergencyShift/Scenes/ArtReview/FloorMarkingsReview.unity`: каталог, одна стрелка трёх цветов, соединённый маршрут, рамка и короткая/длинная линия. Это отдельная арт-проба, не уровень для прохождения; в Build Settings она не включена.

| Имена | Элементы |
|---|---|
| thin-straight / corner / tee / cross | Тонкая прямая, угол, Т-соединение и крест |
| thick-straight / corner / tee / cross | Те же соединения с толстой полосой |
| arrow-forward / turn / double | Прямая, поворотная и двусторонняя стрелки |
| chevron | Отдельный шеврон |
| thin-dashes / thick-dashes | Пунктир двух толщин |
| thin-end / thick-end | Скруглённое окончание двух толщин |
| thin-/thick-straight-short / long | Прямые длиной 1 и 4 units из прежних PNG |

## Разместить и перекрасить

1. Перетащить нужный prefab на пол сцены.
2. Выбрать его **Sprite Renderer → Color**: жёлтый, красный, голубой или любой другой оттенок. Альфа цвета управляет общей прозрачностью. При нескольких выделенных SpriteRenderer цвет можно изменить сразу всей композиции.
3. Поворачивать модули кратно 90°. Для соединений использовать шаг сетки 2 units: порты находятся в середине граней квадратной ячейки 2×2. Исходный L-угол направлен вверх/вправо, Т-соединение — влево/вправо/вверх.
4. Прямые используют **Draw Mode: Tiled**. Менять длину через **Size X**, оставляя **Size Y = 2**, чтобы сохранялись толщина и масштаб фактуры. Готовые short/обычная/long имеют длины 1/2/4. Для произвольной длины лучше сначала проверить композицию; длины кратно 2 сохраняют фазу повторения между модулями.

Толщина краски: thin 0.125, thick 0.25 units. У соединений pivot в центре, Scale 1. Стрелки — отдельные знаки внутри ячейки, а не универсальные соединительные порты. Поворотную стрелку можно соединять по левому входу.

## Почему один PNG подходит для всех цветов

RGB каждого пикселя PNG — белый, включая прозрачные пиксели. В альфа-канале записаны силуэт, зерно и стёртые участки. Color умножает белый на выбранный оттенок; дырки показывают фактический пол, а не нарисованное серое пятно. Цветных копий PNG и отдельных материалов для каждого цвета нет. Сглаживание Bilinear отвечает за края, не за перекраску.

Общий `FlatLit` обеспечивает реакцию на 2D-свет. Префабы имеют Sorting Order -9 при обычном полу -10; при ином порядке слоёв в новой сцене его нужно согласовать. Коллайдеров, ShadowCaster, Light2D, Update и скрипта управления цветом на разметке нет. Светящейся краской этот набор не является.

В MorgueRouteTest для двух карточных дверей сохранены три геометрических варианта белой основы с цветной рамкой, полосатой каймой или двойным П-контуром. Прежний трафарет карты отклонён и снят со сцены. Новые PNG используют фактуру существующей краски; сами линии основного набора не менялись. Цвет соответствует уровню доступа; разметка остаётся матовой. [Размещение и звуковой отклик](MORGUE_ROUTE_TEST.md#проба-карточных-дверей).

## Источники и повторение подготовки

Фактура создана встроенным imagegen. Контуры и порты растрированы отдельно, чтобы соседние модули точно соединялись. Покрытие сгенерированной фактуры переведено в альфу; у самых краёв соединительных портов оно плавно доводится до плотного покрытия, чтобы повторение не создавало светлых/тёмных швов.

Команда **Emergency Shift → Art → Generate floor marking assets** работает только в остановленном Editor. Она повторно экспортирует 16 PNG из сохранённой маски, настраивает импорт и создаёт отсутствующие префабы. Существующие префабы сохраняются; ручная правка самих PNG при повторной генерации будет заменена. Игровые сцены команда не изменяет, при Play ничего не генерируется. Общие FlatLit и LevelRig не изменены.
