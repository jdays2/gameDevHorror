# Тени окружения

Статус на начало архитектурного прохода 2026-10-19: Авторинг контуров и URP-тени реализованы; физическая высота мебели не моделируется.

Архитектурная цель — [ADR-001](../Decisions/001-sod-architecture.md); фактическая карта ниже перенесена из ARCHITECTURE без изменения поведения. При кодовой миграции обновлять её по исходникам.

## Контуры теней окружения

Окружение использует стандартный URP ShadowCaster2D с источником SpriteRenderer, Cast Shadow и alphaCutoff .2. Provider берёт треугольную сетку спрайта: FullRect давал прямоугольную тень прозрачного холста. Общий Editor-импорт EnvironmentSpriteAuthoring читает текущий PNG напрямую, генерирует Tight-контур с порогом .2 и детализацией .25, затем ограниченно упрощает сложные контуры с допуском 2 исходных пикселя и проверками площади/пересечений. Sprite Editor data provider сохраняет render outline; GUID, активные pivot/PPU и ссылки сохраняются. Контур находится в .meta, runtime не анализирует пиксели. Внутренний SpriteUtility.GenerateOutline изолирован в авторинге и явно проверяет совместимость версии Unity. [Аудит 41 предмета и границы производительности](../Environment/FURNITURE_SHADOW_SHAPES.md).

Длину и направление считает URP для каждого Light2D. Временные PropGroundShadow2D, PropShadowProfile и LowPropShadows удалены. Коллайдеры движения/лучей остаются простыми и независимыми от визуального контура. Камера, защитные свойства света, AI, тени Сталкера/игрока и их общий материал не меняются. Это стандартные 2D-тени, без физической модели высоты предмета.
