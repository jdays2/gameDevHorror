# Общие параметры игрока и сценовые overrides

`Data/Player/PlayerRules.asset` — общий неизменяемый SO здоровья/защиты, скорости, дистанции взаимодействия и подбора, допуска выбора цели и очереди уведомлений. WorldInstaller проверяет профиль до любых bindings и создаёт неизменяемый `PlayerRulesSettings`. Текущий HP, временный предел и направление остаются в личных моделях.

Стандартный world требует ссылку на профиль. Необязательный аргумент фабрик оставлен для явно создаваемых standalone/test adapters: он использует неизменяемые прежние значения. Production composition не подменяет отсутствующий asset этим fallback.

## Совместимость ручного авторинга

Старые имена/значения полей PlayerLife, PlayerMotor и PlayerInteraction сохранены. Политика выбора явная:

- Поле равно прежнему default — используется текущее значение общего профиля.
- Поле отличается от прежнего default — это сохранённый authored override, он имеет приоритет.
- `Use Authored Rules` — принудительный override всех полей данного компонента, включая значения, совпавшие со старым default.

Поэтому HP=3 в песочнице сохраняется при общем HP=2. Для перехода старого override на shared tuning нужно вернуть соответствующее поле к прежнему default и выключить Use Authored Rules. Прежние defaults названы в `PlayerRulesSettings.Legacy*`: это маркеры совместимости, не текущий баланс. Компоненты не пишут в SO; значения проецируются при composition/Awake. Изменение Inspector после построения модели не пересоздаёт её автоматически.

PlayerLife.MaximumHealth читает личный предел модели. Временная ёмкость больше не перезаписывает authored maximumHealth; RestoreHealth ограничивается текущим пределом. Motor и interaction factories используют общий профиль с указанными overrides; native pickup overlap и точная проверка расстояния используют один разрешённый радиус модели.

## Настройка

Общие значения менять в PlayerRules.asset до Play. Индивидуальные значения задавать в нужном компоненте сцены/prefab. Ссылки на двери, blocking layers, позиции и маршруты остаются авторингом уровня. Профиль не хранит состояние инвентаря, оружия, фонаря или врагов.

Текущие параметры сохранены: HP2, защита.7с, скорость3.5, reach1.6, pickup.65, tie.05, уведомление1.8с, очередь8. Источники/сценарии проверки — [индекс](../Reports/ValidationIndex.md). Остальные аудио/дверные/lamp-настройки и общий SOD-проход учитываются отдельно в Notion.
