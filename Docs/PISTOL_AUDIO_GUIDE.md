# Пистолет и падающие гильзы — v0.8.3

Пользователь выбрал оружие **№3 (небольшое помещение)** и гильзы **№6 (бетон)**, затем запросил небольшую вариативность, адаптацию и игровую запись. Эти звуки теперь назначены сохранённой сцене и включены. Подбор/баланс/свет/AI прежние. Прежний процедурный пистолет не возвращён; одобренная мембрана сталкера сохранена.

## Что сделано со звуком

Предыдущий пример уже был нарезанным MP3-превью с линейным уровнем, а не исходной raw-записью микрофона. Теперь выстрел дополнительно обработан: фильтр ниже45Hz, очень мягкое широкое выравнивание низких/высоких частот, более короткий хвост отражений после первых65ms. Атака сохраняется, добавленного синтетического баса/свиста/ревербератора нет. Выстрел длится около.58с; несколько источников позволяют следующему выстрелу начаться без обрыва предыдущего хвоста.

**Шесть вариантов выстрела — близкие обработки одной выбранной записи**, а не шесть разных записанных выстрелов. Небольшие отличия EQ/затухания поддерживают характер одного пистолета. В игре добавляются pitch±.8% и уровень±.4dB, немедленный повтор того же варианта исключён. Это тонкие изменения, без превращения каждого выстрела в другое оружие.

Гильзы — **шесть разных записанных падений на бетон**, нарезанных из выбранного источника. Подрезаны края/гул, немного смягчена резкость, динамика дублей сохранена одним общим коэффициентом. Клип уже содержит мелкие отскоки: он запускается только один раз, при первом касании пола. На последующих визуальных отскоках целая запись не повторяется.

Источники: [Brokenphono — Gunshot_001](https://freesound.org/people/Brokenphono/sounds/344143/), [GrayJoy — brass on concrete](https://freesound.org/people/GrayJoy/sounds/210102/), на обоих страницах CC0. Сохранились публичные MP3-превью и авторство в `Docs/Audio/WeaponRealism02/Sources`. Это качество превью, **PCM24/48k экспорт не восстанавливает lossless-детализацию**. Для финального производства остаётся желательным получить оригиналы выбранных записей. Происхождение/параметры обработки — `Docs/Audio/PistolIndoor/manifest.json`.

## Проверка в игре

1. Открой BasementPrototype, нажми Play, найди пистолет. Автоподбор до.65 работает как раньше.
2. Стреляй ЛКМ. Слышен выбранный выстрел, из оружия вылетает маленькая латунная заглушка.
3. Через физический подлёт примерно.23–.30с в записи гильза касается пола и звучит; затем остаётся на месте. Время не задано фиксированной задержкой аудио — его определяет движение гильзы.
4. Измени направление/постреляй рядом со стеной. Гильза учитывает высокие и низкие препятствия8|9, не блокирует игрока/пули/врагов.
5. Для сравнения выключи **Player → Player Casing Ejector 2D → Casings Enabled** в Play: следующие выстрелы продолжатся без новых гильз. Уже выпущенные успеют приземлиться. После Stop сохранённый флаг снова true.

На полу остаются максимум48 косметических гильз игрока; дальше переиспользуются старые. Это ограниченная коллекция эффектов, а не данные сейва/инвентаря. Никаких AudioSource на каждой гильзе нет. Перезапуск комнаты убирает выпущенные гильзы.

## Материал пола

При первом приземлении `GroundAudioSurface2D.At(position)` возвращает поверхность **пола под гильзой**, а не материал мишени пули. Без региона — Concrete, что соответствует текущему уровню.

Для будущего дерева/плитки создай пустой объект, добавь GroundAudioSurface2D. BoxCollider2D будет trigger; растяни его по нужному участку пола, оставь на Default0. Surface выбирает Concrete/Wood/Tile, Priority определяет приоритет перекрывающихся регионов. Сам region не рисует текстуру и не меняет физику пола. В PlayerAudioSet поля Wood Casings/Tile Casings пока пусты: они явно используют бетонный fallback до появления нужных записей. **Не считать другой материал уже озвученным фильтром**.

ImpactSurface2D по-прежнему отвечает за конечную мишень пули. Эти две задачи нельзя объединять: попали в мясо, а гильза упала на бетон.

## Почему архитектура такая

```text
PlayerWeapon2D.ShotFired
├─ PlayerAudio2D → вариант/pitch/gain → один из4 Shot AudioSource
└─ PlayerCasingEjector2D → PistolCasing.prefab из ограниченной коллекции
   └─ ShellCasing2D → движение/подлёт/первое касание пола
      └─ GroundAudioSurface2D.At → PlayerAudio2D.PlayCasingAt → один из8 Casing AudioSource
```

Оружие определяет факт выстрела/расход патрона и не выбирает звук. Эжектор подписывается на тот же факт, поэтому пустой патронник/отклонённый cooldown не выпускают гильзу. Когда дуло перекрыто стеной, патрон реально потрачен, поэтому гильза всё равно одна. ShellCasing2D только косметический объект: виртуальная высота, движение по XY, небольшой визуальный отскок и остановка. Он не наносит урон и не участвует в общем инвентаре.

Основной звук и гильзы имеют отдельные RNG: отключение гильз не меняет последовательность оружейных вариантов. Собственная случайность не перетасовывает AI/процедурную кровь. Для записи используются только Editor-методы с явным seed; обычная игра использует независимые случайные состояния.

PlayerAudio2D имеет сохранённые каналы:1 подбора,4 выстрела,4 импакта,8 гильз —17. Вместе с14 источниками7 сталкеров в текущей сцене31 источник и один listener. Число источников не равно числу одновременно звучащих голосов. Занятый пул гильз пропускает лишний звук; при нынешнем темпе.3с8 каналов хватает проверенной серии. Настройка оружия на существенно более частый огонь потребует нового теста микса/производительности. Ранение/разрыв сталкера не дублируются generic Flesh.

Гильза следует по полу через CircleCast8|9, высота отдельная. В строго верхней камере подлёт читается размером и контактной тенью; это стилизованное 2D-представление, не 3D-баллистика. После остановки компонент Update выключается, след на полу остаётся. Коллекция48 объектов переиспользует старые следы вместо бесконечного Instantiate.

## Производство, настройка и проверки

`Tools/Audio/prepare_pistol_runtime.py --ffmpeg <полный-путь>` воспроизводит12 WAV из сохранённых CC0-источников. Для замены существующих WAV требуется `--force`. NumPy2.3.5/FFmpeg7.1 — офлайн-инструменты; игра использует готовые клипы. Данные processing/windows/SHA сохранены. У импорта PCM/DecompressOnLoad/Preload/Normalize=false, mono гильзы и stereo выстрелы48k.

Меню **Emergency Shift → Audio → Apply selected indoor pistol and concrete casings** записывает выбранный набор/эжектор/префаб и источники в активную сцену. При повторном вызове уже выбранные уровни/флаги сохраняются. PlayerAudioSetup обеспечивает минимум4/8 разных ссылок, исправляя типичное дублирование последней ссылки при росте SerializedProperty-array. Редакторские инструменты не строят уровень при запуске.

**15/15 интеграционных проверок Play**: реальные выстрелы, отсутствие раннего звона, первое касание один раз, диапазоны/различие вариантов,13 звуков после13 выстрелов с тестовым пулом8 объектов, выключение гильз, регион пола/fallback, закрытое дуло, остановка/однократная подписка аудио, смерть игрока и уже летящая гильза. DSP shot≈.5793/casing≈.1101/mix≈.5805. Видеозахват480 кадров/768000 stereo sample frames =16с;14 выстрелов,7 настоящих приземлений только во второй половине, совпадающая последовательность/pitch/gain, задержки.233–.300с, peak≈.5817. Оба MP4 полностью декодированы.

Это реальные Play/DSP/видеопроверки и визуальный просмотр кадров, а не субъективное прослушивание моделью. Оценку адаптированного тембра/баланса даёт пользователь. Полный микс со всей угрозой, Profiler толпы и самостоятельный Windows-билд не проверены этой задачей. Факты: `RuntimeValidation.json`, `UnityImport.json`, `Validation.json`, `RecordingValidation.json` в Docs/Audio/PistolIndoor.
