## Что сохранено

BloodTraces05, BloodPools01, плоть и варианты останков используются действующим контентом. Общие круговые формы и исторические ID останков нужны восстановлению старых снимков. Неиспользование в стартовой сцене не означает ненужность библиотеки: остаются модули разметки, prefab для авторинга, шаблон уровня, системы чекпоинтов и отдельные ArtReview-сцены.

Принятые аудиоклипы не меняются. Три промежуточных WAV, из которых собирается текущий FirearmMix02, скопированы без изменения байтов в `Concepts/Used/Audio/FirearmMix02/Inputs`; процессор и manifest используют новый путь. Исходные записи, авторы, лицензии и обработка действующих семей сохранены. Метаданные удалённых материалов собраны в [retired-sources.json](../Concepts/retired-sources.json); это исторические записи происхождения, не требования к игре.

Не удаляются текущие варианты UI, референсы владельца, редактируемая схема демо, исследования нового рисунка Спящего и непринятые материалы из незавершённых задач. Пользовательские сцены не пересоздаются и не сохраняются этой очисткой.

## Проверка и восстановление

`Tools/Maintenance/audit_content.py` строит статический инвентарь ссылок и проверяет локальные Markdown-ссылки. Список без входящих GUID — кандидаты для ручного разбора; C#-типы, динамически загружаемые ресурсы и инструменты авторинга требуют отдельной проверки. Перед удалением Unity проверяет зависимости всех оставляемых сериализованных ресурсов; отсутствие ссылки только из Build Settings недостаточно.

Резервная копия подготовленного набора находится вне Assets в `Temp/content-cleanup-backup-2026-10-18.zip`; manifest содержит исходные пути и хеши. Temp не входит в Git и не является долговременным архивом. Версии tracked-файлов сохраняются в Git. Сборка и игровой регрессионный прогон этой очисткой не подменяются.

После очистки: 0 новых неразрешённых GUID, 0 битых локальных Markdown-ссылок; Unity прочитал 281 prefab/data assets без потерянных скриптов или основных объектов. Console: 0 ошибок/предупреждений. У 1674 оставляемых файлов проверены хеши: изменился только BasementPrototype в параллельной задаче; очистка не записывала сцену. Runtime/сборки не менялись, игровой прогон и сборка не повторялись.
