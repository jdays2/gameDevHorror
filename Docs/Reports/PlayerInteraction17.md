# Выбор интеракции и уведомления игрока

Дата: 2026-10-21. База `a38aed5`. Features/Interaction разделяет личную InteractionSelectionModel, controller/InteractSelectionCommand и PickupNoticeModel/ShowPickupNoticeCommand. Immutable settings копируют reach, допуск расстояния .05, длительность уведомления 1.8 и предел очереди 8. Время внедряется через IGameClock. Model не хранит Unity targets: только transient index текущего запроса, который не является save/entity ID.

Native PlayerInteraction сохраняет API, serialized fields и ItemCollected. Он находит двери из scoped registry и локальные colliders, проверяет LOS и отображает выбранный IInteractable. Прежний приоритет по дистанции/направлению и порядок кандидатов сохранены; command повторно проверяет actor/target перед действием. Очередь уведомлений ограничена, старейшее ожидающее сообщение вытесняется как раньше. Во время modal block очередь не переключается, истёкшее сообщение скрывается по scaled clock; disable очищает цель и всю очередь.
