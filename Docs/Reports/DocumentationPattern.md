## Перенос

| SOD | Emergency Shift | Результат |
|---|---|---|
| README с «зачем/когда читать» | Docs/README | Текущий этап и тематическое чтение, без обязательного чтения всего каталога |
| Roadmap + этапы | Roadmap, Roadmap/00–02 | Топ-приоритет владельца, реальное состояние прототипа, отдельные будущие игровые решения |
