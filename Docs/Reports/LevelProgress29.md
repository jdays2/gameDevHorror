# Цели и прохождение уровня · LevelProgress29

Проверено 2026-10-22 после `30eb1d0`. Это завершённая граница состояния/команд уровня, не завершение общего SOD-переноса.

## Что изменено

`ObjectiveProgressModel` хранит личные phase/text и выбирает первую подходящую строку по прежнему порядку. Refresh/Configure проходят команды и controller; Unity-инвентарь предоставляет только `IObjectiveFacts`. `ObjectiveRuleSet` копирует валидированные immutable rules, не содержит Unity Object и не выдаёт исходный массив. Настройки перечитываются при Configure или повторном включении, без опроса Inspector каждый кадр. Нет совпадения — прежнее состояние; совпадение повторно уведомляет, как раньше. Фазы не принудительно возрастают.

`LevelRunModel` хранит completion и elapsed с внедрённым scaled `IGameClock`. Start идемпотентен, Restore не перезаписывается поздним Start; конечное отрицательное время по прежнему clamp-ится к нулю, NaN/Infinity отклоняются до изменения. Finish проверяет живого владельца и доступ, фиксируется один раз до остановки участников, затем уведомляет. Время после Finish продолжает идти, как раньше. Restart-команда отклоняет незавершённый run и повторный вход; environment очищает checkpoint и перезагружает ту же сцену. Guard освобождается и при исключении среды.

`LevelProgressInstaller`/factory подключены к LevelContext; каждый native owner получает отдельные модели. У обоих controller по две зависимости; фабрика принимает clock. MonoBehaviour сохраняют поля/публичные фасады, сценовый выбор игрока, Unity-подписки, обход участников своей Scene, Input Actions и SceneManager. Они не ищут другую сцену для доменных правил. Новых конфигов/балансных чисел нет.

## BUG-027 и доказательство

Исходный Configure целей менял ссылки, оставляя старые подписки. Настоящий PlayMode baseline: **0/2** — новая карта не обновляла цель, событие старого инвентаря продолжало вызывать Changed. Теперь preflight rules выполняется до мутаций, затем снимаются фактически подписанные источники, заменяются ссылки и подключается одна подписка к новым. Disable/Destroy снимают точные источники. Невалидный Configure сохраняет прежние связи. Схема решения прикреплена к карточке Notion.
