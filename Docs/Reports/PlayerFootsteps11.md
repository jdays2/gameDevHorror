# Шаги игрока · личное расстояние и cadence

Дата: 2026-10-21. База `b214308`. Из PlayerFootsteps2D выделены чистые PlayerFootstepModel/settings, ResetFootstepCommand и controller. Модель получает IGameClock, фактическую позицию/скорость и разрешение движения; она не знает Rigidbody, аудио или устройства ввода. Controller передаёт разрешённый контакт IPlayerFootstepView. Factory/installer подключены через LevelContext, модели личные.

Сохранены прежние дистанция контакта, минимальный интервал, проверка телепорта >2, пороги физического/кадрового сэмплирования, выбор покрытия, чередование источников, защита от повтора клипа, cosmetic RNG и принятые звуки/громкость. Render-кадр без нового physics-перемещения сохраняет незавершённый шаг, пока тело движется; фактическая остановка его очищает. Disable останавливает оба источника и сбрасывает личный stride. Невалидные числовые входы не создают ложный контакт.

**690/690 EditMode**: 19 новых случаев расстояния/cadence, render/physics bridge, стены, телепорта, запрета движения, cooldown/reset, изоляции, отказа некорректной команды/clock/config и восстановления после плохого sample. 1000 чистых Sample после прогрева — 0 managed bytes. **32/32 PlayMode**, включая существующий AdaptiveAudioProbe: действительное движение по трём покрытиям, телепорт без контакта, тишина при стоянии и после смерти. Это проверка воспроизведения/счётчиков, не новая слуховая приёмка.

Обычная Windows64 success, собственная Player-сборка только EmergencyShift.Runtime. Source hashes совпадают с тестовой копией; 1794 защищённых ресурса, включая звуки, не изменились.
