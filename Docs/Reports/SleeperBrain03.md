# FSM Спящего · MVC/DI

Дата: 2026-10-21. База `5042f6c`. Видовой цикл перенесён без изменения prefab, art, заданных значений и формата Snapshot.

`SleeperModel` хранит состояние, постоянную агрессию, накопление/затухание засветки, возраст фазы, stagger и направление выпада. Две зависимости — immutable SleeperSettings и IGameClock. Пробуждение, атака, завершение, stagger, смерть и restore проходят команды; собственный Step продвигает таймеры. Модель не хранит SO, Transform, MonoBehaviour, контроллер или View. Загрузка молча восстанавливает значения и относительный stagger.

`SleeperController` связывает модель с отдельными интерфейсами locomotion и melee. Это три явные зависимости, исключение для координации двух исполнителей одной FSM. Он проверяет готовность melee только в Hunting, передаёт зафиксированное направление, затем завершает атаку и выдерживает recovery. Адаптеры интерфейсов делегируют существующим EnemyMotor2D/EnemyMeleeAttack2D; не прячут clock, configs, input или другие сервисы. Команды создаются на переходах/попаданиях/restore, не в каждом шаге атаки.

`Sleeper2D` сохраняет авторские ссылки и поля, публичные enum/API/events, native physics/death lifetime, подписки и DTO. Он собирает value-наблюдение из perception и передаёт fixed dt; собственных FSM-таймеров и чтения Time.time в нём больше нет. Снимает handlers при Destroy. Звук и анимация получают прежние события. Настройки копируются через SleeperBehaviourProfile.ToSettings; остальные public API/валидация SO ещё входят в общий config-pass.

**604/604 EditMode**, включая 16 новых случаев для светового накопления/затухания, постоянной агрессии, target death, точного направления, recovery, выключенных атак, прерывания и crowd-free stagger, тихого/атомарного restore, часов/настроек и независимых экземпляров. Прежние 588 случаев также прошли до добавления новых проверок.

**23/23 PlayMode**: новый тест запускает настоящую FSM prefab через LevelContext/MechanicsSandbox. Близость не будит; реальная стена перекрывает настоящий направленный фонарь; снятие стены даёт накопление и пробуждение; выключение луча не снимает агрессию; игрок уходит вбок после начала атаки и не получает довёрнутый укус; restore не испускает state events; летальный урон даёт одну смерть и отключает физику. Для проверки направления тело зафиксировано на месте, остальные враги выключены. Это полноценный локальный цикл этой FSM, не маршрут всей карты и не оценка анимации/звука владельцем.

Обычная Windows64-сборка и хеши — [SleeperBrain03.json](../Validation/SleeperBrain03.json). Копия содержит исходные принятые незавершённые изменения паузы; ресурсы/слоты игрока не менялись. FPS не измерялся. Цена: личные model/controller и два небольших адаптера при создании, value-вызовы каждого существующего FixedUpdate; дополнительные Update, глобальные списки или физические запросы не добавлены.

В документации текущий SLEEPER укорочен до фактического поведения/параметров/границ. Уникальное старое обсуждение сохранено отдельно в Archive с явной исторической областью; его фразы «не реализовано» больше не противоречат текущей инструкции. Перенос Сталкера и другие части общей задачи продолжаются.
