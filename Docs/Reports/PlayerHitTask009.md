# TASK-009 · отклик принятого урона

## Независимая подготовка · 2026-11-04

В [семье аудиопроб](../../Concepts/Unused/Audio/PlayerHitTask009/README.md) сохранены три реальные звуковые семьи, исходные MP3, точные генерационные prompts/task IDs, четыре монтажные вариации на направление, одиночные/серийные и контекстные WAV. **B рекомендован как рабочий, художественная оценка владельцем открыта.** A — сухой контакт, B — плоть/ткань, C — контакт с коротким выдохом без утверждённого характера голоса.

Воспроизводимый процесс — [prepare_audio.py](../../AgentScripts/Task009/prepare_audio.py). PCM16 mono48k, базовые LUFS −25.25/−25.21/−25.17, peak≤.68; варианты 0.284–0.356s, изменение скорости до2.1%, уровня менее0.5dB. Preview gain .8. Контекстные монтажи имеют peak≤.54, цифрового clipping нет. Измерения — [processing.json](../../Concepts/Unused/Audio/PlayerHitTask009/processing.json). Это техническая сопоставимость, не свидетельство слуховой приёмки.

Контекстные WAV используют одинаковые существующие игровые samples (пистолет .45, шаг .24, подготовка/бросок Сталкера .22). Это **offline-монтаж**, не игровой прогон. Фактический runtime-пример с текущим UI пока не записан.

## Предварительное исследование текущего контракта

Снимок до получения game lease; после чужих изменений подлежит свежей сверке. Исходные hashes — [prelease-source-hashes.json](../Validation/PlayerHitTask009/prelease-source-hashes.json).

- `PlayerUtilityAudio2D` подписан только на `Flashlight2D.PowerChanged` и `PlayerWeapon2D.EmptyTriggerPulled`. Сохранённый источник используется для этих двух сигналов.
- `PlayerWorldAudioSet` и текущий `Audio/PlayerWorld/PlayerWorldAudio.asset` содержат шаги, фонарь и сухой спуск; массива/клипа hurt или death нет. Строка AUDIO_GUIDE о ранении/поражении не подтверждается этими файлами.
- Поиск runtime-подписок на `PlayerLife2D.Damaged` нашёл HUD и визуальную реакцию, аудиоподписки не найдены. Живой сценарий ещё не проверен; отсутствие слышимого звука не объявлено воспроизведённым дефектом.
- `PlayerLifeController.TakeDamage` сначала выполняет команду здоровья. При отказе не вызывает View; при успехе вызывает `PresentDamage`, затем `PresentHealth`. `Damaged` содержит фактически снятое HP и вызывается в том числе на последнем ударе. Restore/SetCapacity идут через `PresentHealth` без `PresentDamage`.
- Общий `EnemyMeleeController` вызывает `TryDamage` один раз при strike; реальное принятие принадлежит здоровью. Звуковая логика не должна вызывать эту команду и не подписывается на windup/Resolved вместо факта урона.
- BUG-053 принадлежит WorldAudio; новый мировой голос требует явного `WorldAudioBus.Route`. Смерть без музыки, визуальная правка TASK-006 параллельно ожидает своего слота; её актуальное состояние необходимо перечитать перед интеграцией.

Игровые Assets, C# и Editor на этой стадии не менялись. Место в актуальной очереди зарегистрировано своим thread ID; независимые материалы выполняются под files-резервом. Техническая реализация/проверки и итоговая оценка сохраняются в карточке TASK-009 по мере фактического выполнения.
