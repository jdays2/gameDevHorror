# BL-001: реестры и сервисы работы

Дата: 2026-10-19. Продолжение после `8bbd57e`. Весь архитектурный проход остаётся открытым.

`SceneRegistry<T>` заменяет изменяемые static-списки дверей, CrowdAgent и голосов Сталкера. Каждый уровень получает свои экземпляры и освобождает их при завершении. Номер регистрации — временный порядок, не persistent ID. Потребители получают контракт через DI; внешние ссылки и позиции в сценах этим этапом не менялись.

История выбора клипов смерти принадлежит миру и освобождается с ним. Банки не меняются, повтор клипа подряд по-прежнему исключён, один допустимый клип остаётся рабочим. Косметический RNG отделён от потоков навигации.

Существующие квоты 2 построения пути и 32 создаваемых фрагмента за кадр теперь используют общий чистый FrameWorkBudget с IFrameClock. Две совместимые оболочки сохраняют прежние имена/метрики. Это перенос владельца уже существующей работы, не новый OPT-01. Останки не удаляются ради квоты. Путь особи получает часы, бюджет и отдельный RNG через фабрику; у неё три явные зависимости с разными обязанностями, без context bag. Навигационный поиск/Physics остаются средовым адаптером и требуют дальнейшей полной сверки.
