# Очистка документации после переноса планирования

Дата: 2026-10-21. База `f6f89e5`, ручные незавершённые изменения учтены до редактирования. Поручение включает дальнейший полный MVC/DI-перенос; этот отчёт фиксирует только документационную часть.

Удалены 13 локальных снимков планов/реестров, дублировавших действующий Notion: Roadmap и этапы 00–02, Backlog/Bugs/Questions/Changelog, OPTIMIZATION_BACKLOG, UI_PLAN, OBJECT_BACKLOG, MVP_PLAN и ENGINEERING_REVIEW. Назначения в Notion проверены до удаления. Старые статусы больше не встречаются при обычном чтении текущих документов; исходные редакции остаются в Git. Технические контракты, ADR, provenance/лицензии, полезный Archive и Reports/Validation сохранены.

Ссылки 27 документов перенаправлены на канонические страницы; ссылки с BUG/BL/Q ID по возможности ведут прямо на карточку. Убраны десять пустых compatibility-разделов ARCHITECTURE после перенаправления локальных ссылок на документы фич. README использует одну общую доску задач и багов; неверный старый URL исправлен. Внешние URL и смысл/актуальность не объявляются проверенными одной этой программой.
