# BUG-001: неиспользуемые prefab overrides

Дата: 2026-10-19, после `b414a18`. Ошибка находилась в сохранённом dirty-дереве: HEAD уже не содержал отсутствующий GUID. Поэтому чужие сценовые изменения целиком в commit не включаются.

Через официальный PrefabUtility.RemoveUnusedOverrides очищены BasementPrototype, LevelTemplate и MechanicsSandbox. Удалённые ссылки — 9/2/4 записи на прежний FloorShadows.asset. Отклонённая система конечных теней не восстанавливалась. Backup исходных файлов: `work/unused-shadow-overrides-before` внутри проекта.

Перед сохранением сравнивались все сериализованные данные GameObject/компонентов, включая неактивные объекты, ссылки, игровые параметры, иерархический порядок и мировые позы геометрии: Basement — 1843 состояния, Template — 228, Sandbox — 2060. Различий авторенных значений после очистки нет. Первая несовместимая попытка остановилась до записи; сохранялись только прошедшие проверку сцены.

Сравнение исключает подтверждённый пересоздаваемый Inspector-кеш кандидатов URP Provider2DSources; выбранные источники и геометрия ShadowMesh сохранены. Перед сравнением применяются обычные обновления ceiling-cookie и Canvas. Для экранного UI проверяются все сохранённые параметры RectTransform/Canvas; его производная матрица неактивного дисплея не является мировой расстановкой уровня. Для world-space UI проверка мировых поз остаётся.

MorgueRouteTest не сохранялась; её активность и dirty-флаг сохранились. Карты не перегруппировывались и не генерировались заново.

Результаты: 352 сериализованных ресурса — 0 отсутствующих внешних GUID; 116/116 EditMode (3.41 с); Windows64 release четырёх сцен — Succeeded, одно прежнее предупреждение RuntimePipelineConfig. Это не полная проверка локальных fileID/всех обязательных null-ссылок и не визуальная приёмка автора. Raw evidence — папка чата `work/code-migration-2026-10-19`; сценарий — AgentScripts/CleanUnusedShadowOverrides.cs.
