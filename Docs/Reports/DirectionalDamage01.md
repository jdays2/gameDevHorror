# Кровь по краям экрана · 2026-10-19

Реализовано в общем GameplayHud01: принятый удар показывает процедурную кровь на краю со стороны источника; HP и прежнее покраснение игрока сохранены. [Контракт](../Features/Hud.md), [настройка](../UI/HUD_DESIGN_SYSTEM.md), [происхождение](../../Concepts/Used/UI/DirectionalDamage01/README.md).

- 16/16 профильных EditMode: стороны/углы, отказ команды, удержание/затухание, отдельные таймеры, ограничение восьми пятен, изоляция HUD, сброс и простой.
- Общий прогон рабочего дерева: 157/157 EditMode. Он включал параллельную незавершённую работу PauseMenu; этот коммит содержит только DamageFeedback и его подключение.
- 26/26 native-проверок в MorgueRouteTest через реальные PlayerLife2D.TryTakeDamage: стороны и диагональ, поворот камеры, HP, защита, неизвестное направление, повторное включение, затухание при timeScale=0, смерть/восстановление, неизменность общего материала и профиля.
- Установка через Editor prefab API: 115 прежних компонентов HUD без изменения значений, 11 сохранённых сцен без изменения байтов. Для этой задачи сцены не сохранялись.
- Аудит 357 сериализованных ресурсов рабочего дерева: 0 отсутствующих внешних GUID. Это не проверка каждого локального fileID или всех необязательных null-полей.
- Windows64 release: MechanicsSandbox, MorgueRouteTest, LevelTemplate, BasementPrototype; Succeeded, 0 ошибок, 1 предупреждение об отсутствии RuntimePipelineConfig. Служебный Pipeline в Player отключён. Проверялась сборка текущего рабочего дерева, включая отдельные правки PauseMenu.

При визуальной проверке исправлена ошибка HLSL с зарезервированным именем point; после исправления сборка и отрисовка успешны. Финальные кадры получены ScreenCapture из Game view с видимым Canvas, а не отдельным рендером камеры. Изображения просмотрены: кровь видна у нужного края, центр прозрачен, HP читается. Художественное одобрение владельца пока не заявляется.
