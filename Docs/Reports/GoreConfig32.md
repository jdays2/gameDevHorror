# Конфиги крови и останков · GoreConfig32

2026-10-22, после 52779f4. GoreProfile, BloodPoolProfile и вложенные GoreVariant/GorePiece/BloodPoolVariant предоставляют readonly API. Сериализованные имена, значения, GUID и ссылки сохранены; массивы доступны только через Count/At. Вложенные типы вынесены в свои файлы без изменения namespace/имени типа.

GoreProfile проверяет конечность, диапазоны, составы и уникальность ID перед выбором или поиском варианта. GoreBurst проверяет индексы частей до отметки emitted и создания root. Restoration-only варианты доступны при загрузке, но не выбираются для новой смерти. BloodPoolProfile дополнительно проверяет ID и размер каждого варианта. Сохранённые DTO и формат checkpoint не менялись.

BUG-029 воспроизведён на 52779f4: **0/2 EditMode**, выбор принимал NaN gravity и повторяющиеся ID. После исправления **1111/1111 EditMode**, включая исходные случаи, readonly API, все текущие assets без мутации, legacy recipes и изоляцию RNG. **60/60 PlayMode**, включая настоящие additive unload, кровь, останки и checkpoint. Обычная Windows64 success, собственная Player assembly только EmergencyShift.Runtime. [Хеши и исходные результаты](../Validation/GoreConfig32.json).

Уровень внедряет именованную cosmetic RandomSourceFactory, отдельную от gameplay factory родительского scope. GoreBurst, шаги и гильзы получают личные потоки из неё: косметическое действие не меняет seed следующего игрового актора. Проверка использует настоящий LevelRegistriesInstaller и два соседних scope. Другие старые cosmetic Unity Random вызовы остаются предметом следующего прохода.

1805 защищённых ресурсов и 60 исходных dirty файлов сохранены. Новые meta импортированы из копии exclusive create; сцены и prefab не перестраивались. Проверялась отдельная копия с исходной незавершённой паузой, не clean HEAD; эти правки исключены из коммита. Имеющийся нефатальный LicensingClient warning остался.

Validate вызывается на редком пути смерти/восстановления; уникальность ID проверяется O(n²) без нового кеша. Выбор O(n), новые модели/Update для декоративной анимации не добавлены. Это проверенный config/RNG этап, не завершение остальных lifetime/style/actor границ или авторской приёмки.
