# Главное меню · монохромный вариант

По последним указаниям владельца: без фонарика, пояснений действий и декоративных линий. [Контракт](../Features/MainMenu.md), [кадр Unity](../Validation/MainMenu01/home.png).

## Проверки

- Unity 6000.6.5f1: компиляция без ошибок; MainMenuTests 10/10.
- Реальные UI-кнопки запускают новую игру и все четыре каталожные сцены. Esc возвращает из раздела, F8 — из каждой игровой сцены. После возврата один MainMenuPresenter, AudioListener и EventSystem, timeScale=1. [Прогон](../Validation/MainMenu01/play-checks.json).
- Below the Ward 02: проверены передача вступления в петлю и native wrap через ускоренный перевод AudioSource.timeSamples к границам. Громкость 0.4. Всю композицию агент не прослушивал; художественная оценка остаётся владельцу.
- F8 из поставленной на паузу MechanicsSandbox: timeScale=1, AudioListener.pause=false, один экземпляр музыки меню. Старые источники и захваты паузы освобождены.
- SHA256 всех 11 ранее существовавших `.unity` файлов совпадают со снимком перед авторингом. Игровые карты не переписаны. В ProjectContext добавлены установщик/адаптер с сохранением прежних четырёх конфиг-ссылок.
- Обычная Windows64 сборка, BuildOptions.None: Succeeded, 520695030 байт, 63.67 с. Из EmergencyShift-сборок включена только Runtime.dll; Editor/Development/Tests отсутствуют. [Сводка](../Validation/MainMenu01/build.json), [сообщения](../Validation/MainMenu01/build-messages.json).

## Границы

В успешный build вошёл один Error управляющего Pipeline: запрос ожидал main thread дольше 55 с. Сборка продолжилась и завершилась через 63.67 с; результат прочитан после её завершения. Warning сообщает об отключённом runtime Pipeline в Player без RuntimePipelineConfig. Эти сообщения не являются ошибками компиляции меню. Повторная сборка не понадобилась.

Сборка подтверждает включение ресурсов, но не заменяет ручную оценку изображения/звука в Player. TASK-UI-02 и BUG-043 оставлены на проверке владельцем. Кампания, межсценовый прогресс и реальные слоты не реализованы. Новая игра запускает чистую песочницу. Чужие незавершённые изменения паузы/оружия не считаются результатом этой задачи.
