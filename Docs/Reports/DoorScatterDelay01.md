# TASK-004 · Индивидуальные задержки разбега

После полного открытия двери MorgueRouteTest участники начинают свои маршруты по очереди: Stalker_Intro — 0 s, Stalker_Hall02 — .2 s, Stalker_Hall01 — .45 s, Stalker_Hall03 — .7 s. Новое поле Start Delay Seconds редактируется на личном ScriptedStalkerRoute2D; общие профиль и prefab не менялись.

## Граница поведения

Личный ScriptedRouteModel хранит startDelayLeft и состояние WaitingToStart. До первого выполненного условия таймер не расходуется; StartScriptedRouteCommand фиксирует запуск один раз. Пока он идёт, controller задаёт остановку через прежний motor, глаз остаётся открыт и обычные агрессия/атака/патруль подавлены. После ожидания начинается отдельная реакция либо сразу движение. Ноль сохраняет прежнее поведение, отрицательные/нечисловые значения отклоняются на границе модели. Inspector показывает остаток времени.

Свет, урон, stagger и смерть обрабатываются прежним actor loop. Stagger приостанавливает таймер и исполняет толчок; смерть/недоступная цель отменяет маршрут. Никаких Coroutine, общего таймера группы, второго владельца Rigidbody и нового checkpoint payload нет. Сама задержка не запускает световую анимацию или EyeBurn. Физическое тело остаётся обычным и может быть толкнуто соседом; очередь рассчитана на текущую авторскую расстановку.
