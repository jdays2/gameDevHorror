# Блик доступного лута

2026-10-24. Реализация выбранного владельцем «Блика обнаружения» по [карточке задачи](https://app.notion.com/p/4038d6dc06b681bca3a6f5cdcc6a15d7). Аура и окружность исключены последним решением владельца. Внешний вид позднее одобрен владельцем; [уточнение тайминга](PickupGlintTiming58.md) заменяет описанные ниже исходные .6 с/rearm. Остальной отчёт сохраняет исторические результаты первой реализации.

## Поведение и границы

Короткая диагональная полоса проходит по исходной альфа-форме предмета при обнаружении фонарём. Удержание луча не зацикливает эффект; после .65 с вне видимости его можно увидеть снова. Начальные параметры: .6 с, intensity .78, ширина .2 диагонали. Это настраиваемая отправная точка, не численно утверждённый баланс.

`PickupGlintFactory` создаёт native View в scope уровня при композиции каждого pickup. Полоса использует общий материал с личным MaterialPropertyBlock и временными дочерними SpriteRenderer; исходные материалы, спрайты, расстановка и GUID сохраняются. Shared `Resources/PickupGlintProfile.asset` только читается. Косметические таймеры не владеют правилами инвентаря и сохраняются отдельно от gameplay-состояния. При disable/unload показ и принадлежащие View объекты прекращаются; пауза останавливает время полосы.

Общий эффект зависит от `IPickupGlintTarget`, без выбора видов предметов в рендерере. Новый вид предоставляет read-only проверку приёма. Существующие weapon/ammo, карты, фонарь и модули подключены. `IPickupPreviewActor` использует правила нужного оружия/запаса, карт и команды модулей. Он не меняет инвентарь и не увеличивает дистанцию автоподбора.

Требуется принадлежащий игроку включённый фонарь и его `Illuminates` с настоящим blockingGeometry. Shader дополнительно обрезает полосу по лучу. Ambient/потолочные лампы/выстрел сами по себе эффект не включают. После недоступности, потери видимости или consumed-восстановления блик снимается.

## Проверки

- [EditMode](../Validation/PickupGlint57/edit-summary.json): 1285/1285. Новые независимые проверки покрывают одиночный показ, отсутствие цикла при удержании, rearm, паузу/изоляцию, невалидное время, адресный запас патронов и конфликты оружейных слотов; модульная проверка повторно использует CanInstall без применения эффекта.
- [Целевой PlayMode](../Validation/PickupGlint57/play-tests.json): реальная additive MorgueRouteTest; несколько предметов, фонарь off/on, solid blocker, consumed restore, уже полученная карта, полный/частичный запас, сохранение короткого радиуса и частичной коробки, предел модулей, disable и неизменяемость профиля.
- Первый полный PlayMode: [83/84](../Validation/PickupGlint57/play-summary-first.json); краткий kick в существующем DamageFeedbackLifetimeTests не попал в момент выборки. [Отдельный повтор 2/2](../Validation/PickupGlint57/damage-recheck.json) прошёл; этот тест и код камеры не менялись.
- [Финальный общий PlayMode](../Validation/PickupGlint57/play-summary-final.json): 84/84, без провалов.
- [Shader/profile inspection](../Validation/PickupGlint57/prepare.json): shader errors отсутствуют, профиль/общий материал созданы через AssetDatabase. Новые исходники эффекта оригинальные; растровые изображения или сторонние игровые материалы не добавлялись.
- [Обычная Windows64](../Validation/PickupGlint57/build.json): Succeeded, 0 ошибок; Resources-профиль включён, из собственных assembly присутствует только EmergencyShift.Runtime.dll. Единственное [предупреждение](../Validation/PickupGlint57/build-messages.json) сообщает, что Runtime Pipeline управления Player не включён, как и прежде. Это проверка текущего рабочего дерева с сохранённым прежним pause/input draft, а не публикация релиза.
