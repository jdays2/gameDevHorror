# Личные сигналы слышимости врагов

Дата: 2026-10-22. База `b3e0d93`. AudioThreatSignalModel хранит heard/urgent deadlines экземпляра с IGameClock. ReportThreatCueCommand проверяет alive/gain/duration/clock до изменения; Execute повторно проверяет значения и использует один sampled clock. Reset — отдельная команда. Controller предоставляет только значения сигнала для perception query: это сенсорная граница, отдельного пустого графического View нет. AudioThreatEmitter2D адаптирует реальные audible cues и native lifecycle, не читает Time.time и не содержит tuning numbers.

AudioThreatSignalProfile — readonly SO с прежними **.02 / .25 / 2 / .4**. WorldInstaller требует явную ссылку и валидирует immutable snapshot до bindings; фабрика уровня получает этот snapshot и свой scaled clock, создаёт отдельную модель/controller источнику. Повторный bind начинает новую membership/сигнал; невалидный bind не снимает существующий источник. Disable тихо сбрасывает deadlines, enable регистрирует новый transient ordinal.

Профиль создан через Editor API в копии, затем проверен и перенесён. В существующем ProjectContext prefab изменена **ровно одна serialized ссылка threatSignals**; прежний GUID/meta и все остальные строки сохранены. Новый SO и девять новых script meta импортированы через exclusive create. **1793 прежних ресурса неизменны, один prefab намеренно дополнен ссылкой**, а не 1794 unchanged; [точный manifest](../Validation/AudioThreatSignal26AssetChanges.json) содержит before/after hashes. Обновлённый guard проверяет 1805 путей. Пользовательские сцены/расстановка/звуки не менялись. Старый InstallWorldComposition builder также назначает профиль, но не запускался для регенерации.

**979/979 EditMode**, 20 новых: legacy clamp/накопление, urgent hold, gain boundary, dead/nonfinite rejection, injected clock и однократное чтение, command check/recheck, reset/два экземпляра, invalid config, production SO/ref/defaults без мутации, missing/invalid world config до bindings, warmed allocation. **49/49 PlayMode**, полный audio probe и source scope lifecycle, включая невалидный rebind, disable/re-enable и frozen unload/sibling. Обычная Windows64 success; собственная Player assembly только EmergencyShift.Runtime. [XML, hashes и source parity](../Validation/AudioThreatSignals26.json).

Один immutable snapshot на world и две маленькие личные C# сущности на источник при composition/rebind. Новых Update/коллекций/голосов/Physics2D-запросов нет. 1000 warmed cue commands: **0 managed bytes**, не оценка FPS всей игры. Копия содержит исходную незавершённую паузу, не clean HEAD; нефатальный LicensingClient остаётся. Общая MVC/config/style работа и приёмка открыты; остальные audio adapters не объявлены автоматически завершёнными.
