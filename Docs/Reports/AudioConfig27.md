# Readonly аудионаборы и банки клипов

Дата: 2026-10-22. База `5050cb5`. WeaponAudioProfile, PlayerWorldAudioSet, SleeperAudioProfile и DoorAudioSet получили private SerializeField с прежними names/defaults и readonly getters. PlayerAudioSet, StalkerAudioSet и EnemyDeathAudioSet также больше не выдают свои массивы наружу. Общий AudioClipBank — маленький readonly value view с Count/indexer/typed enumerator; его нельзя привести обратно к исходному массиву или IList. Он не копирует массив на каждое обращение. Unity Object references остаются references; reflection/Editor-изменения не объявляются запрещёнными этим C# API.

Equality/hash банка сохраняют identity исходного массива: PlayerAudio хранит историю выбора отдельно по тем же банкам, равное содержимое разных массивов не объединяется. Count вместо Length, null bank заменён пустым value; порядок, пустые/nullable slots, surface fallback и алгоритмы RNG сохранены. Native потребители используют конкретный value type; приведение к IReadOnlyList может создать boxing, это не обещание нулевых allocations при любом способе использования.

Finite/range/relation guards добавлены для громкости, размеров/цвета гильзы, voice limits и пространственного микса. Они вызываются на init либо перед соответствующим cue/consumption; валидные принятые значения не нормализуются заново. Source enums и прежние fallback-правила сохранены. Shotgun Editor recipe пишет старые поля через SerializedObject; Sandbox probe проверяет записанный клип по readonly банку. Builder не запускался для перестройки сцены. Новые модели для native audio timers в этом проходе не заявляются.

**1003/1003 EditMode**, 24 новых: read-only runtime API всех семи типов, загрузка/validation всех текущих assets без мутации, readonly bank/cast/collection contracts, bank identity/history, native serialized names/order/null slots/fallback и .24, nonfinite rejection, warmed enumeration/history loop. **49/49 PlayMode**: полные существующие audio/weapon/native lifecycle probes прошли. Обычная Windows64 success; собственная Player assembly только EmergencyShift.Runtime. [XML, source/meta parity и 1805 неизменённых ресурсов](../Validation/AudioConfig27.json).

Клипы, их import settings, volume assets, prefab/scene values и существующие GUID не менялись; три новых script meta получены из импорта копии через exclusive create. Совместимость SO сохранена, runtime C# API намеренно readonly. Копия содержит исходную незавершённую паузу, не clean HEAD; нефатальный LicensingClient остаётся.

Новых Update/голосов/коллекций на cue нет; scalar guards добавляют ограниченные проверки. Warmed 1000 циклов typed bank enumeration и dictionary history lookup: **0 managed bytes**, не оценка FPS/CPU всей аудиосистемы и не новая слуховая приёмка. Семь config boundaries проверены; прежние timing/model/style/authoring partial-статусы потребителей сохранены. Общая миграция и приёмка открыты.
