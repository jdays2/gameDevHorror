## Доказательства и пределы проверки

Десять проверок игрового поведения и наблюдавшиеся значения сохранены в `SmokeResults.json`. Для ввода создавались временные устройства Input System: события проходили через настоящие компоненты Update и физику Play Mode. После проверки временные устройства удалены, Play остановлен. Ввод проверялся в редакторе; самостоятельный Windows-билд в этой итерации не собирался.

Снимки из Game View: `Previews/flashlight-off.png`, `Previews/door-closed.png`, `Previews/door-open.png`, `Previews/wall-shadow.png`. Это изображения работающего прототипа, не концепт-арт.

После проверки начальная позиция сохранена перед дверью: x=2.8, y=0. При запуске фонарь выключен, дверь закрыта. Проверка света после этого сохранения выполнена повторно на снимках.

При первоначальном импорте Unity показала предупреждение об изменённых immutable package assets. Наш код не редактировал исходники пакетов. Повторное чтение консоли после запуска и проверки света вернуло 0 ошибок/предупреждений. Если предупреждение снова появляется при переимпорте, его нужно рассматривать отдельно от игрового поведения.

Unity MCP использовался напрямую по MCP из локального клиента агента. Записи серверов сохранены в Codex, но список инструментов уже открытого чата ещё не обновился автоматически. Чтобы получить штатные инструменты в новом чате, перезагрузить MCP-подключения/приложение; это не требуется для запуска самой игры.

При будущих изменениях добавлять способ проверки и краткое наблюдение. Не считать отсутствующий лог доказательством успешной компиляции.
