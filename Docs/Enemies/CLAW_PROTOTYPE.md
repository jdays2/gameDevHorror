# Когтистый · TASK-005 · тестовый прототип

В MechanicsSandbox добавлены два экземпляра в первой комнате: ожидание(5,4.5), патруль(15,5.5), зона3.5×3.5. Неподвижная мишень4HP — тир(42.5,8). Образцы останков A/B/C — x47, y10.7/12.4/14.1, группа `R03_WeaponsRange/Dressing/Claw remains · A B C`. Новых AudioSource нет. Прежние враги, оружие, комнаты, пауза и ручные параметры сохранены.

4HP, погоня1.65 units/s, обнаружение3.2 при близости+LOS, агрессия постоянна. Пуля вызывает короткое прерывание. Коммитится одно направление атаки: D/sweep1.21s, момент удара.554, дуга110°, урон1, дистанция1.6. Числа находятся в EnemyDefinition. Это минимальное поведение для тестирования визуала, не утверждённый третий вид со стайным дизайном/реакцией глаз на свет.

`Features/ClawEnemy/Config` — неизменяемые настройки; Logic — личная model, проверяемые commands и controller; View — Unity actor/движение/спрайты. Factory внедрена EnemyInstaller через Zenject. Общие health/perception/motor/patrol/melee используются через адаптеры, пули и HUD не выбирают новый вид по типу. У каждого экземпляра собственные HP, агрессия и таймеры. SceneContext не добавлялся: применяется существующая композиция LevelContext2D.

TimedSpriteMotion хранит реальные длительности кадров, а не равномерный FPS атаки. Частота походки умножается на фактическую скорость/referenceSpeed, pivot и размер кадра постоянны. Художественно текущий бег владельцу не подходит; это не исправлено техническим тестом.

Смерть выключает коллайдер/физику/AI и один раз передаёт кровь и композицию независимому RemainsRecord. Три равновесных варианта: A2/B3/C2. Для каждой композиции один полный статичный PNG, нулевой импульс; новая опция GorePiece.PreserveSourcePose сохраняет поворот и отключает вращение. По умолчанию false, старые профили сохраняют прежнее поведение. Нет независимого разлёта частей нового тела, checkpoint/campaign адаптера или массового pooling. Sandbox R начинает свежую сцену.

После выбора нового основного дизайна J с жвалами живые клипы/останки остаются прежним мастером F17. Голова и более грозный бег требуют следующего художественного прохода. Источники/промпты: Concepts/Used/Visual/ClawPrototype01 и F18/F19. Проверки: Docs/Validation/ClawSandbox01.
