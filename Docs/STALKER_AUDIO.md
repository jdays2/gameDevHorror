## Файлы

Исходники находятся в `Assets/EmergencyShift/Audio/Stalker/Prototype01/`. Имена имеют вид `stalker_<категория>_<вариант>.wav`.

| Категория | Варианты | Длительность примерно | Назначение |
|---|---:|---:|---|
| step | 4 | 0.20 с | Сухие острые контакты нескольких ног, без человеческих ботинок |
| idle | 3 | 1.6 с | Тихий влажный выдох, скрежет, редкие щелчки |
| notice | 2 | 0.65 с | Короткий сигнал обнаружения добычи |
| windup | 2 | 0.24 с | Напряжение перед укусом |
| lunge | 2 | 0.22 с | Короткое движение/рывок |
| bite | 3 | 0.42 с | Хруст и влажный удар укуса |
| light_fear | 3 | 1.1 с | Резкий болезненный скрежет при испуге от света |
| retreat | 2 | 0.94–1.0 с | Ускоренная серия контактов при отходе |
| hit | 3 | 0.33 с | Попадание в плоть и короткая реакция, без звука пистолета |
| death | 3 | 1.5 с | Разрыв, хруст ткани, брызги и затухание |
| debris | 4 | 0.35 с | Влажное падение небольших останков |

Все исходники — моно WAV PCM 24 bit / 48 kHz. Предпросмотры — стерео PCM 16 bit / 48 kHz. Все клипы однократные; `retreat` — готовая короткая последовательность, не бесшовная петля. Длительности слегка различаются. Отдельные seed меняют рисунок варианта, а не только его pitch.

Шаги/дыхание намеренно тише испуга/смерти. Unity Import Settings: Decompress On Load, PCM, Preserve Sample Rate, Preload Audio Data, Normalize выключен. Иначе нормализация каждого файла уничтожит предварительный баланс. Этот небольшой набор занимает около 3 MB исходных WAV; более длинный фон потребует других настроек импорта. Моно позволит позже пространственно позиционировать источник.

## Следующая интеграция — план, не выполненный код

Небольшой компонент звука на враге с явными ссылками на AudioClip/AudioSource достаточен. Состояния остаются у ShadowStalker2D; звук наблюдает конкретные переходы и фазы, не управляет AI. Отдельный глобальный менеджер сейчас не требуется.

| Событие | Предлагаемое правило |
|---|---|
| Контакты ног | По фазе шага/пройденной дистанции при движении; не каждый Update |
| Idle | Редко и со случайной паузой; не непрерывная петля |
| Обнаружение | Один раз при false → true у HasAggro |
| Атака | Windup на входе в Attacking; lunge/bite синхронизировать с фазой анимации и фактическим уроном |
| Испуг | Один сигнал при входе в реакцию, после существующей задержки; не каждый кадр освещения |
| Отход | Только при реальном движении; не накладывать серию поверх каждого отдельного шага |
| Ранение | Один вариант на несмертельное попадание; ограничить частоту |
| Смерть | Однократно; при смертельном попадании приоритет над обычным hit |
| Останки | Ограниченное число звуков посадки, а не AudioSource на каждом фрагменте навсегда |

Для будущих 10–20 мобов нужны предел голосов, приоритет ближней угрозы, исключение немедленного повтора варианта и небольшая случайность громкости/pitch. Обязательны проверка пространственной слышимости и стен: монофайл сам по себе не делает звук приглушённым за дверью. Нагрузочное тестирование/микшер/окклюзия пока отсутствуют.

## Воспроизводимость и проверка

`Tools/Audio/generate_stalker_sfx.py` — офлайн-инструмент, не код Unity и не зависимость игры. Для повторной генерации нужен Python с NumPy **2.3.5** (`Tools/Audio/requirements.txt`). Из корня проекта: `python Tools/Audio/generate_stalker_sfx.py`. Если WAV уже существуют, скрипт остановится; осознанная перезапись — с `--force`. Скрипт не трогает `.meta`; GUID остаются прежними. Фиксированные seed/версия NumPy зафиксированы в manifest.

[manifest.json](Audio/StalkerPrototype01/manifest.json) содержит назначение, seed, формат, длительность, уровни и SHA-256 каждого файла. [Validation.json](Audio/StalkerPrototype01/Validation.json) — объективная проверка формата/уровней/декодирования и импорта Unity. Проверены все 31 клип, отсутствие клиппинга, ненулевой сигнал, нулевые края и уникальность данных; оба превью декодированы FFmpeg. Это не заключение о художественном качестве и не проверка звука в игровом миксе. Unity импортировал клипы с сохранением относительных уровней; runtime-привязки нет.
