# TASK-005 · звук хвата r2

Владелец отверг сухие щелчки r1 как не соответствующие мясистому дизайну. Текущий эффект — оригинальный короткий органический хват с хрустом оболочки. Исходники и обработка: [Scorpion01](../../../Concepts/Used/Audio/Scorpion01/README.md).

Независимый scorpion_motion_qa проверил WAV и код. Mono PCM16/32kHz, 10880 samples = 340ms, clipped 0, края нулевые. Максимум centered 5ms RMS на 44.8125ms; cue .32 и strike .40 атаки .56s дают целевые 44.8ms. При pitch .96..1.03 отклонение акцента до 1.9ms, без учёта Update/DSP-задержки. Самый поздний штатный конец 533.37ms при конце атаки 560ms. Полная повторная обработка воспроизводит побайтно те же восемь WAV.

[import.json](import.json): настоящий Editor, GUID Attack сохранён, PCM/DecompressOnLoad, четыре разных канала, ноль missing scripts; все четыре авторских instance наследуют новое поле. Менялся только существующий Scorpion.prefab через PrefabUtility, сцены не сохранялись.

[play.json](play.json): один настоящий авторский actor в MechanicsSandbox. Клешни и попадание звучат одновременно; pause сохраняет sample/playhead, resume продолжает; один cue на атаку; disable останавливает, reactivate разрешает новую атаку, смерть останавливает все каналы. Это проверка состояния AudioSource, не прослушивание. Фаза пробы не является измерением точности синхронизации: pipeline-компиляция/опрос влияют на кадры.
