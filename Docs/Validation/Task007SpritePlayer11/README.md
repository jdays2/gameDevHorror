# TASK-007 · просмотр и наложение цельных PNG

По запросу владельца создан автономный player.html: Canvas проигрывает полные PNG, показывает исходные Sprite из текущего ShadowStalker.prefab, позволяет паузу/шаг/таймлайн/миниатюры, фон/масштаб/темп, полные соседние кадры, исходник и заранее заданные костные схемы. Ни video-элементов, ни кадров сгенерированного видео, ни нарезки тела/риг-деформации нет. Альфа-цвет диагностического наложения существует только при показе, не записывается в исходные PNG.

Свежая проба10 —9реальных рисунков движения (16шагов туда-обратно),4атаки (6шагов); сон/пробуждение только статические новые ключи. Отдельный вариант09/R3 — прежние цельные ImageGen-рисунки24/16/16/32, до отвергнутой слойной сборки. Их происхождение/реальные количества/непройденная приёмка видны в UI и README. Не объявлены новыми принятыми или игровыми сериями. Текущий игровой базовый проигрыватель не изменялся.

build-verification.json фиксирует121ссылку на изображения, реальные counts, неизменность всех прочитанных источников, нулевой ввод видео, точные RGB/alpha>=3 после допустимой exterioralpha1/2cleanup и точное декодирование видимого RGBA каждого кадра APNG. Исходные native Sprite экспортированы целиком с фактическими rect/pivot/PPU; крупный Recoil00 сохранён на большей прозрачной подложке, без обрезки и изменения пикселей. animations.json связывает каждый кадр с исходным целым rect. ZIP содержит HTML, PNG, APNG/GIF, листы и точные промпты.

verification.json: JS-синтаксис проверен Node, ZIP и автономность HTML проверены; APNG сна/пробуждения играет один раз, движение/атака циклично. **Браузерные UI-клики не проверены:** CUA отверг file:// по политике URL. Не использованы обход через сервер, другой браузер или иной UI-канал. Локальные PNG/APNG и GIF-превью осмотрены напрямую; HTML выдаётся файлом для ручного открытия. Это не native/gameplay или художественный PASS.

Unity/Assets/сцены/игровой код не изменялись, game lease не брался. Итоговый контроль авторинга неприменим. TASK-007/BUG-054 остаются в работе.
