# TASK-005 · Попадания, кровь и глаза Скорпиона · r14

2026-10-31. Владелец сообщил об отсутствии голоса попадания, брызг и свечения глаз. Палитра BlushIvory, рисунки и анимация остаются прежними.

## Причины и изменения

- В [исходном нативном прогоне](before.json) HP снижалось 3→2→1→0, voice действительно запускал Hit.wav на двух нефатальных попаданиях. Source не был muted/virtual, listener активен; volume=.376 на 2.5 unit. Старый тихий контакт не давал отчётливого насекомого сигнала. Hit теперь переиспользует одобренный Detection.wav, pitch1 и отдельный HitVolume=.75; остальные каналы/смерть не усилены. Новый WAV не генерировался, слуховая приёмка не заявляется.
- Scorpion2D не вызывал общий EnemyHitResponse2D, самого компонента не было в prefab: до исправления все три попадания давали 0 sprays. Теперь каждое принятое bullet hit создаёт восемь направленных капель на .24s. ToxicBlood с белым vertex tint даёт жёлто-зелёную кровь; при затухании меняется alpha. Постоянная лужа живому врагу не создаётся. Старый overload/default сохраняет красный tint других врагов.
- Eyes renderer и LOS работали, но .12 терялся на светлой плоти. [День](eyes-day.png) и [ночь](eyes-night.png) сравнивают слева направо .12/.24/.32 на одной позе; выбрано .32 с запасом читаемости. Изменены только два prefab tint и текущий authoring builder. EyeGlow, shader, маски и все 56 кадров прежние. Глаза не освещают пол и остаются за LOS/death gates.
- Независимое ревью обнаружило риск быстрого добивания во время squash предыдущего попадания: смерть захватывала изменённую матрицу до сброса реакции. У Scorpion отключено transform deformation; цветовая реакция и брызги сохранены. Общий default deformVisual=true оставляет прежнее поведение других врагов.

## Проверено

- [После исправления](after.json): три настоящих выстрела игрока, HP3→2→1→0; два голоса Detection с прогрессирующими timeSamples, volume≈.470, не muted/virtual. Смертельное попадание сохраняет один CreatureRupture06. Каждый выстрел дал один spray/8 капель ToxicBlood. [Живое попадание](shot-after-1.png), [смерть](shot-after-2.png).
- [Быстрая смерть](rapid-death.json): нефатальное попадание → 40ms ещё активной реакции → смертельное. Visual scale/position стабильны, начальные центры всех 12 частей совпали с исходной позой (максимальная ошибка0). Глаза выключились. Тем же прогоном подтверждены сокрытие за стеной и видимость при выключенном фонаре.
- [Audio EditMode8/8](audio-tests.json), [TransientBlood PlayMode10/10](blood-tests.json): независимая громкость боли, приоритет смерти, дальность/валидация, цвет при затухании, прежняя красная кровь, неизменная геометрия, глубина останков и lifetime при unload/disable/destroy.
- [Установка](install.json): actual prefab и открытая MechanicsSandbox, authored scene state сохранён, сцена не сохранялась. Новые объекты сцены не добавлялись/не перемещались. Итоговый контроль авторинга: неприменим.
- [Нормальная Windows-сборка](build.json): BuildOptions.None, обычный Player без runtime Pipeline. Это сборка текущего рабочего дерева, а не изолированного коммита. Первый запуск builder превысил 30s dispatcher timeout, сам build завершился; после последней правки повтор выполнен с достаточным timeout. В итоговом отчёте хранится последний результат.

Два субагента независимо проверили код и нативные изображения; найденный rapid-death риск исправлен и перепроверен до закрытия. Изменение не перерисовывает анатомию и не заменяет полный прежний покадровый аудит; исходные PNG неизменны. Исторический браузер r12 сохраняет сравнение палитр и не демонстрирует текущую игровую обратную связь. Художественная оценка звука владельцем остаётся отдельной; stress10/20 и Profiler не запускались. Notion пропущен по прежнему поручению владельца.
