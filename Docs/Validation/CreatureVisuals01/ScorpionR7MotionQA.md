# TASK-005 · Scorpion r7 · независимая проверка движения

Проверена редакция `scorpion-native-r7-stocky`, 24 кадра Run и 32 кадра Attack. Проверка read-only; исходники, кадры, префабы и сцены не менялись. Художественная приёмка владельца не подменяется этим отчётом.

## Найденные ограничения склеек

1. **Idle/Neutral → Run 00 пока не согласованы.** У нейтрального рисунка стопы стоят в середине размаха, а Run 00 уже содержит две различные фазы опоры. Максимальный скачок костной точки стопы — `0.20 native = 0.17 Unity unit`, то есть 34 px при PPU200; колена — `0.10639 native`; кончика клешни — `0.03569 native`. Различие подтверждено фактическими `native-neutral.png` и `frames/run/run-00.png`. Для игрового ожидания можно удерживать Run00 вместе с RunEyes00 либо использовать отдельный согласованный старт. Наличие нулевой ошибки Run→Attack это ограничение не устраняет.
2. **Run → Attack бесшовны только на общей нулевой фазе.** Запуск Attack 00 из произвольной фазы Run может сдвинуть стопу до `0.40 native = 0.34 Unity unit` (худшая проверенная фаза Run `0.64`). В художественном сценарии вход специально привязан к границе цикла. Для будущего AI необходима такая же явная фазовая политика; это условие интеграции, а не уже проверенное игровое поведение.

Root принял оба пункта: планирует игровой Idle на Run00/RunEyes00 и вход атаки при пересечении нулевой фазы. Реализация и реальные переходы в Unity в рамках этой проверки ещё не проверялись.

## Фактический визуальный просмотр

Просмотрены все 56 кадров на текущих контактных листах `run-clean-dark.jpg` / `attack-clean-dark.jpg`, отдельно крупные исходники Run00/08 и Attack12/31, текущая нейтраль и UV-источник новой ноги. На просмотренных рисунках не обнаружены оборванные конечности, вновь открывшиеся пустые гнёзда корпуса, перескоки цвета/крови между состояниями, склейка клешни с ходовой ногой или отсечение жала холстом. Крупные тени и кровь принадлежат общим поверхностям, а не заново сгенерированным фазам.

Корни ног закрыты корпусом; колени остаются видимыми шарнирами. На беге клешни сохраняют почти закрытый хват. В атаке читаются раскрытие, захват и возврат; опорные ноги продолжают движение. Оценка устрашающего характера и финальное принятие дизайна остаются за владельцем.

Запас опор относится к проекции начала корпуса, не к восстановленному реальному центру массы; это не расчёт динамического равновесия или сил. Постановка проверена на костной точке стопы, а не как симуляция контакта каждого пикселя когтя.

На всех кадрах непрозрачный силуэт остаётся внутри x=288…735, y=212…904; запас до края достаточен. Производственные body и eyes имеют общий размер в мире и общий pivot: `(256,274)/200` и `(128,137)/100` от верхнего левого угла. Idle использует эквивалентную регистрацию `(512,548)/400`.

Run содержит 24 различных кадра по 15 ms, длина `.36 s`. Attack содержит 32 кадра с чередованием 18/17 ms, длина `.56 s` и два цикла опор. Unity-ключи Body/Eyes совпадают попарно; дополнительный конечный ключ удерживает последний рисунок и не создаёт ещё одной позы. Длительности сериализованных клипов `.36000013` и `.56000006 s`, погрешность времён исходных ключей не больше `1.2e−7 s`.

Непрерывный Run loop и аналитические Attack entry/exit сходятся на нулевой фазе; соответствующие конечные позы не требуют дополнительного нарисованного дубликата. Отдельная политика необходима для переходов, описанных выше.

## Границы проверки

Unity Play, сцена, AI, звук, тень и производительность здесь не проверялись. Проверка интеграции после их добавления обязательна. Сами клипы не подтверждают поведение группы, попадание по герою или FPS при 10/20 врагах. Итоговый контроль авторинга: неприменим, объекты сцен этим агентом не менялись. Notion пропущен по поручению владельца.

### Проверенные границы кода

- У стаи личный `ScorpionPackModel`; повторный Alert отвергается. Дверная подписка снимается при disable, callback реагирует только на opening. Члены явно перечислены, Awake проверяет родителя и запрещает привязку к двум pack.
- У каждого actor собственные Health, ScorpionModel, melee controller и timers. Конфиги в runtime не переписываются; authoring настраивает их только в Editor.
- После тревоги HasAggro сохраняется. Flashlight передаётся только представлению/теням, а perception получает `ThreatLight=null`: световой страх и возврат домой не добавлены.
- Контактный урон проходит через существующий общий melee с проверкой target alive, LOS, range и arc. Его lunge velocity не заменяет движение Scorpion; мотору передаётся Follow с уменьшенной скоростью.
- В новых общих weapons/HUD потребителях species switch не появился. Scene-scoped factory использует существующий `IGameClock` через EnemyInstaller.

После повторного чтения перечисленные причины адресованы кодом; новых блокирующих причин в этом проходе не найдено. Эта дополнительная проверка не подтверждает сохранность фактической сцены или результат функционального Play. Конкретные regression-сценарии должны быть закрыты root до сдачи.
