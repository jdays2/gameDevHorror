# TASK-005 · Бледные палитры Скорпиона · r12

2026-10-31. По новому направлению владельца подготовлены четыре параметрических варианта существующего рисунка. Это материалы одного рига и тех же56 фаз; новые bitmap, анатомия, механики или звуки не генерировались.

| Номер | Вариант | Материал |
|---|---|---|
| 1 | Телесно-розовый | FleshPink |
| 2 | Холодный серо-розовый | ColdPale |
| 3 | Меловой белый | ChalkWhite |
| 4 | Почти белый с розовинкой | BlushIvory |

Тело и GoreBurst в игровом prefab, а также тело ScorpionVisual теперь используют FleshPink. Остальные материалы доступны как кандидаты. BurgundyShell r11 сохранён. Единый источник RGB-параметров — [palette-variants-r12.json](../../../Concepts/Unused/Visual/Scorpion01/palette-variants-r12.json); ScorpionPalettesR12.InstallAndCapture создаёт материалы и применяет default, R10 installer учитывает тот же default. Браузерный выбор сам не меняет Unity.

[Native report](native.json) подтвердил ссылки, отсутствие shader errors и сохранность открытой сцены. Нативные [свет](native-comparison.png) и [ночь](native-night.png) захвачены одним URP2D-материалом в четырёх вариантах на одной позе слева направо1–4. Сравнение в [просмотрщике](http://127.0.0.1:8103/Scorpion01/viewer.html?revision=pale-variants-r12&compare=1) синхронизирует кадр и раскладку частей, чтобы цвет не сравнивался на разных позах. Доступны отдельная палитра крупно, Attack/Approach/Death, тёмный/светлый/ночной фон и прежний бордовый вариант. [Снимок](viewer-comparison.png).

В браузере сохраняется максимум128 окрашенных кадров/частей; полные атласы для каждого цвета не дублируются. Read-only QA логики проверила LRU/eviction, разделение ключей, неизменную alpha и четыре синхронных Run/Attack/Approach/Death. Найденный старый сбой таймера после переключения семейства исправлен: options сбрасывает nextSqueak вместе со временем; выбор цвета не сбрасывает кадр/звук. Эти проверки не являются измерением FPS.

На бледном цвете выявились слабые прямые полосы за пределами силуэта, существовавшие и вr11. В соответствующем bilinear support исходных Run00 и RunEyes00 alpha строго0. Нативный A/B подтвердил устранение полос повышением compressionQuality Run/Attack50→100: в точках(90,235)/(80,630) былоRGB39,40,43/42,42,45, стало ровноRGB28,33,37 — фон. [До](native-before-import-quality.png), [после](native-comparison.png). ФорматBC7, размеры3072×2048/3072×3072, PPU, rect, pivots, sprite IDs и исходные PNG прежние. Alpha cutoff не добавлялся. Осмотрено нативное A/B показанной позы; полный повторный нативный захват56 кадров не заявляется.

Два субагента выполнили read-only проверки: визуально четыре палитры различимы, новых дыр/обрезок не найдено; FleshPink и BlushIvory близки в темноте. Данные JSON и материалов совпадают, body/gore ссылки сохранены. Художественная приёмка остаётся владельцу. Красные глаза, жёлтая кровь и одобренный звук не менялись.

Авторинг неприменим: объекты сцены не добавлялись/не перемещались, карта не пересохранялась. Runtime C# и сборки не менялись; текущие готовые player-сборки относятся кr11. Notion пропущен по прежнему поручению владельца. Внешним сервисам материалы не отправлялись.
