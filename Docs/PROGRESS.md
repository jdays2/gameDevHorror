# Текущий прогресс — 14 октября 2026

Репозиторий: https://github.com/jdays2/gameDevHorror, ветка main. Корень репозитория — сама папка Unity-проекта EmergencyShift. Стартовая история GitHub сохранена; force-push не используется.

## Работает

v0.6: найденный пистолет, патроны на полу, скрытый до находки счётчик, одиночный ЛКМ, физический полёт с проверкой пути, урон/смерть сталкера и три профиля световых эффектов. Руководство — WEAPONS.md; сравнение — Demos/shooting-concepts-v06.mp4.

v0.5.3: подбор улучшений без сообщения о прибавках. E показывает только название; параметры и фактический рост света сохранены.

- Unity 6000.6.5f1, URP 2D, редактируемая сцена из двух комнат/коридора/двери.
- Капсула: WASD, направление мышью, F, здоровье, смерть и R.
- Фонарь 4.2/80°, стены/дверь перекрывают свет, почти полная темнота.
- Сталкер: шесть ног, независимый взгляд, подкрадывание, задержка реакции на свет, отступление, укус, смерть, затемнённые останки и процедурная кровь. Полные силуэтные тени включают ноги. Первая версия принята пользователем.
- Плейсхолдер наземного модуля фонаря, E, подсказка и уведомление. В v0.5.2 по новому запросу Repeatable=true: каждая копия +0.6 дальности/+6° угла. Три предмета в сцене, исходная позиция пользователя сохранена; две дополнительные в первой/второй комнате. После трёх 6.0/98°, пределы 7/110 редактируются на игроке. Прогресс при перезагрузке сбрасывается.
- Исправлено отображение Game View: увеличенный редакторский масштаб обрезал HUD. Fit Game View подгоняет полный кадр; подготовка демонстрации также делает Fit. Камера/Canvas и игровая логика подбора не изменены.
