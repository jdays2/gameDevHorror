# Инженерные ограничения и расширение

Текущий стандарт — [ADR-001](Decisions/001-sod-architecture.md), активный полный проход — [Roadmap](Roadmap/00-ArchitectureMigration.md). Фактические границы находятся в [ARCHITECTURE](ARCHITECTURE.md) и [Features](Features/README.md).

## Незакрыто

- [BL-001](Backlog.md#bl-001) — весь собственный код: MVC, команды, DI, адаптеры и проверка использования. Активно по поручению владельца.
- [BL-002](Backlog.md#bl-002) — динамические persistent ID и перенос между сценами не реализованы.
- [BL-003](Backlog.md#bl-003) — сохранение останков после удаления actor не имеет отдельного каталога.
- [BL-004](Backlog.md#bl-004) — совместимость будущих save-форматов и fallback .bak ограничены.
- [OPT-01](OPTIMIZATION_BACKLOG.md#opt-01-пик-нагрузки-при-массовой-гибели) — массовая смерть отложена; O(N²) соседей и прежний native-замер не доказывают производительность целевой карты.

## Удобство следующего изменения

Числовой вариант — данные/profile. Другой алгоритм — новая реализация за общим интерфейсом; общие пуля/HUD/урон не выбирают вид врага. Новая карта — авторенная сцена, а не копия логики прежнего уровня. Чистые Model/команды и изолированные экземпляры должны проверяться EditMode.
