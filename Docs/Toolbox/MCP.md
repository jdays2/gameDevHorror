Unity MCP — рабочий мост к открытому Unity Editor с нашим проектом. Перед изменениями проверяем фактическую сцену и ошибки консоли; наличие настройки не означает соединение с редактором.

В текущем чате объявлены инструменты Context7; прямые команды Unity MCP не объявлены. Конфигурация unityMCP и прежние фактические проверки описаны в руководстве выше. Этот список не меняет подключения и не запускает редактор.
