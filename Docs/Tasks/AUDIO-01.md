# Звук и музыка демо

**[← План](../MVP_PLAN.md)** · [Все разделы](README.md)

**Результат:** звук помогает исследовать, распознавать угрозы и чувствовать изменение темпа на всём пути.

## Принятая основа

- [x] Мембрана Сталкера, основные голоса/контакты, реалистичные выстрелы, гильзы, двери и подборы подключены.
- [x] FirearmMix02 закреплён как рабочий парный звук пистолета/дробовика.
- [x] Общий CreatureRupture06 содержит три варианта без немедленного повтора; коэффициент 0.8 уже проверен у Сталкера и Спящего.
- [x] Подключена семья трёх адаптивных фоновых слоёв; это ещё не окончательное сведение сцен демо.

[Аудиогайд](../Audio/AUDIO_GUIDE.md), [источники](../../Concepts/README.md), [проверка громкости разрыва](../Validation/RuptureVolume06.json).

## Недостающий контент

- [ ] После выбора третьего вида и босса подготовить их сигналы/реакции и согласовать слышимость.
- [ ] Определить нужные события маршрута: обучение, секрет, улучшение, переход, запуск/победа финала.
- [ ] Подготовить только недостающие звуки этих событий, переиспользуя подходящую текущую библиотеку.
- [ ] Выбрать атмосферу холодного сырого подвала и этажа больницы/лабораторий без подсказок о несуществующих угрозах.
- [ ] Довести адаптивную музыку исследования/угрозы/боя и переход к финалу.

## Сведение в игре

- [ ] Проверить тихое исследование, одного врага, смешанную встречу и финальный бой.
- [ ] Настроить слышимость через стены, дистанцию, громкость оружия/шагов и количество одновременно звучащих событий.
- [ ] Проверить отсутствие неприятных повторов, clipping и потерянных предупреждений.
- [ ] Прослушать полный маршрут и записать решения владельца.

Новое музыкальное направление начинается с короткой пробы на оценку; существующие принятые SFX не заменяем ранними бипами. Шаги игрока сохраняют намеренно тихий уровень .24.

Готовность: полный маршрут и финал прослушаны владельцем, необходимые звуковые события подключены, источники/лицензии сохранены. Технически чистый экспорт не заменяет художественного решения.
