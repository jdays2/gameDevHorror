## Окружение по локациям

- [ ] По принятому списку помещений составить набор: уже есть / нужно изготовить / можно переиспользовать.
- [ ] Выделить недостающие характерные предметы морга, холодного подвала, больничных помещений, лабораторий и арены. Конкретные новые типы сначала согласовать.
- [ ] Разобрать [существующий backlog объектов](../Environment/OBJECT_BACKLOG.md): первые восемь одобренных типов уже подготовлены, оставшиеся предложения не становятся обязательным заказом.
- [ ] Оценить текущую библиотеку в игровом масштабе и темноте; записать принятые семейства и точечные правки.
- [ ] Подготовить выбранные недостающие объекты, пол/стены/проёмы и навигационные детали без повторного производства уже подходящего контента.
- [ ] Разместить наборы в авторенных локациях, проверить коллизии, проходы, альфу и тени с разных направлений.

## Игрок, враги и оружие

- [ ] Утвердить и изготовить графику игрока и её связь с прицеливанием/оружием.
- [ ] Подготовить графику пистолета и дробовика в общей стилистике.
- [ ] Принять решение по временному Спящему; после снятия отсрочки собственного дизайна согласовать анатомию до анимационных листов.
- [ ] Сделать согласованные представления третьего вида и босса из [плана врагов](ENEMIES-01.md).
- [ ] Проверить состояния движения, попадания, атаки и смерти в реальном игровом масштабе.

## Кровь и останки

- [ ] Выбрать релизный объём [нового концепта разрыва](../Enemies/RUPTURE_CONCEPT.md): базовую существующую смерть оставляем или расширяем выбранными композициями.
- [ ] Для выбранного расширения сделать рисунки туш/частей/глаза и проверить отсутствие дублирующего глаза.
- [ ] Проверить однократность смерти, порядок отрисовки, точное восстановление осевших следов и читаемость пола.

Новая лужа, три осмысленных композиции и отдельный глаз пока являются концептом, в отличие от уже внедрённого звука. Их нельзя отметить готовыми по наличию GoreProfile.

Готовность: выбранный набор перечислен по локациям/персонажам, реально подключён и оценён. Источники, лицензии и промпты сохранены; подключение в обзорную сцену само по себе не означает художественного одобрения.
