# NAV-02 · Кликабельные галочки

**[← План](../MVP_PLAN.md)** · [Все карточки](README.md)

**Статус:** выполнено · **Дата:** 17 октября 2026.

## Цель

Отмечать выполнение мышью, сохраняя состояние в исходных Markdown-файлах. Встроенный просмотрщик на скриншоте показывает разметку `[x]` обычным текстом; предыдущая проверка ссылок этого не выявила.

## Шаги

- [x] Подтвердить проблему по скриншоту и исходному плану.
- [x] Подготовить локальный просмотрщик плана, карточек и навигации.
- [x] Сохранять переключение галочки в соответствующий MD, защищая более свежие изменения файла.
- [x] Проверить нажатие, перезагрузку, переходы и обратное снятие галочки в браузере.
- [x] Добавить запуск в один клик и обновить инструкции.

## Готово, когда

- [x] Галочки доступны мышью и клавиатурой, а состояние переживает обновление страницы.
- [x] Отметки реально изменяют Markdown, который читает агент; отдельной копии прогресса нет.
- [x] Проверки записи и конфликта пройдены; тестовые изменения восстановлены.

## Подтверждение

Пять изолированных тестов пройдены: запись/снятие с сохранением BOM и CRLF, отказ при более свежей правке, границы записи/путей, реальный HTML чекбоксов со ссылками и экранированием, HTTP-запись с проверкой Origin/сеансового ключа. Проверка через HTTP читает галочку обратно из файла и повторно загруженной страницы.

В браузере проверены переход план → карточка, нажатие мышью, перезагрузка с сохранённым состоянием, снятие галочки и повторная установка пробелом. После нажатия отдельно прочитан изменённый MD. Каталог skills открывает установленный SKILL.md. Launcher успешно поднял локальный процесс и открыл план.

[Инструкция](../Guides/PLAN_VIEWER.md), [сервер](../../Tools/PlanViewer/server.py), [тесты](../../Tools/PlanViewer/test_server.py). Изменения ограничены инструментом документации; игровой код и сцены эта задача не редактировала. Встроенный просмотрщик приложения не модифицирован: для кликов используется локальная страница, а данные остаются в MD.
