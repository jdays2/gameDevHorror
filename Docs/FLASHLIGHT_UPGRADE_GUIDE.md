# Повторяемое улучшение фонаря — v0.8.1

## Добавление на сцену

1. Останови Play и открой `Assets/EmergencyShift/Scenes/BasementPrototype.unity`.
2. В Project → Assets → EmergencyShift → Prefabs найди `FlashlightRangeUpgrade.prefab`.
3. Перетащи в Scene/Hierarchy. Задай свободную X/Y позицию, Z=-.045, Scale=1. Не клади внутрь стены или под врага. Для быстрой проверки размести в .8 от капсулы, чтобы сначала подойти.
4. Сохрани Ctrl+S, нажми Play, подойди центром игрока ближе .65. Предмет подберётся автоматически, даже с выключенным F; стена/закрытая дверь блокируют подбор.
5. Предмет исчезнет, прозвучит короткий временный звук, появится «Получено: Модуль фонаря». Числа оптики в игровом UI не показываются. При исходных4.2/80° первый модуль даст4.8/86°.

В текущей сцене четыре находки, включая пользовательскую дополнительную; их расстановку не сбрасываем. Ctrl+D создаёт следующий самостоятельный экземпляр. Один физический предмет однократный; Repeatable разрешает многократный тип. Дверь отдельно на E. Общая инструкция подбора/звука — [AUTO_PICKUP_AND_WEAPON_AUDIO.md](AUTO_PICKUP_AND_WEAPON_AUDIO.md).

| Модулей | Дальность | Угол |
|---|---|---|
|0|4.2|80°|
|1|4.8|86°|
|2|5.4|92°|
|3|6.0|98°|
|4|6.6|104°|

## Inspector

| Компонент/поле | Назначение |
|---|---|
|Pickup → Module Id|ID вида `range-lens-01`, одинаковый для повторяемых копий|
|Display Name|Название в уведомлении|
|Range Bonus / Angle Bonus|.6 /6°, редактируемые прибавки|
|Repeatable|true: каждая копия усиливает; false: один раз на Module Id|
|Pickup Range|Локальный максимум1, дополнительно ограничен PlayerInteraction.Auto Pickup Radius=.65 и Reach=1.6|
|Player → PlayerInteraction → Auto Pickup Radius|Фактическая общая дистанция автоподбора|
|Player → FlashlightUpgrades → Maximum Range/Angle|Пределы7/110°|
|Player → Flashlight2D → Range/Beam Angle|Исходная оптика, менять вне Play|

Requires Light удалён: свет помогает заметить предмет, но физический подбор не требует его. Нет подсказки E для модуля. Если оба предела достигнуты или уникальный ID уже установлен, предмет остаётся без спама уведомлений/звуков. Если один параметр ещё может расти, улучшение работает. Предмет сам F не включает.

Для отдельного углового модуля дублируй префаб в Project, задай новый Module Id, Range Bonus=0/Angle Bonus=15. Для изменения всех копий редактируй исходный префаб; отдельный экземпляр создаёт override. Настройки в Play сбрасываются после Stop.

## Почему компоненты разделены

IAutoPickup — маленький контракт C#, аналог интерфейса TypeScript: позиция и попытка подбора. PlayerInteraction ищет близкие коллайдеры, предмет проверяет доступность/однократность. FlashlightUpgradePickup знает название/бонус, FlashlightUpgrades хранит установленные модули игрока и пересчитывает от базы, Flashlight2D.SetOptics изменяет существующий источник. Класс света не заменяется и фонарь не создаётся заново.

HUD читает готовое сообщение. PlayerAudio2D подписан на успешный ItemCollected; он не устанавливает улучшение. CircleCollider2D.isTrigger нужен поиску, не физическому столкновению. Лут нарисован над полом/кровью, ниже живых врагов.

При переносе в другую сцену нужны Flashlight2D, PlayerInteraction, FlashlightUpgrades на игроке и Pickup Notification на HUD. Для звука — настроенный PlayerAudio2D; меню Emergency Shift → Audio → Configure pickup and candidate weapon audio назначает реальные ссылки в активной сцене, не строит уровень. Отдельный список предметов игроку не нужен.

Прогресс существует только в текущем запуске комнаты. Stop/перезагрузка возвращают предметы и базу; сохранение на диск/ключ-карты/случайное выпадение ещё не реализованы. Module Id — ID вида, не будущий стабильный ID конкретной находки для сейва. Если весь HUD обрезан в Game, воспользуйся Emergency Shift → Preview → Fit Game View.
