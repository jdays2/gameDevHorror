# Повторяемое улучшение фонаря — v0.5.2

## Добавление на сцену

1. Останови Play. Открой `Assets/EmergencyShift/Scenes/BasementPrototype.unity`.
2. В окне Project открой `Assets → EmergencyShift → Prefabs`.
3. Перетащи `FlashlightRangeUpgrade.prefab` в Scene или Hierarchy. Это небольшой светлый ромб с голубой серединой; итогового рисунка пока нет.
4. Выдели экземпляр. В Transform укажи X/Y свободного участка пола. Для быстрой проверки: рядом со стартовой капсулой, примерно в 0.7 единицы от неё. Z оставь **-0.045**, Scale **1,1,1**. Не клади предмет внутри стены, двери или непосредственно под телом врага.
5. Сохрани сцену Ctrl+S. Включи Play, включи фонарь F, наведи на предмет и подойди. Появится `[E] Подобрать: Модуль фонаря`.
6. Нажми E. Предмет исчезнет, дальность станет 4.8, угол 86° при исходных 4.2/80°. По правке пользователя отчёт о прибавках в игре не выводится; изменения видны по лучу. Дистанция страха сталкера остаётся прежней.

Игрок и HUD существующей сцены уже подключены. Вручную назначать ссылку на каждый экземпляр предмета не нужно: PlayerInteraction находит близкие коллайдеры. Новый объект можно дублировать Ctrl+D: при включённом Repeatable каждая новая копия складывает бонусы. Один физический предмет подбирается только один раз.

В сцене **три находки**: твоя исходная позиция сохранена, две дополнительные лежат в группе `Flashlight upgrades — test path`: (0,-0.7) в первой комнате и (12,1) во второй, после двери/коридора. Их можно свободно перемещать/дублировать. Повторное меню `Emergency Shift → Preview → Add two flashlight upgrades` не создаёт дубликаты уже существующих именованных экземпляров и не перемещает их.

| Найдено модулей | Дальность | Полный угол |
|---|---|---|
| 0 | 4.2 | 80° |
| 1 | 4.8 | 86° |
| 2 | 5.4 | 92° |
| 3 | 6.0 | 98° |

База сохранена: прибавки небольшие, чтобы после трёх находок обзор был заметно лучше, но не раскрывал всю комнату. Пределы сейчас 7.0/110°; при достижении обоих предмет остаётся с подсказкой «Фонарик улучшен до предела». Если достигнут только один предел, другой параметр продолжает расти.

Если пропали все подписи в Game, включая здоровье/F/E, сначала выбрать `Emergency Shift → Preview → Fit Game View`: fixed-resolution кадр может быть обрезан увеличенным Scale вкладки. Это отличается от недоступного предмета за стеной или вне дистанции.

В другой сцене игрок должен иметь `Flashlight2D`, `PlayerInteraction`, `FlashlightUpgrades`; HUD — ссылки на игрока и поле `Pickup Notification` типа Text. Ссылки камеры/света назначаются как раньше. Меню `Emergency Shift → Prepare flashlight upgrade` подготавливает только текущую BasementPrototype, сохраняет игрока/префаб/HUD и не расставляет лут. Повторный вызов сохраняет существующий предметный префаб и пользовательские значения оптики/сталкера.

## Поля Flashlight Upgrade Pickup в Inspector

| Поле | Значение и назначение |
|---|---|
| Module Id | `range-lens-01`. Идентификатор **вида улучшения**, не экземпляра на земле. При Repeatable одинаковые ID складываются |
| Display Name | Название в подсказке подбора |
| Range Bonus | 0.6; прибавка дальности в единицах мира |
| Angle Bonus | 6; прибавка полного угла в градусах |
| Pickup Range | 1.0; максимальная дистанция подбора от центра игрока. Дополнительно ограничена Reach компонента PlayerInteraction (1.6) |
| Requires Light | Включено: предмет требует попадания в основной луч. Выключено: можно подобрать рядом без включённого фонаря; стена всё равно блокирует подбор |
| Repeatable | Включено: каждая новая копия даёт бонус. Выключено: этот Module Id устанавливается только один раз |

Чтобы создать второй самостоятельный модуль, дублируй префаб в Project, например `FlashlightWideUpgrade`, задай **другой Module Id** (`wide-lens-01`), название, Range Bonus=0 и Angle Bonus=15. Такой модуль изменит угол 80 → 95 и сохранит дальность. Бонусы не могут быть отрицательными; хотя бы один должен быть больше нуля. Полный угол ограничен Flashlight2D значениями 20–140°.

Пределы меняются на **Player → Flashlight Upgrades → Maximum Range / Maximum Angle**. База — **Player → Flashlight 2D → Range / Beam Angle**. Для настройки одинаковых прибавок сразу у всех предметов открой сам префаб в Project; изменение на экземпляре сцены создаёт индивидуальное переопределение. Все эти значения меняй вне Play для сохранения.

При Repeatable=false две копии с одинаковым ID — уникальное улучшение: после первой установки вторая показывает «уже установлено», остаётся на земле и не усиливает свет. По текущему дизайну основная находка Repeatable=true; разные ID для каждой копии не нужны.

## Почему классы разделены

`FlashlightUpgradePickup` отвечает за предмет на полу: название, бонусы, доступность, однократное исчезновение. `FlashlightUpgrades` принадлежит игроку, суммирует успешные находки по видам модулей, считает оптику от исходной базы и применяет пределы. `Flashlight2D` остаётся тем же компонентом: `SetOptics` применяет результат к существующему Light2D, не меняя состояние F. Уменьшение пределов во время Play не превращает следующее улучшение в ухудшение.

`IInteractable` — небольшой интерфейс C#, похожий на контракт объекта в TypeScript: позиция, дистанция, доступность, подсказка, действие. Дверь и предмет реализуют его по-разному. `PlayerInteraction` выбирает одну цель и читает E; сами предметы клавиатуру не слушают. Поэтому одно нажатие не открывает дверь и не подбирает несколько вещей одновременно. HUD читает подсказку/уведомление, но не устанавливает модули.

Для одного типа лута данные хранятся прямо в компоненте префаба. ScriptableObject-каталог из дизайн-документа пока не создавался: он станет полезен при нескольких видах лута, нескольких представлениях одного предмета и общей таблице данных.

Триггер CircleCollider2D нужен для локального поиска, не для столкновения или автоматического подбора. Материал FlatLit делает плейсхолдер видимым в игровом свете. Порядок отрисовки и Z размещают его над полом/кровью и ниже живых врагов.

## Границы этой версии

Прогресс существует только в текущем запуске комнаты. Выход из Play или перезагрузка сцены возвращает расставленные предметы и исходную оптику; установленное улучшение не записывает изменения в префаб. Сохранение модулей между комнатами, ключ-карты, каталог лута и случайное выпадение ещё не реализованы. Module Id не заменяет будущий стабильный ID конкретной находки для сохранения.

Для подбора требуется досягаемость и свободный путь. При Requires Light используется текущий игровой тест основного луча с небольшим запасом от затухающего края; слабое ближнее свечение не считается. Мёртвый игрок предмет не подбирает. При выключении F модуль сам фонарь не включает. Дверь сохраняет свою дистанцию 1.6 и движение створки; ближайшая доступная цель имеет приоритет, почти одинаковые дистанции разрешаются по направлению взгляда.
