# Как собрать следующий уровень — v0.10

Уровень остаётся редактируемой .unity сценой. Префабы хранят повторяемые объекты, C# управляет поведением. Генерации карты при Play нет.

## Первые шаги

1. Остановить Play. Открыть Assets/EmergencyShift/Scenes/LevelTemplate.unity. Сразу File → Save As в новый файл, например MyFirstRoom.unity, чтобы сохранить шаблон.
2. В Hierarchy есть Level rig — player camera HUD context и Level geometry — edit in Scene. В rig уже Player, Camera+один AudioListener, Canvas/прицел, слабый Global Light2D, LevelContext2D.
3. Переставлять дочерний Player в стартовую точку; камера следует ему. Менять/дублировать стены/пол вместе с коллайдерами. Вне комнаты чёрный фон, unlit-границы слабо видны постоянно. Шаблон18×12 — плейсхолдер, не готовая карта.
4. Из Prefabs перетащить Door, ShadowStalker, PistolPickup, AmmoPickup, FlashlightRangeUpgrade. Шаблон специально пустой. Не сохранять временные объекты/запись/свет из Play.
5. На карте один LevelContext2D с PlayerLife2D/Flashlight2D этой карты. В rig он заполнен. Новые враги/дверной звук заполняют недостающие ссылки; явные ручные не заменяются.
6. В Build Profiles → Scene List добавить новую сцену для загрузки/сборки. Шаблон уже второй для проверки, BasementPrototype остаётся первой. Перехода комнат/переноса прогресса пока нет.

При сборке с нуля перетащить **один LevelRig.prefab**, затем геометрию. Не добавлять вторую Camera/AudioListener/Canvas/Global Light. Smoke явно загружает шаблон для проверки; обычная игра сама туда не переходит.

## Враги и темп

ShadowStalker содержит анимацию/звук/урон/CrowdAgent. Для засады выключить Patrol Enabled; Detection Radius определяет первичную близость, дополнительно нужен незаблокированный обзор. Для блуждания включить Patrol Enabled, Use Patrol Area опциональна. После первой агрессии враг не забывает игрока/не возвращается на патруль. Свет отгоняет временно.

EncounterZone нужен, чтобы группа начала участвовать позже. Расставить врагов, выключить их GameObject галочкой, добавить в Actors зоны, растянуть trigger на вход. Вход игрока разово включает список. Активных врагов зона сама не выключает, повторный вход не сбрасывает бой. Не помещать trigger внутрь выключенного родителя. После включения сохраняются обычные правила обнаружения сталкера; это не новая агрессия и не спавнер волн.

Для10–20 оставлять проходы шире тел, проверять узкие двери/углы и читаемость. CrowdAgent раздвигает тела, но не резервирует полосы движения. Радиус тела не равен размаху ног. Разные фазы ходьбы не меняют физику.

## Оружие и числа

Settings/PistolDefinition.asset: Damage=1, Maximum Ammo=120, Seconds Between Shots=.1, Range=10, Visuals=WarmFlash, Automatic=false. Новый Player/LevelRig читает эти данные. Изменение ассета меняет всех его пользователей.

У старого игрока BasementPrototype Use Definition Stats **выключен**, ваши ручные числа сохранены. Для перехода на ассет включить флаг PlayerWeapon2D. Для локального теста оставить выключенным/менять старые поля. При таком override изменение ассета не влияет на числа экземпляра.

Для другого прямого оружия Create → Emergency Shift → Weapon definition, настроить и назначить Weapon Definition находке. Пока находка выдаёт оружие только пустому слоту: переключения арсенала нет. Если definition совпадает с текущим, Acquire сохраняет локальные overrides. Звук отдельно настраивается в PlayerAudioSet; собственного аудиобанка WeaponDefinition пока не содержит.

## Минимальная проверка сцены

- WASD/F/мышь, один listener/нет ошибок; свет перекрывается стеной/дверью.
- E у новой двери, слышны начало/движение/упор; можно пройти/закрыть.
- Лут автоматически подбирается с правильным сообщением/звуком, через стену — нет.
- Новый враг обнаруживает только по близости+LOS, затем преследует, реагирует на свет/урон/умирает.
- Группа не проходит стены, проходы играбельны; трупы не блокируют путь.
- Проверить Windows-сборку целевой карты. Специальный Editor-тест20 не заменяет итоговый уровень.

Не запускать первоначальный SceneBuilder/старые массовые миграции ради каждой комнаты. LevelAuthoringSetup создаёт rig/шаблон только при отсутствии, не перезаписывает ваши ассеты.

## Проверка самостоятельной сборки

Для служебного smoke выбрать Managed Code Variant=Instrumented в Player Settings и Development Build в Build Profiles, собрать Windows x64. Запустить exe с --es-smoke-test --es-smoke-output <полный путь результата.json>. Проверка сама завершает приложение и пишет12 результатов. Обычный запуск без этих аргументов не меняется. После проверки вернуть Managed Code Variant=Release; instrumentation-мишени/runner в release-код не входят. Одного флага Development Build в Unity6.6 недостаточно для включения служебного кода.

Текущая сборка/отчёт — Readiness/BuildReport.json / StandaloneSmoke.json. Полный обычный запуск со светом/звуком/вводом и прохождением своей карты всё равно обязателен. Шаблон визуально проверен отдельно: Readiness/level-template.png.
