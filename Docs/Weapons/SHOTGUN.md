# Помповый дробовик

Статус: функциональный концепт утверждён владельцем 2026-10-16; первая игровая версия и звуковой вариант A подключены по поручению «попробуй пока так добавить». Баланс и звучание остаются на корректировку. Улучшения вместимости ещё не реализованы. [Пистолет](PISTOL.md) — звуковой ориентир.

## Утверждённый функционал

- Базовая вместимость — **4 патрона: до четырёх выстрелов без перезарядки**.
- Одно нажатие ЛКМ — один выстрел, расходующий один патрон. Удержание не продолжает стрельбу.
- Выстрел выпускает несколько отдельных дробин веером в направлении курсора. Каждая может попасть во врага или препятствие. Вблизи одна цель получает большую часть заряда; на расстоянии дробь рассеивается и может задеть нескольких врагов.
- Стены и закрытые двери останавливают дробь. Стрельба и попадания используют общие правила урона; несколько смертельных дробин не должны повторно создавать смерть/кровь одной особи.
- После каждого выстрела персонаж автоматически передёргивает цевьё: выбрасывает стреляную гильзу и готовит следующий выстрел. До завершения помпы стрелять нельзя.
- Перезарядка — по одному патрону. Её можно прервать выстрелом, если уже есть заряженный патрон и оружие готово стрелять. Незавершённая вставка не считается заряженным патроном.
- Движение и фонарь доступны во время помпы и перезарядки.
- В будущем найденные улучшения увеличивают вместимость магазина, как планируется и для пистолета. Вместимость магазина отделена от общего запаса патронов; см. [общую политику](README.md).

Желаемый ритм: мощный близкий выстрел → короткая работа помпы → движение/свет → следующий выстрел. Дробовик особенно эффективен вблизи; с расстоянием попаданий в одну цель становится меньше.

## Звучание

Реалистичное, типичное для помпового дробовика, в одной стилистике с принятым пистолетом. Использовать записи настоящих выстрелов, механики и гильз с тем же сдержанным подходом к обработке. Различия дублей не превращают одно оружие в три разных художественных направления.

| Событие | Звуковая роль |
|---|---|
| Выстрел | Узнаваемый хлопок/тело дробовика, короткий естественный хвост; один выстрел на расход одного патрона |
| Помпа после выстрела | Отдельные движение цевья/затвора и фиксация; событие помпы через 0.16 с после выстрела; анимация рук ещё не создана |
| Вставка патрона | Короткие реальные касание корпуса/загрузочная защёлка; один завершённый звук соответствует одной вставке |
| Пустой спуск | Короткий механический щелчок, без выстрела |
| Падение гильзы | Записанная стреляная гильза дробовика; контакт с полом отделён от помпы, без звона длинной винтовочной гильзы |
| Попадание | Бетон/дерево/плоть из общей стилистики; короткие группы контактов дроби. Один полный звук на материал за залп; реакция плоти Сталкера ограничена интервалом 0.05 с |

Текущая звуковая проба и происхождение — [ShotgunRealism01](../../Concepts/Used/Audio/ShotgunRealism01/README.md). В Unity теперь подключены три выстрела `shot_01_01..03` из ранее записанного банка B: атаки подрезаны до 3 мс предзвука, длина 0.6 с, короткий fade хвоста; PCM и предзагрузка. Помпа, вставки, пустой спуск, гильза и общая библиотека попаданий сохранены. Банк A остаётся прежней пробой для сравнения. В записи восьми выстрелов все события присутствовали, но разброс RMS атаки A достигал 13.5 дБ; после замены — 0.9 дБ. Это исправление не доказывает отсутствие любых аппаратных/нагрузочных пропусков.

## Первая игровая настройка

| Параметр | Значение |
|---|---|
| Магазин / стартовый резерв | 4 / 12 патронов |
| Максимальный общий боезапас | 36, включая заряженные |
| Дробины / урон каждой | 8 / 1 |
| Полный угол веера / дальность от дула | 18° / 8 Unity units |
| Помпа / минимальный интервал выстрелов | 0.85 / 0.9 с |
| Начало звука помпы и выброс гильзы | 0.16 с после выстрела |
| Завершение вставки одного патрона | каждые 0.8 с |

Это стартовые числа для тестов, не окончательный баланс. Направления дробин теперь независимые, со случайным сгущением к центру и прежним предельным углом ±9°. Равномерные угловые сектора удалены: попадания стали менее равномерными, а средняя кучность ближе к центру выше. Это намеренное изменение рисунка разброса для следующей оценки владельцем. Дробины используют настоящий общий projectile/collision/урон; двери и стены их останавливают.

В третьей комнате дробовик лежит у (46,2), коробка на 12 патронов — у (54,2). Подбор оружия переключает на него; **1 — пистолет, 2 — дробовик, X — зарядка, ЛКМ — отдельный выстрел**. Во время помпы смена оружия заблокирована; при смене во время зарядки незавершённая вставка отменяется. T пополняет общий запас выбранного оружия, зарядить магазин всё равно нужно через X. R сбрасывает песочницу.

Общие параметры — `Data/Weapons/PumpShotgun.asset`, эффекты — `ShotgunVisual.asset`, звуки — `Data/Audio/ShotgunPump.asset`. Заряженные/резерв/таймеры находятся в `PumpShotgunCycle` конкретного экземпляра; asset в Play не изменяется. Пистолет и дробовик хранятся в `WeaponInventory` независимо. Сохранение игрока format2 восстанавливает оба оружия и незавершённую операцию; в самой песочнице автосохранения нет.

## Видимость дроби

В `ShotgunVisual` лишь 28% дробин в среднем показывают штрих: число видимых следов случайное, иногда их может не быть. Все восемь projectiles продолжают лететь и наносить урон. Цвет следа приглушён до alpha .3, длина .1, ширина .012; `Trail Variation = .55` независимо меняет длину и прозрачность в пределах 45–100%. Скорость 44 и дальность 8 прежние. Пистолет использует ту же общую отрисовку, alpha его следа снижена до .45; звук пистолета не менялся.

Эти поля принадлежат общему `ShotVisualProfile`, а состояние видимости/вариации — конкретной пуле. Для следующего оружия достаточно своего профиля: `BulletProjectile2D` не проверяет тип оружия. Физический разброс остаётся ответственностью `PumpShotgunDefinition`. Собственная помпа/состояние магазина не затронуты.
