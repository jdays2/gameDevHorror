# Дверь и подбор предметов — v0.10

Используются физические записи направляющей/упора двери, щелчков патронов/оружия/модуля. Процедурные игровые сигналы заменены. Выбранные пистолет/гильзы и мембрана сталкера сохранены.

## Послушать

[Настоящий игровой микс](Audio/WorldFoley/gameplay-preview.wav), около7с: .3с открытие,1.4с закрытие,2.6с патроны,4с оружие,5.6с модуль. Записаны настоящие дверь/автоподбор временной постановки, без WAV-overdub.210 кадров/30fps,335872 стереосэмпла48kHz≈6.997с: начальный DSP-буфер даёт разницу128 сэмплов от ровно7с. Факты — RuntimeValidation.json рядом.

## Настройка в Unity

1. Остановить Play. Door.prefab → DoorAudio2D: Volume=.85, Movement Volume=.4, Hearing Distance=12. До2 единиц полная громкость, дальше плавное ослабление; XY-панорама до±.75.
2. Sounds → Audio/WorldFoley/DoorFoley.asset. Open Start/Close Start — разные монтажи одной rail-записи; Stop —2 упора; Slide Loop поддерживает движение и прекращается при остановке.
3. На двери сохранены2 AudioSource. Не включать Play On Awake и не переводить в3D rolloff: дистанция уже считается кодом для XY-камеры.
4. PlayerAudio2D → Pickup Volume=.9 (было.65). В PistolIndoorAudio.asset по2 варианта ammo/weapon/module. ItemCollected приходит только при успешном получении; без свободного места нет ложного звука, остаток патронов остаётся.
5. Общие настройки будущих игроков менять в Player.prefab; локальные — override экземпляра. LevelRig уже содержит полный Player, HUD/камеру/прицел. Уровень не создаёт их в Start.

Дверь пока не фильтруется через другие стены. Запись подтверждает работу без клиппинга; комфортную громкость на своей системе оценивает пользователь.

## Как работает код

Door2D владеет движением и сообщает MotionStarted(opening)/MotionStopped(opened). DoorAudio2D подписывается в OnEnable/отписывается в OnDisable, запускает transient+loop и завершает loop по факту остановки. Изменение Duration не требует второго аудиотаймера. Отключение двери посреди движения останавливает coroutine/фиксирует выбранную конечную позу и прекращает аудио.

PlayerInteraction подтверждает получение предмета, затем сообщает HUD/PlayerAudio2D. Канал принадлежит игроку, поэтому Destroy предмета не обрывает звук. У игрока25 источников:12 выстрел/8 гильзы/4 импакты/1 подбор. Это ограниченная полифония, не25 обязательных одновременных звуков.

WorldFoleySetup — редакторская миграция: обновляет банки, переносит прежнее scene-only аудио в префаб с сохранением ссылок, проверяет уникальность каналов. Это не runtime-построение сцены.
