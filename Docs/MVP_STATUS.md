## Что делать дальше

В терминах исходного MVP_PLAN: следующий незакрытый этап3 (доступ/дверь), затем5 (завершение/checkpoint),6 (целый маршрут),7 (прохождение в сборке). Этап4 уже работает без постоянного сохранения. Оптимизация массовой гибели отложена пользователем как некритичная: OPTIMIZATION_BACKLOG.md / OPT-01; при архитектурных решениях учитывать, сейчас не внедрять.

1. Собрать из уже работающих систем один короткий маршрут: найти ключ-карту, открыть дверь, добраться до выхода. Сначала формы и плейсхолдеры, без финального окружения.
2. Оценить подключённые звуки в нормальном прохождении; добавить шаги игрока/окружение по необходимости.
3. Подключить завершение румы/контрольную точку и сохранение на диск; сохранять доступ, находки, улучшения, боезапас и необходимое состояние пройденного участка. Уточнить правило завершения румы перед реализацией.
4. Проверить прохождение/поражение/продолжение в самостоятельной сборке, затем балансировать и расширять контент. Повторить нагрузочный сценарий на целевой карте в обычной сборке.

Новые виды, флаер, модификации пистолета, сложный инвентарь и финальные ассеты не обязательны для ближайшего проходимого среза. Порядок — рекомендация, а не разрешение автоматически реализовывать весь список.
