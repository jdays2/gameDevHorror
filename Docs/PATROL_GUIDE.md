# Ожидание, блуждание и постоянная агрессия — v0.7.2

Последнее решение пользователя отменяет возврат домой и потерю цели из v0.7.1. Патруль — только способ иногда двигаться до первого обнаружения. После агрессии враг преследует игрока до своей смерти или смерти игрока, с перерывами на испуг/реакцию попадания.

## Настроить засаду за углом или коробкой

1. Остановить Play, выбрать корневой объект сталкера в Hierarchy.
2. В **Stalker Patrol 2D** снять **Patrol Enabled**. Он стоит на текущем месте, возврата к spawn нет.
3. В **Shadow Stalker 2D → Detection Radius** выбрать дистанцию первого обнаружения. Голубой круг теперь вокруг самого врага, поэтому у гуляющего моба он перемещается вместе с телом.
4. Поставить врага за стеной/высоким шкафом/ящиком со слоем LightObstacles8. Близость сама по себе не активирует через преграду: нужна прямая видимость. Низкий стол9 пропускает свет/взгляд, поэтому для такой засады не подходит.
5. Сохранить сцену Ctrl+S и проверить подход с разных сторон.

В коде поле пока называется habitatRadius, чтобы сохранить пользовательские значения/overrides, но в Inspector отображается **Detection Radius**. Это больше не домашняя территория и не радиус прекращения погони.

## Добавить редкие перемещения

| Поле Stalker Patrol 2D | Назначение |
|---|---|
| Patrol Enabled | Включить мирные переходы и паузы; выключить — остановиться там, где находится |
| Use Patrol Area | Необязательное ограничение мирных точек прямоугольником |
| Wander Step Distance | При выключенном Use Patrol Area: дальность случайного шага от текущего места; база1.6 |
| Area Size / Area Offset | При включённой области: ширина/высота и центр относительно начальной расстановки |
| Patrol Speed | Мирная скорость, база0.6 |
| Pause Seconds | Случайная пауза, база0.6–1.8; увеличить для более редких перемещений |

Область можно растягивать жёлтыми маркерами в Scene при включённых Gizmos. Она задаёт мирные точки назначения, не территорию преследования. Без области моб выбирает короткие свободные шаги от текущей позиции. При смене флага в Play он не идёт домой. После отброса/испуга положение не сбрасывается: ограниченный патруль выбирает достижимую точку внутри заданной области, свободный — возле нового места. Слишком маленькая область безопасно останавливает движение; непроходимый отрезок отклоняется.

Изменения Play после Stop исчезают. Позиции/радиусы и выбранные пользователем Patrol Enabled сохранены. В текущем примере за шкафом второй комнаты флаг включён и область3×4 сохранена; остальные настройки не переписаны. Новый префаб по умолчанию ждёт, Use Patrol Area доступен как отдельный флаг.

## Что происходит после обнаружения

Близость + прямая видимость один раз устанавливают **HasAggro**. Попадание пули по живому врагу также провоцирует его. Уход из радиуса, большое расстояние, угол, закрытая дверь и истечение времени агрессию не сбрасывают. При ясном проходе он стремится за спину; за преградой выбирает путь к текущему положению игрока. Укус по-прежнему требует дистанции и прямой видимости. Закрытая дверь остаётся физической преградой: враг не проходит сквозь неё, не ломает/не открывает её автоматически, но не забывает игрока. После открытия проверяет путь снова.

После испуга возвращается к преследованию, если агрессия уже была. Освещение может напугать и ещё не активированного врага вне Detection Radius: само по себе это не включает вечную агрессию. После испуга такой враг продолжает выбранное мирное поведение с нового места. Фонарь не действует через непрозрачную преграду.

| Параметр Shadow Stalker 2D | Новая база |
|---|---|
| Creep Speed | 1.5 — преследование |
| Retreat Speed | 3.8 — отход от света |
| Light Fear Distance | 3.2 — дальность страха, дополнительно нужны луч/LOS |
| Reaction Delay | Сохранён на каждом экземпляре:0.33/0.45; это не мгновенный разворот |

Расстановка, Detection Radius и задержки пользователя сохранены. Новые значения скоростей/страха применены к префабу и всем семи живым экземплярам. Более высокие ручные значения при подготовке не уменьшаются. Большая дальность страха не увеличивает сам луч; она работает только в реально освещённой части.

## Пределы текущей навигации

Мирный маршрут проверяет свободные прямые отрезки. Для активной погони добавлен ограниченный A* по сетке0.6 с радиусом тела, стенами/дверями8 и низкой мебелью9. Прямой свободный путь обходится без поиска. Перестроение ограничено по частоте и объёму; закрытый проход означает ожидание доступного маршрута, а не сброс агрессии. Это не гарантия пути по любой карте и не проверка толпы10–20: сложные уровни, узкие проходы, нагрузку и групповое движение потребуется измерять отдельно.

## Флаер — будущее требование

Бросаемый флаер станет временным перемещаемым источником опасного для сталкера света: отпугивание от освещённой зоны, отсчёт времени и учёт стен. Он временно прерывает наступление, но не обнуляет HasAggro. Физика броска, предмет, расход, длительность, выбор угрозы между флаером/фонарём и эффект ещё не реализованы. Обычные лампы и вспышки выстрелов пока не отпугивают. Когда дойдём до флаера, отделим описание световой угрозы от самого Flashlight2D; сейчас лишняя пустая система не добавлена.

Для нового экземпляра ShadowStalker.prefab назначить Player и Flashlight в Shadow Stalker 2D ссылками на игрока/его фонарь в сцене. У существующих семи они уже назначены.
