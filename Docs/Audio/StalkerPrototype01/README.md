# Прослушивание сталкера — Prototype01

Порядок в `stalker-showcase.wav`:

- 0.40–1.45 с — Контакты конечностей
- 2.10–3.76 с — Тихий скрежет и выдох
- 4.41–5.03 с — Обнаружение игрока
- 5.68–5.92 с — Подготовка укуса
- 6.57–6.78 с — Бросок
- 7.43–7.85 с — Укус
- 8.50–9.65 с — Испуг от света
- 10.30–11.28 с — Быстрый перестук при отступлении
- 11.93–12.26 с — Попадание в плоть и короткий хрип
- 12.91–14.38 с — Разрыв тела и кровь
- 15.03–15.36 с — Падение останков

`stalker-encounter.wav` — постановочная 16-секундная сцена: подкрадывание, обнаружение, атака, испуг/отход, ранение/разрыв. Это монтаж аудио, не запись Unity.

Исходные 31 WAV: 48 кГц, 24 бит, моно, короткие one-shot. Новые варианты получены отдельным синтезом с разными seed, не только изменением pitch.

Это оригинальный процедурный прототип, не нейросетевая генерация или запись настоящих животных. Художественная оценка — после прослушивания пользователем. К игровым событиям ещё не подключён.

Файлы и назначение — manifest.json. Подробный гайд — ../../STALKER_AUDIO.md.
