# Три состояния v2 — развитие новой серии фактур

Пользователь запросил новое превью исследование/угроза/бой после отказа от дабстепа. Скриншотом он уточнил, что понравилась новая10-секундная проба под сообщением о трёх фактурах, а не DistantMemory. Открытый URL был ошибочно принят ассистентом за выбор; до передачи результата основа исправлена.

Использована общая base из новой серии. Она не фильтруется, сохраняется во всех фазах и повторяется с секундными плавными стыками. Скриншот не содержит task ID: оригинальные три10-секундные записи доступны в плеере для сверки, отдельно подтверждённый пользователем ID не заявляется. Это развитие через сведение, не новая40-секундная непрерывная генерация.

## Прослушивание

- 0–12с: исследование, только основа.
- 12–24с: угроза, за3с добавляется тихая напряжённая фактура.
- 24–36с: бой, за3с добавляется более плотный слой, основа остаётся.
- 36–40с: слои уходят, финальное затухание.

Файл: ../../Demos/audio-states-v2.mp3. Это реальный офлайн-микс трёх записей, не запись Unity и не готовый игровой контроллер. Ритмическая заготовка из прошлой попытки не использована. Программно не добавлены бит/перкуссия/оружие/монстры.

Созданы три новые10-секундные ambient-заготовки за30 кредитов, все участвуют в миксе; после уточнения пользователя дополнительных генераций не запускалось. DistantMemory не используется. Всё происхождение/промпты/task ID — manifest.json.

## Сведение и проверка

build_preview.py принимает каталог base.mp3/tension.mp3/pressure.mp3, FFmpeg и путь выходного MP3. Нужен numpy. У новых слоёв плавное спектральное ограничение/уровни/огибающие; у основы только уровень/повтор/затухание. Отдельные синхронные ноты/такты не заявляются, это свободные неритмичные фактуры.

validation.json содержит длительность40с, декодирование MP3, контроль конечности чисел, запас по sample peak, RMS фаз, фактические коэффициенты слоёв и SHA-256. Это техническая проверка, не слуховая оценка: попадание в настроение/отсутствие нежелательных тембров/незаметность повторов ещё оценивает пользователь.

Сырые файлы скачаны для настоящей обработки/сведения, хранятся в work вне репозитория; подписанные URL не коммитятся. Пользовательская сцена, принятые SFX и игровой код не менялись. Интеграция/автоматические игровые переходы — после оценки.
