# Аудиосистема

## Роли

- **StalkerAudio2D / StalkerAudioSet:** два ограниченных голоса, контакты по фактическому пути, нерегулярная мембрана, события страха/укуса/разрыва. Фильтр поверхности меняет контакт, не характер существа.
- **PlayerAudio2D / PlayerAudioSet:** пистолет, гильзы, попадания, подбор. Player prefab содержит25 уникальных AudioSource:12 shot,8 casing,4 impact,1 pickup. При увеличении массива Inspector не клонировать ссылки.
- **DoorAudio2D / DoorAudioSet:** начало/движение/остановка двери, два источника и пространственная слышимость.
- **PlayerFootsteps2D / PlayerUtilityAudio2D / PlayerWorldAudioSet:** шаги, фонарь, сухой спуск, ранение/поражение. Шаги по пути, не при толкании стены; footstepVolume=.24.
- **LevelAudioDirector2D / AudioMoodProfile:** Explore/Tension/Combat, Critical независимо; локальные AudioThreatEmitter2D сообщают угрозу через видовые адаптеры.

Общие профили — Data/Audio; видовые наборы — соответствующие каталоги Assets/EmergencyShift/Audio. WeaponDefinition/ShotVisualProfile — Data/Weapons. Общий asset влияет на все ссылки, не использовать его как временную переменную в Play.

## Настройка

1. Шаги: PlayerWorldAudioSet, Footstep Volume.
2. Выстрел/гильза/подбор/попадание: PlayerAudioSet и частные уровни PlayerAudio2D.
3. Дверь: DoorAudioSet/компонент; движение отдельно от одиночного щелчка.
4. Мембрана: варианты в StalkerAudioSet, слышимость/паузы/уровни в StalkerAudio2D.
5. Фон/переходы: Data/Audio/SurvivalAudio.asset; проверить одиночную угрозу, группу и спад.

ImpactSurface2D выбирает бетон/дерево/плоть на конечной цели. Пуля не зависит от вида врага. Гильза звучит при падении/контакте. Чередование дублей и малые вариации снижают повторение, не меняют характер выстрела.

## Текущий парный микс FirearmMix02

Закреплён владельцем 2026-10-16 как текущий рабочий звук оружия. Точные файлы и уровни зафиксированы в [acceptance.json](../../Concepts/Used/Audio/FirearmMix02/acceptance.json); новые правки — по обратной связи.

Оба оружия теперь имеют явный WeaponAudioProfile; пистолет больше не зависит от скрытого shotVolume fallback для текущего выстрела. Производные из прежних реальных источников находятся в Audio/FirearmMix02. Пистолет: чуть меньше низа/хвоста, shotGain .45, casingGain .14. Дробовик: более плотное тело, shotGain .92. В Unity атака дробовика на 4.4 дБ плотнее, общий peak .758 без clipping. [Обработка, лицензии и запись](../../Concepts/Used/Audio/FirearmMix02/README.md).

Пустой щелчок — только `CanDryFire`: пустой магазин в Ready. При Loading/Pumping и успешном выстреле dry-события нет. Один общий записанный dry-trigger, emptyGain .3; отдельный utility-голос. Звук перезарядки пистолета запускается один раз на MagazineReloadStarted и останавливается при отмене/смене оружия/смерти. Источник взят из существующего ограниченного банка механики, новых AudioSource нет. Прежние записи выстрелов и гильз сохранены как источники; блок про прежнюю интеграцию ниже — история выбора до FirearmMix02.

## Сведение

Обычное огнестрельное оружие следует единой реалистичной стилистике принятого пистолета. Для дробовика нужны узнаваемые реальные выстрелы, механика помпы, зарядка по одному патрону и собственная стреляная гильза. Вариативность — близкие дубли одного оружия, со сдержанной обработкой и короткими естественными отражениями. Не добавлять фантастический бас, бипы или чрезмерную кинематографическую реверберацию. Попадания по бетону/дереву и принятая реакция плоти сохраняют общую палитру; смена оружия не разрешает подменять их новым художественным направлением.

Документация оружия — [пистолет](../Weapons/PISTOL.md) и [помповый дробовик](../Weapons/SHOTGUN.md). Из [ShotgunRealism01](../../Concepts/Used/Audio/ShotgunRealism01/README.md) подключены 11 событийных записей: три выстрела `shot_01` из банка B с ровной атакой и коротким предзвуком, три помпы, три вставки, пустой спуск и гильза. Новые выстрелы импортированы как предзагруженный PCM/Decompress On Load. Прежние A сохранены как материал сравнения и больше не выбираются профилем. [Точная нарезка](../../Concepts/Used/Audio/ShotgunRealism01/gameplay-bank.json), [запись восьми выстрелов из Unity](../../Concepts/Used/Audio/ShotgunRealism01/Previews/06-gameplay-even-shots.mp3). WeaponAudioProfile выбирается через definition. Выстрел/помпа/вставка/падение гильзы/попадание остаются отдельными событиями. Материалы используют прежнюю библиотеку, один полный impact на материал за залп; у Сталкера hit-cue ограничен 0.05 с. Новых AudioSource не добавлено, голоса механики берутся из существующего casing-банка. Окончательный микс требует прослушивания владельцем.

Атмосфера/слышимость угрозы важнее громкости каждого слоя. Не переписывать принятые SFX без причины. Фон не содержит монстров/оружия, они динамические. Исследование без навязчивого бита; угроза усиливает напряжение; бой не превращается по умолчанию в дабстеп/Doom.

Новое направление: короткая отдельная проба для оценки → одобрение → наложение/полная работа. Отсутствие clipping не доказывает попадания в атмосферу. Оценивать шаги/выстрелы/одного врага/группу вместе. Текущее подключение ещё не финальное сведение всей акустики.


## Ожог и общий разрыв существ

[StalkerTissue05](../../Concepts/Used/Audio/StalkerTissue05/README.md): EyeBurn 0.48 с, предзагруженный PCM16 mono / 48 kHz; контакт начинается до видимого ожога, шаги ждут его окончания, голос страха остаётся отдельным. Два прежних flesh-pop этой семьи больше не выбираются.

[CreatureRupture06](../../Concepts/Used/Audio/CreatureRupture06/README.md): одобренный клип и две монтажные вариации, 0.97–1 с, PCM16 mono / 48 kHz, предзагрузка. `Data/Audio/CreatureRupture06.asset` содержит единственный общий список. Его `volume = 0.8` уменьшает только разрыв обоих видов примерно на 1.94 дБ. Это множитель поверх видового voiceVolume, без изменения WAV и уровней остальных голосов. `StalkerAudioSet.deathSounds` и `SleeperAudioProfile.deathSounds` ссылаются на него; legacy `death`/`rupture` используются только если общий набор не назначен. В текущих профилях legacy-ссылки очищены, исходники сохранены.

`EnemyDeathAudioVariants` хранит последний выбор на время Play-сессии отдельно от SO и исключает его при следующем выборе с тем же набором, включая другого врага/вид. При запуске Play история очищается. Пустые записи пропускаются, единственный клип может повторяться. Обычные XY-затухание/преграды, уровни видовых voice-источников и бюджет смертей Сталкера сохранены; новых AudioSource нет. Сон/пробуждение/ранение и ожог не заменены. Один death event даёт одно проигрывание; повторное попадание и восстановление checkpoint не запускают новый разрыв.
