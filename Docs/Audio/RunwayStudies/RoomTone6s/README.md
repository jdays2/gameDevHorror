# Фоновый тональный шум помещения — 3 × 6 секунд

После отклонения BasementTrio пользователь уточнил: нужен «мелодичный шум помещения» как непрерывный фон. Монстры звучат динамически своими источниками, а не в этой дорожке. Запрошены три разных образца ровно по6 секунд.

Созданы A «Тёплый глухой гул», B «Холодный воздушный фон», C «Тесное помещение». Различаются низкой/воздушной/плотной резонансной фактурой. Это описания заданий, не подтверждение художественного результата. Во всех промптах исключены монстры, дыхание, шаги, скрежеты, удары и другие отдельные события.

6 кредитов за каждый образец,18 всего. Точные промпты/task ID/длительности — manifest.json. Loop запрошен генератору; качество стыка/звучания требует прослушивания, автоматического одобрения нет.

Локальный потоковый плеер позволяет сравнить варианты; подписанные URL в репозиторий не включены. Пробы сгенерированы, не полевые записи. Интеграция/игровой микс/замена SFX не выполнялись. Пользовательская сцена не менялась.
