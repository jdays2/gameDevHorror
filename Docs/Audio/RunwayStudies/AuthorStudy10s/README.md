# Самостоятельная проба — 10 секунд

Пользователь отклонил RoomTone6s и попросил один10-секундный пример по собственному представлению ассистента, без следования прежним описаниям. Замысел «Гул пустоты»: ощущение глубины, глубокий мягкий резонанс и далёкая полая тональная фактура, растворяющаяся в тишине. Это описание намерения; оценка звучания ожидается.

Одна генерация через подключённый аудиосервис по промпту ассистента,10 секунд/10 кредитов. Это не локальный процедурный синтез и не настоящая запись помещения. Промпт/task ID — manifest.json. Проба отдельно в потоковом плеере; временный подписанный URL не сохраняется в Git.

Без интеграции, игрового микса, замены SFX или изменений пользовательской сцены. Повтор/сведение — после оценки.
