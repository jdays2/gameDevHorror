# Проверка Runway Standard

15 октября 2026 пользователь сообщил о покупке Standard и поручил проверить, хватит ли тарифа. Проверка авторизации подтвердила платный доступ и625 месячных кредитов. Приняты две пробные генерации: музыка исследования за4 кредита и3с костяного скрежета по бетону за3. Остаток после принятия запросов —618.

Обе генерации завершились успешно и вернули MP3: музыка≈25.78с, скрежет3с по метаданным результата. Параметры/идентификаторы/промпты в manifest.json. Это экспериментальные пробы, не утверждённое аудио. Результаты представлены через Runway; временные подписанные ссылки/токены в Git не сохраняются. Успешная генерация подтверждает доступ, но не художественное качество, бесшовную петлю или успешную интеграцию в игру.

Первоначальная оценка музыкального набора:25–50 полных вариантов ×8 +10–20 коротких ×4 =240–480 кредитов. После этих7 тестовых кредитов на балансе618 такой бюджет оставляет138–378. Это расчёт числа попыток, не обещание готового саундтрека; SFX/видео/картинки и дальнейшие переделки расходуют тот же баланс отдельно.

Рабочая мембрана/пистолет/двери/подбор и игровые сцены не изменяются. Следующий расход — после оценки этих образцов или нового прямого поручения пользователя.
