# Короткие варианты голоса сталкера — Choices03

Пользователь отклонил звонкость плитки и дыхательный характер Studies02. Здесь три новых варианта для художественного выбора, не утверждённый набор. Все созданы локальным процедурным синтезом; платные сервисы/записи не используются.

| Файл | Характер |
|---|---|
| 01-cartilage.wav | Редкие суховатые щелчки сочленений, затем короткий писк с серией хрящевых сокращений |
| 02-membrane.wav | Короткое натяжение/скрип мембраны, резче при реакции на свет |
| 03-quiet-hunter.wav | Почти тихий покой, один малый щелчок; короткий высокий писк, прерывистое затихание |
| 04-neutral-feet.wav | Более глухой базовый контакт ног без ceramic ring/комнатного хвоста; медленно → быстрее |

Каждый файл 5.5 секунды. У первых трёх: покой до2с, реакция на свет с2.3с, короткие затихающие реакции около3.25/4.1с. Паузы/реакции поставлены вручную для сравнения, это не игровая последовательность. Для отбора тембра шаги не смешаны с голосом. Сохранён общий масштаб уровней: редкий idle тише боли, не нормализовать файлы отдельно.

Непрерывного дыхательного/шумового слоя нет. Это синтезированные эскизы, художественное звучание ещё не одобрено. Нейтральный контакт допускает будущие отдельные слои поверхности и настройки в движке; сами такие настройки/детектор поверхности здесь не реализованы. В игре звука пока нет. WAV — моно PCM24/48kHz; manifest содержит seed/SHA/уровни, Validation — фактическое декодирование/формат/края/тишина.
